# 🟡 Level 6: Lists (Ordered, Unordered & Nested)

Welcome to Level 6! In this challenge you will organize content using unordered lists (bullet points), ordered lists (numbered steps), and nested lists.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-6/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- An unordered list (`<ul>`) listing at least 3 technologies you want to learn.
- An ordered list (`<ol>`) detailing 3 steps to contribute to Open Source (Fork, Clone, PR).
- At least one nested list (a list inside another list item `<li>`).

---

## 💡 Example

```html
<h2>Technologies</h2>
<ul>
  <li>Frontend
    <ul>
      <li>HTML5</li>
      <li>CSS3</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
```

---

## 🧪 Testing your solution

Open your file in any web browser to verify its visual display:
