# 🟢 Level 4: Hyperlinks & Anchors

Welcome to Level 4! In this challenge you will create various types of hyperlinks: external links, email links, and internal page jump anchors.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-4/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- External link using `<a href="https://github.com/<your-username>" target="_blank" rel="noopener noreferrer">`.
- Email link using `<a href="mailto:...">`.
- Internal jump link: a link with `href="#section-bottom"` that jumps to an element with `id="section-bottom"`.

---

## 💡 Example

```html
<a href="#contact">Jump to Contact</a>
<hr>
<p><a href="https://github.com/octocat" target="_blank" rel="noopener noreferrer">My GitHub Profile</a></p>
<div id="contact">
  <a href="mailto:hello@example.com">Send me an email</a>
</div>
```
