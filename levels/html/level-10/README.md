# 🔴 Level 10: Interactive Components & Rich Media

Welcome to Level 10! The final challenge of the HTML track. Practice building native interactive widgets using `<details>`, `<summary>`, progress bars, and audio/video elements.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-10/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- At least two collapsible accordion items using `<details>` and `<summary>`.
- A `<progress>` element displaying current progress (e.g. `value="10" max="10"`).
- A `<meter>` element demonstrating measurement display.
- An embedded `<audio>` or `<video>` element with `controls` attribute.

---

## 💡 Example

```html
<details>
  <summary>Click to view FAQ</summary>
  <p>Here is the hidden answer!</p>
</details>
<label for="prog">Progress:</label>
<progress id="prog" value="10" max="10">100%</progress>
```

---

## 🧪 Testing your solution

Open your file in any web browser to verify its visual display:

- **Windows:** Double-click `levels/html/level-10/<your-username>.html` or right-click > Open with > Chrome/Edge/Firefox.
- **Mac:** `open levels/html/level-10/<your-username>.html`
- **Linux:** `xdg-open levels/html/level-10/<your-username>.html`
