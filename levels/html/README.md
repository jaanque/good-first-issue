## 🛠️ General Guidelines

1. **File Name:**  
   Inside each level directory, create a file named with your exact GitHub username followed by `.html`:  
   `levels/html/level-X/<your-username>.html` *(e.g. `octocat.html`)*

2. **Code Quality:**  
   - Use clean, properly indented HTML syntax.
   - Always include meaningful `alt` attributes on images for accessibility.
   - Use lowercase tag names (`<h1>`, `<p>`, etc.).

> [!NOTE]
> You can test your HTML files by opening them directly in any web browser (Chrome, Firefox, Edge, Safari).
