# 🔴 Level 9: Semantic HTML5 Page Layout

Welcome to Level 9! In this challenge you will build a complete page using HTML5 semantic landmark elements instead of unstyled divs.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-9/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- `<header>` with a site title and main navigation (`<nav>`).
- `<main>` landmark containing at least one `<article>` and one `<section>`.
- `<aside>` for sidebar information or extra links.
- `<footer>` with copyright and author info.

---

## 💡 Example

```html
<header>
  <h1>My Site</h1>
  <nav><a href="#home">Home</a></nav>
</header>
<main>
  <article>
    <h2>Article Title</h2>
    <p>Content...</p>
  </article>
</main>
<footer>
  <p>&copy; 2026</p>
</footer>
```

---

## 🧪 Testing your solution

Open your file in any web browser to verify its visual display:
