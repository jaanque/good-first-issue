# 🟢 Level 3: Text Formatting & Typography

Welcome to Level 3! Practice formatting text using semantic HTML tags such as headings, bold, italics, highlights, and line breaks.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-3/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- Use headings `<h1>`, `<h2>`, and `<h3>`.
- Use `<strong>` (or `<b>`) for bold text and `<em>` (or `<i>`) for italicized text.
- Use `<mark>` to highlight a keyword.
- Use `<hr>` for a thematic break and `<code>` for inline code snippets.

---

## 💡 Example

```html
<h1>Developer Story</h1>
<hr>
<h2>About Me</h2>
<p>I am learning <strong>HTML</strong> and writing <em>clean code</em>.</p>
<p>My favorite tag is <code>&lt;strong&gt;</code> because it <mark>stands out</mark>.</p>
```
