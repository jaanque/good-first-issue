# 🟡 Level 5: Images & Media with Accessibility

Welcome to Level 5! Learn how to embed images properly with descriptive alternative text (alt text), dimensions, and semantic figure captions.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-5/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- Embed an image using `<img>` with `src`, meaningful `alt` text, `width`, and `height`.
- Use a `<figure>` tag enclosing an `<img>` and a `<figcaption>` describing the media.
- Use your GitHub avatar URL (e.g. `https://github.com/<your-username>.png`).

---

## 💡 Example

```html
<figure>
  <img src="https://github.com/octocat.png" alt="Octocat GitHub Avatar" width="120" height="120">
  <figcaption>Profile picture of @octocat</figcaption>
</figure>
```

---

## 🧪 Testing your solution

Open your file in any web browser to verify its visual display:

- **Windows:** Double-click `levels/html/level-5/<your-username>.html` or right-click > Open with > Chrome/Edge/Firefox.
- **Mac:** `open levels/html/level-5/<your-username>.html`
- **Linux:** `xdg-open levels/html/level-5/<your-username>.html`
