# 🟡 Level 7: Tables & Tabular Data

Welcome to Level 7! In this challenge you will organize structured data into an accessible HTML table using table headers, body, rows, and cells.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-7/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- Use `<table>`, `<thead>`, `<tbody>`, and optionally `<tfoot>`.
- Use `<tr>` for rows, `<th>` for header cells (with `scope="col"`), and `<td>` for data cells.
- Display a table with at least 3 columns (e.g. Language, Skill Level, Year Started) and at least 3 rows of data.

---

## 💡 Example

```html
<table border="1">
  <thead>
    <tr>
      <th scope="col">Language</th>
      <th scope="col">Level</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML</td>
      <td>Intermediate</td>
    </tr>
  </tbody>
</table>
```
