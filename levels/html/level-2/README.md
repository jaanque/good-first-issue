# 🟢 Level 2: Full HTML5 Document Structure

Welcome to Level 2! In this challenge you will build a complete, valid HTML5 document structure including doctype, head, title, and body.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-2/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- Start with `<!DOCTYPE html>`.
- Root `<html lang="en">` element.
- `<head>` section containing `<meta charset="UTF-8">`, viewport meta tag, and a `<title>` with your username.
- `<body>` section with an `<h1>` heading and an introductory `<p>`.

---

## 💡 Example

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Octocat - Level 2</title>
  </head>
  <body>
    <h1>Welcome to my Level 2 Page</h1>
    <p>This is a complete HTML5 document created by @octocat.</p>
  </body>
</html>
```

---
