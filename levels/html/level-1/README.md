# 🟢 Level 1: Heading & Welcome Message

Welcome to Level 1! This is the simplest possible starting point. Your goal is to write a minimal HTML snippet containing a heading and a paragraph welcoming others to Open Source.

---

## 🎯 Objective

Create a file named `<your-username>.html` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/html/level-1/<your-username>.html` *(e.g. `octocat.html`)*

2. **Specifications:**
- Include an `<h1>` heading with the text `"Hello Open Source!"`.
- Include a `<p>` paragraph introducing yourself with your GitHub username (e.g. `"I am @<your-username> and this is my HTML Level 1 contribution."`).

---

## 💡 Example

```html
<h1>Hello Open Source!</h1>
<p>I am @octocat and this is my HTML Level 1 contribution.</p>
```

---

## 🧪 Testing your solution

Open your file in any web browser to verify its visual display:

- **Windows:** Double-click `levels/html/level-1/<your-username>.html` or right-click > Open with > Chrome/Edge/Firefox.
- **Mac:** `open levels/html/level-1/<your-username>.html`
- **Linux:** `xdg-open levels/html/level-1/<your-username>.html`
