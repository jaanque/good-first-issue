# 🟢 Level 1: Print Welcome Message (console.log)

Welcome to Level 1! This is the simplest possible starting point. Your goal is to write a JavaScript script that outputs a welcome message using `console.log()`.

---

## 🎯 Objective

Create a file named `<your-username>.js` in this directory following the requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/js/level-1/<your-username>.js` *(e.g. `octocat.js`)*

2. **Specifications:**
- Use `console.log()` to print a message to the terminal.
- The output must include:
  - The phrase `"Hello Open Source!"`
  - Your GitHub username (e.g. `@<your-username>`)

---

## 💡 Example

```javascript
console.log("Hello Open Source! I am @octocat and this is my JS Level 1 contribution.");
```

---

## 🧪 Testing your solution

Run your script in the terminal using Node.js:

```bash
node levels/js/level-1/<your-username>.js
```
