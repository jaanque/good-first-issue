# 🟢 Level 1: Print Welcome Message (`console.log`)

> **Difficulty:** Very Easy | **Estimated Time:** 5 mins | **Track:** JavaScript

Welcome to **Level 1** of the JavaScript Track! This is the classic starting point for every programmer: sending text to the standard output (`stdout`) of your terminal.

---

## 📖 What You'll Learn & Why It Matters

In JavaScript, `console.log()` is the fundamental tool for displaying information, checking values, and debugging code. When running in a terminal environment via **Node.js**, `console.log()` writes directly to your terminal screen.

### Syntax Quick Look:
```javascript
console.log("Hello, World!");
```
- Strings can be enclosed in double quotes (`"..."`), single quotes (`'...'`), or backticks (`` `...` ``).
- Statements are executed sequentially from top to bottom.

---

## 🎯 Objective

Create a file named `<your-username>.js` in this directory that outputs a friendly welcome message welcoming you to open source.

---

## 📋 Requirements

1. **File Location:**  
   `levels/js/level-1/<your-username>.js` *(e.g. `levels/js/level-1/octocat.js`)*

2. **Specifications:**
   - Use `console.log()` to print a single greeting line.
   - The printed message must include:
     - The phrase `"Hello Open Source!"`
     - Your GitHub handle (e.g. `@<your-username>`)
     - A mention of Level 1 contribution.

---

## 💡 Example

```javascript
// Contributor: @octocat
console.log("Hello Open Source! I am @octocat and this is my JS Level 1 contribution.");
```

---

## 🧠 Pro-Tips & Common Gotchas

- 💡 **No Browser Needed:** You don't need a browser or an HTML file to run JavaScript — Node.js executes `.js` files directly from your command line.
- ⚠️ **Check Your Filename:** Make sure your file is saved as `<your-username>.js` (lowercase, matching your GitHub username).

---

## 🧪 Testing Your Solution

Open your terminal in the root of the repository and run:

```bash
node levels/js/level-1/<your-username>.js
```

### Expected Terminal Output:
```text
Hello Open Source! I am @octocat and this is my JS Level 1 contribution.
```
