## 🛠️ General Guidelines / Normas Generales

1. **File Name / Nombre del archivo:**  
   Inside each level directory, name your file with your exact GitHub username followed by `.py`:  
   `levels/python/level-X/<your-username>.py` *(e.g. `octocat.py`)*

2. **Code Quality / Calidad de código:**  
   - Follow standard Python naming conventions ([PEP 8](https://peps.python.org/pep-0008/)).
   - Include type hints when possible (`name: str -> str`).
   - Include a runnable `if __name__ == "__main__":` block with test examples.

3. **No External Dependencies / Sin dependencias externas:**  
   All challenges can be solved using the Python Standard Library only (`math`, `re`, `collections`, etc.).

> [!NOTE]
> Make sure your code runs cleanly without errors before opening a Pull Request:
> ```bash
> python levels/python/level-1/<your-username>.py
> ```
