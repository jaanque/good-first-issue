# 🟢 Level 1: Basic Selectors & Colors

Welcome to Level 1! This is the simplest possible starting point. Your goal is to write basic CSS rules to set background and text colors using element and class selectors.

---

## 🎯 Objective

Create a file named `<your-username>.css` in this directory following the styling requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/css/level-1/<your-username>.css` *(e.g. `octocat.css`)*

2. **Specifications:**
- Select the `body` element and set a `background-color` and `color`.
- Select an element with class `.welcome-card` and give it a contrasting `background-color` and `color`.

---

## 💡 Example

```css
body {
  background-color: #0f172a;
  color: #f8fafc;
}

.welcome-card {
  background-color: #1e293b;
  color: #38bdf8;
}
```

---

## 🧪 Testing your solution

Link your CSS file to an HTML document to preview your styles in a browser:

```html
<link rel="stylesheet" href="<your-username>.css">
```
