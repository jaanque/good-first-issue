## 🛠️ General Guidelines

1. **File Name:**  
   Inside each level directory, create a file named with your exact GitHub username followed by `.css`:  
   `levels/css/level-X/<your-username>.css` *(e.g. `octocat.css`)*

2. **Code Quality:**  
   - Use clean, well-indented CSS rules with consistent indentation (2 or 4 spaces).
   - Prefer semantic class names (e.g. `.profile-card`, `.btn-primary`).
   - Group related properties logically.

> [!NOTE]
> You can test your CSS by linking it to an HTML file using `<link rel="stylesheet" href="<your-username>.css">` and viewing it in any browser!
