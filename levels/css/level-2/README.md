# 🟢 Level 2: Typography & Text Styling

Welcome to Level 2! In this challenge you will control text appearance using properties like font family, size, line height, text transform, and alignment.

---

## 🎯 Objective

Create a file named `<your-username>.css` in this directory following the styling requirements below.

---

## 📋 Requirements

1. **File Location:**  
   `levels/css/level-2/<your-username>.css` *(e.g. `octocat.css`)*

2. **Specifications:**
- Set a modern font stack on `body` (e.g. `font-family: system-ui, -apple-system, sans-serif`).
- Style headings (`h1`, `h2`) with specific `font-size`, `font-weight`, and `letter-spacing`.
- Style paragraph text with a comfortable `line-height` (e.g. `1.6`) and `text-align: left` or `center`.

---

## 💡 Example

```css
body {
  font-family: system-ui, sans-serif;
  line-height: 1.6;
}

h1 {
  font-size: 2rem;
  font-weight: 700;
  letter-spacing: -0.02em;
}

p {
  font-size: 1rem;
  color: #64748b;
}
```

---

## 🧪 Testing your solution

Link your CSS file to an HTML document to preview your styles in a browser:

```html
<link rel="stylesheet" href="<your-username>.css">
```
