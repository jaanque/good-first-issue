##

É a sua primeira vez usando o Git e o GitHub? **Você está no lugar certo!**

Este repositório foi criado para ajudar você a dar os primeiros passos no mundo do **Open Source** em um ambiente seguro, sem medo de quebrar nada.

Acredito que a melhor maneira de aprender é **fazendo**, por isso criei um projeto simples que você pode facilmente modificar e melhorar.

**Sua missão é simples:** Siga o passo a passo para adicionar seu nome e foto ao projeto.

**Pronto para começar?** Vá para o **Passo 1** e vamos fazer mágica!

## 1. Faça um fork do repositório

Um **fork** é a sua própria cópia deste repositório na sua conta do GitHub. Ele permite que você faça alterações com segurança sem afetar o projeto original!

1. Vá até o canto superior direito desta página e clique no botão **Fork**:

   <br/>

   <img src="../src/image.png" alt="Botão Fork" width="400" />

   <br/>

2. Na página **Create a new fork**, deixe o nome do repositório como está e clique em **Create fork**.

3. Após alguns segundos, o GitHub irá redirecioná-lo para a sua cópia recém-criada em:

   `https://github.com/<seu-usuario>/good-first-issue`

🎉 **Incrível!** Agora você tem sua própria cópia de trabalho do projeto.

## 2. Clone o repositório

Agora você precisa baixar o repositório bifurcado para o seu computador para poder editar os arquivos localmente.

1. Na **página do seu repositório bifurcado** no GitHub, clique no botão verde "**<> Code**".
2. No menu suspenso, certifique-se de que a aba **HTTPS** esteja selecionada e clique no ícone de cópia para copiar a URL do seu repositório:

   <br/>

   <img src="../src/image2.png" alt="Clonar repositório" width="360" />

   <br/>

3. Abra seu terminal e execute o comando `git clone` seguido da URL copiada:

   ```bash
   git clone https://github.com/<seu-usuario>/good-first-issue.git
   ```

   > 💡 _Substitua `<seu-usuario>` pelo seu verdadeiro nome de usuário do GitHub!_

4. Assim que o download terminar, navegue até a pasta do projeto:

   ```bash
   cd good-first-issue
   ```

🚀 **Ótimo trabalho!** Você agora tem os arquivos do projeto no seu computador e está pronto para fazer suas alterações.

## 3. Crie uma nova branch

Antes de fazer qualquer alteração, a melhor prática é criar uma nova branch. Trabalhar em uma branch separada mantém seu trabalho organizado e deixa a branch `main` limpa.

1. No terminal (dentro da pasta `good-first-issue`), execute o comando `git switch -c` seguido do nome da sua branch:

   ```bash
   git switch -c <nome-da-sua-branch>
   ```

   _(Dê um nome descritivo, como `add-seu-nome` ou `o-nome-da-branch-que-quiser`)_

2. O Git confirmará que você criou e mudou para a nova branch:

   <br/>

   <img src="../src/image3.png" alt="Criar nova branch" width="550" />

   <br/>

   > 💡 _Dica: Se estiver usando uma versão mais antiga do Git, você também pode usar `git checkout -b <nome-da-sua-branch>`._

🌿 **Tudo pronto!** Todas as alterações que você fizer a partir de agora ficarão na sua nova branch.

## 4. Abra o projeto no seu editor de código

Agora que você tem o projeto localmente e sua branch está pronta, é hora de abri-lo no seu editor de código. Neste guia usaremos o **Visual Studio Code (VS Code)**, mas você pode usar qualquer editor de sua preferência.

Se você tem o VS Code configurado na linha de comando, basta executar o seguinte comando dentro da pasta `good-first-issue`:

```bash
code .
```

Como alternativa, você pode abri-lo manualmente:

1. Abra o **Visual Studio Code**.
2. Vá em **File** > **Open Folder...** (ou pressione `Ctrl + K, Ctrl + O` no Windows / `Cmd + O` no macOS).
3. Selecione a pasta `good-first-issue`.

Você deverá ver os arquivos do projeto no explorador:

<br/>

<img src="../src/image4.png" alt="Projeto aberto no VS Code" width="310" />

<br/>

> 💡 _Ainda não tem o VS Code instalado? Você pode baixá-lo gratuitamente em [code.visualstudio.com](https://code.visualstudio.com/)._

💻 **Tudo pronto!** Você agora tem o projeto aberto no seu editor e está pronto para começar a editar.

## 5. Adicione seu cartão de colaborador

Agora vem a parte divertida: adicionar seu próprio cartão ao projeto!

Dentro do diretório `assets/cards/`, crie um novo arquivo com o seu nome de usuário do GitHub seguido de `.json`:

📄 `assets/cards/<seu-usuario>.json` _(ex.: `octocat.json`)_

### Estrutura

Seu arquivo deve seguir exatamente a mesma estrutura de `jan.json`:

```json
{
  "name": "<seu-usuario>",
  "img": "<url-do-seu-avatar>",
  "github": "https://github.com/<seu-usuario>"
}
```

### Como obter a URL da sua foto de perfil (`img`):

1. Abra a página do seu perfil no GitHub no seu navegador (`https://github.com/<seu-usuario>`).
2. Clique com o botão direito na sua foto de perfil e selecione **"Copiar endereço da imagem"** (ou **"Copy image address"**).
3. Cole a URL copiada no campo `"img"`.

> 💡 _Dica rápida: Você também pode usar `https://github.com/<seu-usuario>.png` como a URL da sua imagem!_

### Exemplo

Se o seu nome de usuário for `octocat`, você criaria `assets/cards/octocat.json` com o seguinte conteúdo:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Salve o arquivo quando terminar. Uma vez criado, você está pronto para o próximo passo!

## 6. Faça o commit e push das suas alterações

Antes de criar a Pull Request, você precisa salvar suas alterações e enviar sua branch para o GitHub.

1. Abra o seu terminal dentro da pasta do projeto e prepare seu novo arquivo:

   ```bash
   git add assets/cards/<seu-usuario>.json
   ```

2. Faça o commit das alterações com uma mensagem curta e descritiva:

   ```bash
   git commit -m "feat: add <seu-usuario> card"
   ```

3. Envie sua branch para o seu fork no GitHub:

   ```bash
   git push origin <nome-da-sua-branch>
   ```

   > 💡 _Se solicitado, você também pode executar `git push -u origin <nome-da-sua-branch>`._

## 7. Crie a Pull Request

Agora que sua branch foi enviada para o GitHub, é hora de enviar sua contribuição para o projeto!

1. Vá para a página do seu fork no GitHub (ou visite o repositório original: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Clique no botão **"Contribute"** e selecione **"Open pull request"** (ou clique no botão **"Compare & pull request"** na faixa amarela):

   <br/>

   <img src="../src/image5.png" alt="Abrir pull request" width="450" />

   <br/>

3. Verifique se:
   - **Base repository:** `jaanque/good-first-issue` (branch `main`)
   - **Head repository:** seu fork (sua branch)
4. No título e na descrição, descreva claramente o que você modificou:
   - **Título:** Adicione um título descritivo (ex.: `Add <seu-usuario> card`).
   - **Descrição:** Escreva uma breve descrição explicando o que você modificou (ex.: que você adicionou seu cartão de colaborador em `assets/cards/<seu-usuario>.json`).
5. Clique no botão verde **Create pull request**!

### Agora basta aguardar a revisão do seu pull request. Após a revisão, se aprovado, seu cartão será adicionado automaticamente à vitrine de colaboradores.

Você pode conferir o resultado em tempo real das contribuições de todos aqui:
👉 **[Nossos Colaboradores](https://jaanque.github.io/good-first-issue/)**

##

Lembre-se, este é apenas o começo! Há milhares de projetos de código aberto esperando pela sua contribuição, e o fluxo de trabalho é essencialmente o mesmo em qualquer lugar: faça o fork do repositório, crie uma branch, faça suas alterações e envie um pull request.

## 🎉 **Parabéns!**

Você acabou de enviar sua primeira contribuição Open Source! Assim que for mesclada, seu cartão aparecerá automaticamente na vitrine de colaboradores.
