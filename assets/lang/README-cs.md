##

Je to vaše poprvé s Gitem a GitHubem? **Jste na správném místě!**

Tento repozitář je navržen tak, aby vám pomohl udělat první kroky do světa **Open Source** v bezpečném prostředí bez obav, že něco pokazíte.

Věřím, že nejlepší způsob, jak se učit, je **praxí**, proto jsem vytvořil jednoduchý projekt, který můžete snadno upravovat a vylepšovat.

**Váš úkol je jednoduchý:** Postupujte podle pokynů krok za krokem a přidejte své jméno a fotografii do projektu.

**Jste připraveni začít?** Přejděte na **Krok 1** a pojďme kouzlit!

## 1. Forkněte repozitář

**Fork** je vaše vlastní kopie tohoto repozitáře na vašem účtu GitHub. Umožňuje vám bezpečně provádět změny bez ovlivnění původního projektu!

1. Přejděte do pravého horního rohu této stránky a klikněte na tlačítko **Fork**:

   <br/>

   <img src="../src/image.png" alt="Tlačítko Fork" width="400" />

   <br/>

2. Na stránce **Create a new fork** ponechte název repozitáře tak, jak je, a klikněte na **Create fork**.

3. Po několika sekundách vás GitHub přesměruje na vaši nově vytvořenou kopii na adrese:

   `https://github.com/<vase-uzivatelske-jmeno>/good-first-issue`

🎉 **Skvělé!** Nyní máte svou vlastní pracovní kopii projektu.

## 2. Naklonujte repozitář

Nyní musíte stáhnout svůj forknutý repozitář do počítače, abyste mohli soubory upravovat lokálně.

1. Na **stránce vašeho forknutého repozitáře** na GitHubu klikněte na zelené tlačítko "**<> Code**".
2. V rozbalovací nabídce se ujistěte, že je vybrána karta **HTTPS**, a kliknutím na ikonu kopírování zkopírujte URL vašeho repozitáře:

   <br/>

   <img src="../src/image2.png" alt="Klonování repozitáře" width="360" />

   <br/>

3. Otevřete terminál a spusťte příkaz `git clone` následovaný zkopírovanou URL:

   ```bash
   git clone https://github.com/<vase-uzivatelske-jmeno>/good-first-issue.git
   ```

   > 💡 _Nahraďte `<vase-uzivatelske-jmeno>` svým skutečným uživatelským jménem na GitHubu!_

4. Po dokončení stahování přejděte do adresáře projektu:

   ```bash
   cd good-first-issue
   ```

🚀 **Dobrá práce!** Nyní máte soubory projektu na svém lokálním počítači a jste připraveni provádět změny.

## 3. Vytvořte novou větev (branch)

Před provedením jakýchkoli změn je osvědčeným postupem vytvořit novou větev. Práce v oddělené větvi udržuje vaši práci organizovanou a větev `main` čistou.

1. V terminálu (uvnitř složky `good-first-issue`) spusťte příkaz `git switch -c` s názvem vaší větve:

   ```bash
   git switch -c <nazev-vasi-vetve>
   ```

   _(Zvolte popisný název, například `add-vase-jmeno` nebo jakýkoli název chcete)_

2. Git potvrdí vytvoření a přepnutí do vaší nové větve:

   <br/>

   <img src="../src/image3.png" alt="Vytvoření nové větve" width="550" />

   <br/>

   > 💡 _Tip: Pokud používáte starší verzi Gitu, můžete použít také `git checkout -b <nazev-vasi-vetve>`._

🌿 **Vše je připraveno!** Veškeré změny, které od této chvíle provedete, zůstanou ve vaší nové větvi.

## 4. Otevřete projekt v editoru kódu

Nyní, když máte projekt lokálně a vaše větev je připravena, je čas jej otevřít v editoru kódu. V tomto návodu použijeme **Visual Studio Code (VS Code)**, ale můžete použít jakýkoli editor, který preferujete.

Pokud máte VS Code nakonfigurován v příkazovém řádku, jednoduše spusťte následující příkaz zevnitř složky `good-first-issue`:

```bash
code .
```

Případně jej můžete otevřít ručně:

1. Otevřete **Visual Studio Code**.
2. Přejděte na **Soubor** > **Otevřít složku...** (nebo stiskněte `Ctrl + K, Ctrl + O` ve Windows / `Cmd + O` na macOS).
3. Vyberte složku `good-first-issue`.

V průzkumníku byste měli vidět soubory projektu:

<br/>

<img src="../src/image4.png" alt="Projekt otevřený ve VS Code" width="310" />

<br/>

> 💡 _Ještě nemáte nainstalovaný VS Code? Můžete si jej zdarma stáhnout z [code.visualstudio.com](https://code.visualstudio.com/)._

💻 **Hotovo!** Nyní máte projekt otevřený v editoru a můžete začít upravovat.

## 5. Přidejte svou kartu přispěvatele

Nyní přichází ta zábavná část: přidání vlastní karty do projektu!

V adresáři `assets/cards/` vytvořte nový soubor se svým uživatelským jménem na GitHubu následovaným `.json`:

📄 `assets/cards/<vase-uzivatelske-jmeno>.json` _(např. `octocat.json`)_

### Struktura

Váš soubor musí mít přesně stejnou strukturu jako `jan.json`:

```json
{
  "name": "<vase-uzivatelske-jmeno>",
  "img": "<url-vaseho-avataru>",
  "github": "https://github.com/<vase-uzivatelske-jmeno>"
}
```

### Jak získat URL vaší profilové fotografie (`img`):

1. Otevřete svůj profil na GitHubu v prohlížeči (`https://github.com/<vase-uzivatelske-jmeno>`).
2. Klikněte pravým tlačítkem myši na svůj profilový obrázek a vyberte **"Kopírovat adresu obrázku"** (nebo **"Copy image address"**).
3. Vložte zkopírovanou URL do pole `"img"`.

> 💡 _Rychlý tip: Jako URL obrázku můžete použít také `https://github.com/<vase-uzivatelske-jmeno>.png`!_

### Příklad

Pokud je vaše uživatelské jméno `octocat`, vytvoříte `assets/cards/octocat.json` s následujícím obsahem:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Po dokončení soubor uložte. Jakmile je vytvořen, jste připraveni na další krok!

## 6. Proveďte commit a push vašich změn

Před vytvořením Pull Requestu musíte uložit změny a odeslat větev na GitHub.

1. Otevřete terminál v adresáři projektu a připravte nový soubor:

   ```bash
   git add assets/cards/<vase-uzivatelske-jmeno>.json
   ```

2. Potvrďte změny krátkou a výstižnou zprávou:

   ```bash
   git commit -m "feat: add <vase-uzivatelske-jmeno> card"
   ```

3. Odešlete větev do svého forku na GitHubu:

   ```bash
   git push origin <nazev-vasi-vetve>
   ```

   > 💡 _Pokud vás k tomu systém vyzve, můžete také spustit `git push -u origin <nazev-vasi-vetve>`._

## 7. Vytvořte Pull Request

Nyní, když je vaše větev na GitHubu, je čas odeslat váš příspěvek do projektu!

1. Přejděte na stránku svého forku na GitHubu (nebo navštivte původní repozitář: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Klikněte na tlačítko **"Contribute"** a vyberte **"Open pull request"** (nebo klikněte na tlačítko **"Compare & pull request"** ve žlutém pruhu):

   <br/>

   <img src="../src/image5.png" alt="Otevření pull requestu" width="450" />

   <br/>

3. Zkontrolujte, že:
   - **Base repository:** `jaanque/good-first-issue` (větev `main`)
   - **Head repository:** váš fork (vaše větev)
4. V názvu a popisu srozumitelně popište své změny:
   - **Název:** Přidejte výstižný název (např. `Add <vase-uzivatelske-jmeno> card`).
   - **Popis:** Napište stručný popis vysvětlující vaše úpravy (např. že jste přidali svou kartu přispěvatele do `assets/cards/<vase-uzivatelske-jmeno>.json`).
5. Klikněte na zelené tlačítko **Create pull request**!

### Nyní stačí počkat na kontrolu vašeho pull requestu. Po schválení bude vaše karta automaticky přidána do přehlídky přispěvatelů.

Živý výsledek příspěvků všech účastníků si můžete prohlédnout zde:
👉 **[Naši přispěvatelé](https://jaanque.github.io/good-first-issue/)**
