Kho lưu trữ này được thiết kế để giúp bạn thực hiện những bước đi đầu tiên vào thế giới **Mã nguồn mở (Open Source)** trong một môi trường an toàn, không lo sợ làm hỏng bất cứ điều gì.

Tôi tin rằng cách học tốt nhất là **thực hành**, vì vậy tôi đã tạo ra một dự án đơn giản để bạn có thể dễ dàng chỉnh sửa và cải tiến.

**Nhiệm vụ của bạn rất đơn giản:** Làm theo các hướng dẫn từng bước để thêm tên và ảnh của bạn vào dự án.

**Sẵn sàng bắt đầu chưa?** Hãy chuyển sang **Bước 1** và cùng tạo nên điều kỳ diệu nào!

## 1. FORK KHO LƯU TRỮ (REPOSITORY)

**Fork** là một bản sao của kho lưu trữ này vào tài khoản GitHub của chính bạn. Nó cho phép bạn thực hiện các thay đổi một cách an toàn mà không ảnh hưởng đến dự án gốc!

1. Di chuyển lên góc trên bên phải của trang này và nhấp vào nút **Fork**:

   <br/>

   <img src="../src/image.png" alt="Nút Fork" width="400" />

   <br/>

2. Trên trang **Create a new fork**, giữ nguyên tên kho lưu trữ và nhấp vào **Create fork**.

3. Sau vài giây, GitHub sẽ chuyển hướng bạn đến bản sao vừa được tạo tại:

   `https://github.com/<ten-nguoi-dung-cua-ban>/good-first-issue`

🎉 **Tuyệt vời!** Giờ bạn đã có bản sao làm việc của riêng mình.

## 2. CLONE (NHÂN BẢN) KHO LƯU TRỮ

Bây giờ bạn cần tải kho lưu trữ đã fork về máy tính để có thể chỉnh sửa các tệp cục bộ.

1. Trên **trang kho lưu trữ đã fork của bạn** trên GitHub, nhấp vào nút màu xanh lá "**<> Code**".
2. Trong menu thả xuống, đảm bảo tab **HTTPS** được chọn và nhấp vào biểu tượng sao chép để sao chép URL kho lưu trữ:

   <br/>

   <img src="../src/image2.png" alt="Clone kho lưu trữ" width="360" />

   <br/>

3. Mở terminal và chạy lệnh `git clone` cùng với URL bạn vừa sao chép:

   ```bash
   git clone https://github.com/<ten-nguoi-dung-cua-ban>/good-first-issue.git
   ```

> [!NOTE]
> Thay thế `<ten-nguoi-dung-cua-ban>` bằng tên người dùng GitHub thật của bạn!

4. Khi quá trình tải hoàn tất, chuyển vào thư mục dự án:

   ```bash
   cd good-first-issue
   ```

🚀 **Làm tốt lắm!** Tệp dự án hiện đã có trên máy của bạn và bạn đã sẵn sàng thực hiện thay đổi.

## 3. TẠO MỘT NHÁNH (BRANCH) MỚI

Trước khi thực hiện bất kỳ thay đổi nào, bạn nên tạo một nhánh mới. Làm việc trên một nhánh riêng biệt giúp công việc được sắp xếp gọn gàng và giữ cho nhánh `main` luôn sạch sẽ.

1. Trong terminal của bạn (bên trong thư mục `good-first-issue`), chạy lệnh `git switch -c` cùng tên nhánh của bạn:

   ```bash
   git switch -c <ten-nhanh-cua-ban>
   ```

   _(Đặt một cái tên dễ hiểu, ví dụ như `add-ten-ban` hoặc `ten-nhanh-tuy-y`)_

2. Git sẽ xác nhận rằng bạn đã tạo và chuyển sang nhánh mới:

   <br/>

   <img src="../src/image3.png" alt="Tạo nhánh mới" width="550" />

   <br/>

> [!NOTE]
> Mẹo: Nếu bạn đang dùng phiên bản Git cũ hơn, bạn cũng có thể dùng `git checkout -b <ten-nhanh-cua-ban>`.

🌿 **Đã xong!** Mọi chỉnh sửa từ giờ sẽ được lưu trên nhánh mới của bạn.

## 4. MỞ DỰ ÁN TRONG TRÌNH BIÊN TẬP MÃ

Bây giờ dự án đã có trên máy cục bộ và nhánh đã sẵn sàng, hãy mở nó trong trình biên tập mã. Trong hướng dẫn này, chúng ta sử dụng **Visual Studio Code (VS Code)**, nhưng bạn có thể dùng bất kỳ trình biên tập nào bạn thích.

Nếu bạn đã thiết lập VS Code trong dòng lệnh, chỉ cần chạy lệnh sau từ thư mục `good-first-issue`:

```bash
code .
```

Hoặc bạn có thể mở thủ công:

1. Khởi động **Visual Studio Code**.
2. Chọn **File** > **Open Folder...** (hoặc nhấn `Ctrl + K, Ctrl + O` trên Windows / `Cmd + O` trên macOS).
3. Chọn thư mục `good-first-issue`.

Bạn sẽ thấy các tệp của dự án trong trình quản lý tệp:

<br/>

<img src="../src/image4.png" alt="Dự án mở trong VS Code" width="310" />

<br/>

> [!NOTE]
> Chưa cài đặt VS Code? Bạn có thể tải miễn phí tại [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Tất cả đã sẵn sàng!** Dự án đã mở trong trình biên tập và bạn có thể bắt đầu chỉnh sửa.

## 5. THÊM THẺ NGƯỜI ĐÓNG GÓP CỦA BẠN

Bây giờ là phần thú vị nhất: thêm thẻ của riêng bạn vào dự án!

Trong thư mục `assets/cards/`, tạo một tệp mới có tên là tên người dùng GitHub của bạn kèm đuôi `.json`:

📄 `assets/cards/<ten-nguoi-dung-cua-ban>.json` _(ví dụ: `octocat.json`)_

### CẤU TRÚC

Tệp của bạn phải tuân thủ chính xác cấu trúc giống như `jan.json`:

```json
{
  "name": "<ten-nguoi-dung-cua-ban>",
  "img": "<url-anh-dai-dien-cua-ban>",
  "github": "https://github.com/<ten-nguoi-dung-cua-ban>"
}
```

### CÁCH LẤY URL ẢNH ĐẠI DIỆN (`IMG`):

1. Mở trang hồ sơ GitHub của bạn trên trình duyệt (`https://github.com/<ten-nguoi-dung-cua-ban>`).
2. Nhấp chuột phải vào ảnh hồ sơ của bạn và chọn **"Sao chép địa chỉ hình ảnh"** (hoặc **"Copy image address"**).
3. Dán URL đã sao chép vào trường `"img"`.

> [!NOTE]
> Mẹo nhỏ: Bạn cũng có thể dùng trực tiếp `https://github.com/<ten-nguoi-dung-cua-ban>.png` làm URL ảnh!

### VÍ DỤ

Nếu tên người dùng của bạn là `octocat`, bạn sẽ tạo `assets/cards/octocat.json` với nội dung sau:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Lưu tệp lại khi hoàn tất. Sau khi tạo xong, bạn đã sẵn sàng cho bước tiếp theo!

## 6. COMMIT VÀ PUSH CÁC THAY ĐỔI

Trước khi tạo Pull Request, bạn cần lưu các thay đổi và tải nhánh của bạn lên GitHub.

1. Mở terminal bên trong thư mục dự án và thêm tệp mới:

   ```bash
   git add assets/cards/<ten-nguoi-dung-cua-ban>.json
   ```

2. Commit các thay đổi với một thông điệp ngắn gọn, rõ ràng:

   ```bash
   git commit -m "feat: add <ten-nguoi-dung-cua-ban> card"
   ```

3. Đẩy (push) nhánh của bạn lên fork GitHub:

   ```bash
   git push origin <ten-nhanh-cua-ban>
   ```

> [!NOTE]
> Nếu được yêu cầu, bạn cũng có thể chạy `git push -u origin <ten-nhanh-cua-ban>`.

## 7. TẠO PULL REQUEST

Bây giờ nhánh của bạn đã được tải lên GitHub, đã đến lúc gửi đóng góp của bạn cho dự án!

1. Truy cập trang fork của bạn trên GitHub (hoặc truy cập kho lưu trữ gốc: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Nhấp vào nút **"Contribute"** và chọn **"Open pull request"** (hoặc nhấp vào nút **"Compare & pull request"** ở biểu ngữ màu vàng):

   <br/>

   <img src="../src/image5.png" alt="Mở pull request" width="450" />

   <br/>

3. Xác nhận rằng:
   - **Base repository:** `jaanque/good-first-issue` (nhánh `main`)
   - **Head repository:** fork của bạn (nhánh của bạn)
4. Trong tiêu đề và phần mô tả, hãy ghi rõ những gì bạn đã chỉnh sửa:
   - **Tiêu đề:** Thêm tiêu đề mô tả rõ ràng (ví dụ: `Add <ten-nguoi-dung-cua-ban> card`).
   - **Mô tả:** Viết mô tả ngắn giải thích những gì bạn đã thay đổi (ví dụ: bạn đã thêm thẻ người đóng góp vào `assets/cards/<ten-nguoi-dung-cua-ban>.json`).
5. Nhấp vào nút màu xanh lá **Create pull request**!
