##

Este prima dată când folosești Git și GitHub? **Ești în locul potrivit!**

Acest depozit este creat pentru a te ajuta să faci primii pași în lumea **Open Source** într-un mediu sigur, fără frica de a strica ceva.

Cred că cel mai bun mod de a învăța este **făcând**, așa că am creat un proiect simplu pe care îl poți modifica și îmbunătăți cu ușurință.

**Misiunea ta este simplă:** Urmează instrucțiunile pas cu pas pentru a-ți adăuga numele și fotografia în proiect.

**Ești gata să începi?** Mergi la **Pasul 1** și hai să facem ceva magic!

## 1. FĂ UN FORK DEPOZITULUI

Un **fork** este propria ta copie a acestui depozit în contul tău de GitHub. Îți permite să faci modificări în siguranță, fără a afecta proiectul original!

1. Mergi în colțul din dreapta-sus al acestei pagini și apasă pe butonul **Fork**:

   <br/>

   <img src="../src/image.png" alt="Buton Fork" width="400" />

   <br/>

2. Pe pagina **Create a new fork**, lasă numele neschimbat și apasă pe **Create fork**.

3. După câteva secunde, GitHub te va redirecționa către copia ta nou creată la:

   `https://github.com/<numele-tau-de-utilizator>/good-first-issue`

🎉 **Grozav!** Acum ai propria ta copie de lucru a proiectului.

## 2. CLONEAZĂ DEPOZITUL

Acum trebuie să descarci depozitul forked pe calculatorul tău pentru a putea edita fișierele local.

1. Pe **pagina depozitului tău forked** pe GitHub, apasă pe butonul verde "**<> Code**".
2. În meniul derulant, asigură-te că este selectată fila **HTTPS** și apasă pe pictograma de copiere a URL-ului:

   <br/>

   <img src="../src/image2.png" alt="Clonare depozit" width="360" />

   <br/>

3. Deschide terminalul și rulează comanda `git clone` urmată de URL-ul copiat:

   ```bash
   git clone https://github.com/<numele-tau-de-utilizator>/good-first-issue.git
   ```

> [!NOTE]
> Înlocuiește `<numele-tau-de-utilizator>` cu numele tău real de utilizator GitHub!

4. După finalizarea descărcării, intră în directorul proiectului:

   ```bash
   cd good-first-issue
   ```

🚀 **Excelent!** Fișierele sunt acum pe calculatorul tău și ești gata să faci modificări.

## 3. CREEAZĂ O RAMURĂ (BRANCH) NOUĂ

Înainte de a face orice modificare, este recomandat să creezi o ramură nouă. Lucrul pe o ramură separată păstrează ordinea și lasă ramura `main` curată.

1. În terminal (în folderul `good-first-issue`), rulează comanda `git switch -c` urmată de numele ramurii tale:

   ```bash
   git switch -c <numele-ramurii-tale>
   ```

   _(Alege un nume sugestiv, cum ar fi `add-numele-tau` sau `numele-ramurii-dorite`)_

2. Git va confirma că ai creat și ai comutat pe noua ramură:

   <br/>

   <img src="../src/image3.png" alt="Creare ramură nouă" width="550" />

   <br/>

> [!NOTE]
> Sfat: Dacă folosești o versiune mai veche de Git, poți folosi comanda `git checkout -b <numele-ramurii-tale>`.

🌿 **Totul este gata!** Orice modificare pe care o faci de acum înainte va rămâne pe noua ta ramură.

## 4. DESCHIDE PROIECTUL ÎN EDITORUL DE COD

Acum că ai proiectul local și ramura este gata, este timpul să-l deschizi în editorul de cod. În acest ghid vom folosi **Visual Studio Code (VS Code)**, dar poți folosi orice editor preferi.

Dacă ai configurat VS Code în linia de comandă, rulează pur și simplu următoarea comandă din folderul `good-first-issue`:

```bash
code .
```

Alternativ, îl poți deschide manual:

1. Pornește **Visual Studio Code**.
2. Mergi la **File** > **Open Folder...** (sau apasă `Ctrl + K, Ctrl + O` pe Windows / `Cmd + O` pe macOS).
3. Selectează folderul `good-first-issue`.

Vei vedea fișierele proiectului în explorator:

<br/>

<img src="../src/image4.png" alt="Proiect deschis în VS Code" width="310" />

<br/>

> [!NOTE]
> Nu ai încă instalat VS Code? Îl poți descărca gratuit de pe [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Gata!** Proiectul este deschis în editor și ești pregătit să începi editarea.

## 5. ADAUGĂ CARDUL TĂU DE COLABORATOR

Acum urmează partea distractivă: adăugarea propriului tău card în proiect!

În directorul `assets/cards/`, creează un fișier nou cu numele tău de utilizator GitHub urmat de `.json`:

📄 `assets/cards/<numele-tau-de-utilizator>.json` _(ex. `octocat.json`)_

### STRUCTURĂ

Fișierul tău trebuie să respecte exact aceeași structură ca `jan.json`:

```json
{
  "name": "<numele-tau-de-utilizator>",
  "img": "<url-ul-avatarului-tau>",
  "github": "https://github.com/<numele-tau-de-utilizator>"
}
```

### CUM OBȚII URL-UL IMAGINII TALE DE PROFIL (`IMG`):

1. Deschide pagina de profil GitHub în browser (`https://github.com/<numele-tau-de-utilizator>`).
2. Fă clic dreapta pe poza ta de profil și alege **"Copy image address"** (Copiază adresa imaginii).
3. Lipește acel URL în câmpul `"img"`.

> [!NOTE]
> Truc rapid: Poți folosi direct `https://github.com/<numele-tau-de-utilizator>.png` ca URL al imaginii!

### EXEMPLU

Dacă numele tău de utilizator este `octocat`, vei crea fișierul `assets/cards/octocat.json` cu următorul conținut:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Salvează fișierul după ce ai terminat. Ești pregătit pentru pasul următor!

## 6. FĂ COMMIT ȘI PUSH MODIFICĂRILOR TALE

Înainte de a crea un Pull Request, trebuie să salvezi modificările și să încarci ramura pe GitHub.

1. Deschide terminalul în directorul proiectului și adaugă noul fișier:

   ```bash
   git add assets/cards/<numele-tau-de-utilizator>.json
   ```

2. Înregistrează modificările (commit) cu un mesaj scurt și clar:

   ```bash
   git commit -m "feat: add <numele-tau-de-utilizator> card"
   ```

3. Încarcă (push) ramura ta pe fork-ul tău de GitHub:

   ```bash
   git push origin <numele-ramurii-tale>
   ```

> [!NOTE]
> Dacă ți se solicită, poți rula și `git push -u origin <numele-ramurii-tale>`.

## 7. CREEAZĂ UN PULL REQUEST

Acum că ramura ta este încărcată pe GitHub, este timpul să trimiți contribuția ta la proiect!

1. Mergi la pagina fork-ului tău pe GitHub (sau vizitează depozitul original: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Apasă pe butonul **"Contribute"** și selectează **"Open pull request"** (sau apasă pe butonul **"Compare & pull request"** din bara galbenă):

   <br/>

   <img src="../src/image5.png" alt="Deschidere pull request" width="450" />

   <br/>

3. Asigură-te că:
   - **Base repository:** `jaanque/good-first-issue` (ramura `main`)
   - **Head repository:** fork-ul tău (ramura ta)
4. În titlu și descriere, explică clar ce modificări ai făcut:
   - **Titlu:** Adaugă un titlu descriptiv (ex. `Add <numele-tau-de-utilizator> card`).
   - **Descriere:** Scrie o scurtă descriere explicând ce ai schimbat (ex. că ai adăugat cardul tău în `assets/cards/<numele-tau-de-utilizator>.json`).
5. Apasă pe butonul verde **Create pull request**!
