##

Czy to Twój pierwszy raz z Git i GitHub? **Trafiłeś w idealne miejsce!**

To repozytorium zostało stworzone, aby pomóc Ci postawić pierwsze kroki w świecie **Open Source** w bezpiecznym środowisku, bez obawy, że cokolwiek zepsujesz.

Uważam, że najlepszym sposobem na naukę jest **praktyka**, dlatego przygotowałem prosty projekt, który możesz z łatwością modyfikować i ulepszać.

**Twoja misja jest prosta:** Postępuj zgodnie z instrukcjami krok po kroku, aby dodać swoje imię i zdjęcie do projektu.

**Gotowy do startu?** Przejdź do **Kroku 1** i zacznijmy przygodę!

## 1. SFORKUJ REPOZYTORIUM

**Fork** to Twoja własna kopia tego repozytorium na Twoim koncie GitHub. Pozwala na bezpieczne wprowadzanie zmian bez wpływu na oryginalny projekt!

1. Przejdź do prawego górnego rogu tej strony i kliknij przycisk **Fork**:

   <br/>

   <img src="../src/image.png" alt="Przycisk Fork" width="400" />

   <br/>

2. Na stronie **Create a new fork** pozostaw nazwę repozytorium bez zmian i kliknij **Create fork**.

3. Po kilku sekundach GitHub przekieruje Cię do nowo utworzonej kopii pod adresem:

   `https://github.com/<twoja-nazwa-uzytkownika>/good-first-issue`

🎉 **Wspaniale!** Masz teraz własną roboczą kopię projektu.

## 2. SKLONUJ REPOZYTORIUM

Teraz musisz pobrać sforkowane repozytorium na swój komputer, aby móc edytować pliki lokalnie.

1. Na **stronie Twojego sforkowanego repozytorium** na GitHubie kliknij zielony przycisk "**<> Code**".
2. W menu rozwijanym upewnij się, że wybrana jest zakładka **HTTPS**, i kliknij ikonę kopiowania, aby skopiować adres URL repozytorium:

   <br/>

   <img src="../src/image2.png" alt="Klonowanie repozytorium" width="360" />

   <br/>

3. Otwórz terminal i uruchom polecenie `git clone`, podając skopiowany adres URL:

   ```bash
   git clone https://github.com/<twoja-nazwa-uzytkownika>/good-first-issue.git
   ```

   > [!IMPORTANT]
   > Zastąp `<twoja-nazwa-uzytkownika>` swoją rzeczywistą nazwą użytkownika na GitHubie!

4. Po zakończeniu pobierania przejdź do katalogu projektu:

   ```bash
   cd good-first-issue
   ```

🚀 **Dobra robota!** Masz pliki projektu na swoim lokalnym komputerze i możesz przystąpić do zmian.

## 3. UTWÓRZ NOWĄ GAŁĄŹ (BRANCH)

Zanim dokonasz jakichkolwiek zmian, dobrą praktyką jest utworzenie nowej gałęzi. Praca na osobnej gałęzi pozwala zachować porządek i pozostawia gałąź `main` czystą.

1. W terminalu (wewnątrz folderu `good-first-issue`) uruchom polecenie `git switch -c` wraz z nazwą nowej gałęzi:

   ```bash
   git switch -c <nazwa-twojej-galezi>
   ```

   _(Nadaj jej opisową nazwę, np. `add-twoje-imie` lub `dowolna-nazwa-galezi`)_

2. Git potwierdzi utworzenie nowej gałęzi i przełączenie na nią:

   <br/>

   <img src="../src/image3.png" alt="Tworzenie nowej gałęzi" width="550" />

   <br/>

   > [!TIP]
   > Wskazówka: Jeśli używasz starszej wersji Gita, możesz również użyć `git checkout -b <nazwa-twojej-galezi>`.

🌿 **Wszystko gotowe!** Wszelkie zmiany od tej pory będą zapisywane na Twojej nowej gałęzi.

## 4. OTWÓRZ PROJEKT W EDYTORZE KODU

Teraz, gdy masz projekt lokalnie, a gałąź jest gotowa, czas otworzyć go w edytorze kodu. W tym poradniku korzystamy z **Visual Studio Code (VS Code)**, ale możesz użyć dowolnego edytora.

Jeśli masz skonfigurowany VS Code w wierszu poleceń, po prostu uruchom następujące polecenie z folderu `good-first-issue`:

```bash
code .
```

Możesz go również otworzyć ręcznie:

1. Uruchom **Visual Studio Code**.
2. Wybierz **File** > **Open Folder...** (lub naciśnij `Ctrl + K, Ctrl + O` w systemie Windows / `Cmd + O` w systemie macOS).
3. Wybierz folder `good-first-issue`.

W eksploratorze powinieneś zobaczyć pliki projektu:

<br/>

<img src="../src/image4.png" alt="Projekt otwarty w VS Code" width="310" />

<br/>

> [!NOTE]
> Nie masz jeszcze zainstalowanego VS Code? Możesz pobrać go bezpłatnie ze strony [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Gotowe!** Projekt jest otwarty w edytorze i możesz przystąpić do edycji.

## 5. DODAJ SWOJĄ KARTĘ WSPÓŁTWÓRCY

Teraz najprzyjemniejsza część: dodanie własnej karty do projektu!

W katalogu `assets/cards/` utwórz nowy plik o nazwie będącej Twoją nazwą użytkownika na GitHubie z rozszerzeniem `.json`:

📄 `assets/cards/<twoja-nazwa-uzytkownika>.json` _(np. `octocat.json`)_

### STRUKTURA

Twój plik musi mieć dokładnie taką samą strukturę jak `jan.json`:

```json
{
  "name": "<twoja-nazwa-uzytkownika>",
  "img": "<url-twojego-awatara>",
  "github": "https://github.com/<twoja-nazwa-uzytkownika>"
}
```

### JAK POBRAĆ ADRES URL ZDJĘCIA PROFILOWEGO (`IMG`):

1. Otwórz stronę swojego profilu na GitHubie w przeglądarce (`https://github.com/<twoja-nazwa-uzytkownika>`).
2. Kliknij prawym przyciskiem myszy na swoje zdjęcie profilowe i wybierz **"Kopiuj adres obrazu"** (lub **"Copy image address"**).
3. Wklej skopiowany adres URL w polu `"img"`.

> [!TIP]
> Szybka sztuczka: Jako URL zdjęcia możesz także użyć `https://github.com/<twoja-nazwa-uzytkownika>.png`!

### PRZYKŁAD

Jeśli Twoja nazwa użytkownika to `octocat`, tworzysz plik `assets/cards/octocat.json` o następującej zawartości:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Zapisz plik po zakończeniu edycji. Po jego utworzeniu możesz przejść do kolejnego kroku!

## 6. ZATWIERDŹ I WYŚLIJ ZMIANY (COMMIT & PUSH)

Przed utworzeniem Pull Requesta musisz zapisać zmiany i wysłać swoją gałąź na GitHuba.

1. Otwórz terminal w katalogu projektu i dodaj nowy plik do stagingu:

   ```bash
   git add assets/cards/<twoja-nazwa-uzytkownika>.json
   ```

2. Zatwierdź zmiany z krótkim, czytelnym komunikatem:

   ```bash
   git commit -m "feat: add <twoja-nazwa-uzytkownika> card"
   ```

3. Wyślij swoją gałąź do swojego forka na GitHubie:

   ```bash
   git push origin <nazwa-twojej-galezi>
   ```

   > [!NOTE]
   > W razie potrzeby możesz także użyć `git push -u origin <nazwa-twojej-galezi>`.

## 7. UTWÓRZ PULL REQUEST

Gdy Twoja gałąź znajduje się już na GitHubie, czas zgłosić swój wkład do projektu!

1. Przejdź do strony swojego forka na GitHubie (lub odwiedź oryginalne repozytorium: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Kliknij przycisk **"Contribute"** i wybierz **"Open pull request"** (lub kliknij przycisk **"Compare & pull request"** na żółtym pasku):

   <br/>

   <img src="../src/image5.png" alt="Otwórz pull request" width="450" />

   <br/>

3. Sprawdź, czy:
   - **Base repository:** `jaanque/good-first-issue` (gałąź `main`)
   - **Head repository:** Twój fork (Twoja gałąź)
4. W tytule i opisie dokładnie określ, co zostało zmienione:
   - **Tytuł:** Wpisz opisowy tytuł (np. `Add <twoja-nazwa-uzytkownika> card`).
   - **Opis:** Napisz krótki opis wyjaśniający zmiany (np. że dodałeś swoją kartę współtwórcy w `assets/cards/<twoja-nazwa-uzytkownika>.json`).
5. Kliknij zielony przycisk **Create pull request**!
