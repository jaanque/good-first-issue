##

这是你第一次使用 Git 和 GitHub 吗？**那你来对地方了！**

本仓库旨在帮助你在一个安全、不用担心损坏任何东西的环境中，迈出进入 **开源（Open Source）** 世界的第一步。

我相信最好的学习方式就是**边做边学**，因此我创建了一个简单的项目，你可以轻松地对其进行修改和改进。

**你的任务很简单：** 按照逐步指南，将你的名字和照片添加到项目中。

**准备好开始了吗？** 前往**第 1 步**，让我们一起创造精彩！

## 基础工具

在开始之前，请确保你已准备好以下基本工具：

## 1. Fork（分叉）本仓库

**Fork** 是将该仓库完整复制到你的 GitHub 账号下。它可以让你安全地进行修改，而不会影响原始项目！

1. 前往本页面右上角，点击 **Fork** 按钮：

   <br/>

   <img src="../src/image.png" alt="Fork 按钮" width="400" />

   <br/>

2. 在 **Create a new fork** 页面上，保持仓库名称不变，点击 **Create fork**。

3. 几秒钟后，GitHub 会将你重定向到新创建的副本：

   `https://github.com/<你的用户名>/good-first-issue`

🎉 **太棒了！** 你现在拥有了属于自己的项目副本。

## 2. 克隆（Clone）仓库

现在你需要将 Fork 后的仓库下载到本地电脑上，以便在本地编辑文件。

1. 在 GitHub 上的**你的 Fork 仓库页面**，点击绿色的 "**<> Code**" 按钮。
2. 在下拉菜单中，确保选中 **HTTPS** 标签页，然后点击复制图标复制你的仓库链接：

   <br/>

   <img src="../src/image2.png" alt="克隆仓库" width="360" />

   <br/>

3. 打开终端并运行 `git clone` 命令，后面附上刚复制的 URL：

   ```bash
   git clone https://github.com/<你的用户名>/good-first-issue.git
   ```

   > 💡 _请将 `<你的用户名>` 替换为你真实的 GitHub 用户名！_

4. 下载完成后，进入项目目录：

   ```bash
   cd good-first-issue
   ```

🚀 **干得漂亮！** 项目文件现已保存到你的本地电脑中，随时可以开始修改。

## 3. 创建新分支（Branch）

在进行任何修改之前，创建新分支是最佳实践。在独立的分支上工作能保持代码条理清晰，并确保 `main` 主分支不受影响。

1. 在终端中（位于 `good-first-issue` 文件夹内），运行 `git switch -c` 命令并跟上你的分支名称：

   ```bash
   git switch -c <你的分支名称>
   ```

   _（请起一个具有描述性的名称，如 `add-你的名字` 或 `你想要的分支名`）_

2. Git 会确认你已创建并切换到新分支：

   <br/>

   <img src="../src/image3.png" alt="创建新分支" width="550" />

   <br/>

   > 💡 _提示：如果你使用的是较旧版本的 Git，也可以使用 `git checkout -b <你的分支名称>`。_

🌿 **准备就绪！** 从现在开始，你所做的所有更改都会保存在新分支中。

## 4. 在代码编辑器中打开项目

现在项目已下载到本地且分支已就绪，是时候在代码编辑器中打开它了。本指南中我们使用 **Visual Studio Code (VS Code)**，但你也可以使用任何喜欢的编辑器。

如果你已将 VS Code 配置到命令行中，只需在 `good-first-issue` 文件夹内运行：

```bash
code .
```

或者，你也可以手动打开：

1. 启动 **Visual Studio Code**。
2. 前往 **File** > **Open Folder...**（在 Windows 上按 `Ctrl + K, Ctrl + O` / 在 macOS 上按 `Cmd + O`）。
3. 选择 `good-first-issue` 文件夹。

你可以在资源管理器中看到项目文件：

<br/>

<img src="../src/image4.png" alt="在 VS Code 中打开项目" width="310" />

<br/>

> 💡 _还没有安装 VS Code？可以前往 [code.visualstudio.com](https://code.visualstudio.com/) 免费下载。_

💻 **搞定！** 项目已在编辑器中打开，你可以开始编辑了。

## 5. 添加你的贡献者卡片

接下来是最有趣的部分：向项目中添加你自己的卡片！

在 `assets/cards/` 目录下，创建一个以你的 GitHub 用户名命名并以 `.json` 结尾的新文件：

📄 `assets/cards/<你的用户名>.json` _（例如 `octocat.json`）_

### 结构

你的文件必须遵循与 `jan.json` 完全相同的结构：

```json
{
  "name": "<你的用户名>",
  "img": "<你的头像链接>",
  "github": "https://github.com/<你的用户名>"
}
```

### 如何获取你的个人资料头像链接 (`img`)：

1. 在浏览器中打开你的 GitHub 个人主页（`https://github.com/<你的用户名>`）。
2. 在个人头像上右键点击，选择 **"复制图片地址"**（或 **"Copy image address"**）。
3. 将复制的 URL 粘贴到 `"img"` 字段中。

> 💡 _小技巧：你也可以直接使用 `https://github.com/<你的用户名>.png` 作为头像链接！_

### 示例

如果你的用户名是 `octocat`，则创建 `assets/cards/octocat.json`，内容如下：

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

完成后保存文件。创建好文件后，就可以进入下一步了！

## 6. 提交（Commit）并推送（Push）你的更改

在创建 Pull Request 之前，需要保存更改并将分支推送到 GitHub。

1. 在项目目录中打开终端，暂存你的新文件：

   ```bash
   git add assets/cards/<你的用户名>.json
   ```

2. 提交更改，并附上一段简短清晰的说明：

   ```bash
   git commit -m "feat: add <你的用户名> card"
   ```

3. 将分支推送到你的 GitHub Fork 仓库：

   ```bash
   git push origin <你的分支名称>
   ```

   > 💡 _如果系统提示，你也可以运行 `git push -u origin <你的分支名称>`。_

## 7. 创建 Pull Request

现在分支已推送到 GitHub，是时候向项目提交你的贡献了！

1. 前往 GitHub 上你的 Fork 页面（或访问原仓库：[jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)）。
2. 点击 **"Contribute"** 按钮并选择 **"Open pull request"**（或者点击黄色横幅中的 **"Compare & pull request"** 按钮）：

   <br/>

   <img src="../src/image5.png" alt="创建 Pull Request" width="450" />

   <br/>

3. 确认以下信息：
   - **Base repository:** `jaanque/good-first-issue`（分支 `main`）
   - **Head repository:** 你的 fork（你的分支）
4. 在标题和描述中，清晰说明你的修改：
   - **标题：** 添加一个描述性标题（例如 `Add <你的用户名> card`）。
   - **描述：** 写一段简短说明，解释你修改了什么（例如在 `assets/cards/<你的用户名>.json` 中添加了贡献者卡片）。
5. 点击绿色的 **Create pull request** 按钮！

### 现在只需等待你的 Pull Request 审核即可。通过审核并合并后，你的卡片将自动添加到贡献者展示墙中。

你可以在这里实时查看大家的贡献成果：
👉 **[我们的贡献者](https://jaanque.github.io/good-first-issue/)**
