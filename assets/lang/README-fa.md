**ماموریت شما بسیار ساده است:** دستورالعمل‌های گام‌به‌گام را دنبال کنید تا نام و عکس خود را به پروژه اضافه کنید.

## ۱. مخزن را فورک (FORK) کنید

یک **فورک** کپی اختصاصی شما از این مخزن در حساب کاربری GitHub شماست. این کار به شما امکان می‌دهد بدون تأثیر بر پروژه اصلی، با خیالی آسوده تغییرات دلخواه را ایجاد کنید!

۱. به گوشه بالا سمت راست این صفحه بروید و روی دکمه **Fork** کلیک کنید:

   <br/>

   <img src="../src/image.png" alt="دکمه Fork" width="400" />

   <br/>

۲. در صفحه **Create a new fork**، نام مخزن را تغییر ندهید و روی **Create fork** کلیک کنید.

۳. پس از چند ثانیه، GitHub شما را به کپی جدیدتان هدایت می‌کند:

   `https://github.com/<نام-کاربری-شما>/good-first-issue`

🎉 **عالی شد!** اکنون شما کپی اختصاصی خود از این پروژه را دارید.

## ۲. مخزن را کلون (CLONE) کنید

اکنون باید مخزن فورک‌شده را در رایانه خود دانلود کنید تا بتوانید فایل‌ها را به صورت محلی ویرایش نمایید.

۱. در **صفحه مخزن فورک‌شده خود** در GitHub، روی دکمه سبز رنگ "**<> Code**" کلیک کنید.
۲. در منوی بازشده، مطمئن شوید که برگه **HTTPS** انتخاب شده است و روی نماد کپی کلیک کنید تا آدرس مخزن کپی شود:

   <br/>

   <img src="../src/image2.png" alt="کلون مخزن" width="360" />

   <br/>

۳. ترمینال خود را باز کرده و دستور `git clone` را به همراه آدرسی که کپی کرده‌اید اجرا کنید:

   ```bash
   git clone https://github.com/<نام-کاربری-شما>/good-first-issue.git
   ```

> [!NOTE]
> به جای `<نام-کاربری-شما>` نام کاربری واقعی خود در GitHub را وارد کنید!

۴. پس از اتمام دانلود، وارد پوشه پروژه شوید:

   ```bash
   cd good-first-issue
   ```

🚀 **آفرین!** فایل‌های پروژه اکنون در رایانه شما قرار دارند و آماده اعمال تغییرات هستید.

## ۳. یک شاخه (BRANCH) جدید بسازید

پیش از اعمال هرگونه تغییر، بهترین روش ایجاد یک شاخه جدید است. کار در یک شاخه جداگانه به کارهای شما نظم می‌دهد و شاخه اصلی `main` را پاکیزه نگه می‌دارد.

۱. در ترمینال خود (داخل پوشه `good-first-issue`)، دستور `git switch -c` را به همراه نام شاخه جدید اجرا کنید:

   ```bash
   git switch -c <نام-شاخه-شما>
   ```

   _(نامی واضح انتخاب کنید، مانند `add-نام-شما` یا `نام-شاخه-دلخواه`)_

۲. گیت تأیید می‌کند که شاخه جدید ایجاد شده و به آن منتقل شده‌اید:

   <br/>

   <img src="../src/image3.png" alt="ایجاد شاخه جدید" width="550" />

   <br/>

> [!NOTE]
> نکته: اگر از نسخه‌های قدیمی‌تر Git استفاده می‌کنید، می‌توانید از `git checkout -b <نام-شاخه-شما>` نیز استفاده کنید.

🌿 **همه چیز آماده است!** از این پس هر تغییری که ایجاد کنید در این شاخه جدید ذخیره خواهد شد.

## ۴. پروژه را در ویرایشگر کد خود باز کنید

اکنون که پروژه را در رایانه خود دارید و شاخه شما آماده است، وقت آن رسیده که آن را در ویرایشگر کد باز کنید. در این راهنما از **Visual Studio Code (VS Code)** استفاده می‌کنیم، اما شما می‌توانید از هر ویرایشگری که ترجیح می‌دهید استفاده کنید.

اگر VS Code در خط فرمان شما پیکربندی شده باشد، کافیست دستور زیر را از داخل پوشه `good-first-issue` اجرا کنید:

```bash
code .
```

یا می‌توانید آن را به صورت دستی باز کنید:

۱. نرم‌افزار **Visual Studio Code** را باز کنید.
۲. به **File** > **Open Folder...** بروید (یا `Ctrl + K, Ctrl + O` در ویندوز / `Cmd + O` در مک را فشار دهید).
۳. پوشه `good-first-issue` را انتخاب کنید.

فایل‌های پروژه را در پنل کاوشگر مشاهده خواهید کرد:

<img src="../src/image4.png" alt="پروژه در VS Code" width="310" />

💻 **آماده است!** پروژه اکنون در ویرایشگر باز است و می‌توانید ویرایش را آغاز کنید.

## ۵. کارت مشارکت‌کننده خود را اضافه کنید

اکنون به جذاب‌ترین بخش رسیده‌ایم: افزودن کارت اختصاصی شما به پروژه!

در پوشه `assets/cards/` یک فایل جدید با نام کاربری GitHub خود و پسوند `.json` ایجاد کنید:

📄 `assets/cards/<نام-کاربری-شما>.json` _(مثال: `octocat.json`)_

### ساختار

فایل شما باید دقیقاً از همان ساختار `jan.json` پیروی کند:

```json
{
  "name": "<نام-کاربری-شما>",
  "img": "<آدرس-تصویر-پروفایل-شما>",
  "github": "https://github.com/<نام-کاربری-شما>"
}
```

### نحوه دریافت آدرس تصویر پروفایل (`IMG`):

۱. صفحه پروفایل GitHub خود را در مرورگر باز کنید (`https://github.com/<نام-کاربری-شما>`).
۲. روی تصویر پروفایل خود راست کلیک کرده و گزینه **"Copy image address"** (کپی آدرس تصویر) را انتخاب کنید.
۳. آن آدرس کپی‌شده را در فیلد `"img"` جای‌گذاری کنید.

> [!NOTE]
> ترفند سریع: می‌توانید مستقیماً از `https://github.com/<نام-کاربری-شما>.png` نیز به عنوان آدرس تصویر استفاده کنید!

### مثال

اگر نام کاربری شما `octocat` باشد، فایل `assets/cards/octocat.json` را با محتوای زیر می‌سازید:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

پس از اتمام کار، فایل را ذخیره کنید. با ایجاد فایل، آماده گام بعدی هستید!

## ۶. تغییرات خود را COMMIT و PUSH کنید

پیش از ایجاد Pull Request، باید تغییرات خود را ذخیره کرده و شاخه خود را به GitHub بفرستید.

۱. ترمینال را در پوشه پروژه باز کنید و فایل جدید را آماده ثبت کنید:

   ```bash
   git add assets/cards/<نام-کاربری-شما>.json
   ```

۲. تغییرات را با یک پیام کوتاه و مشخص ثبت (Commit) کنید:

   ```bash
   git commit -m "feat: add <نام-کاربری-شما> card"
   ```

۳. شاخه خود را به فورک گیت‌هاب خود ارسال (Push) کنید:

   ```bash
   git push origin <نام-شاخه-شما>
   ```

> [!NOTE]
> در صورت لزوم، می‌توانید دستور `git push -u origin <نام-شاخه-شما>` را نیز اجرا کنید.

## ۷. یک PULL REQUEST ایجاد کنید

اکنون که شاخه شما در GitHub آپلود شده است، زمان ارسال مشارکت شما به پروژه فرا رسیده است!

۱. به صفحه فورک خود در GitHub بروید (یا به مخزن اصلی مراجعه کنید: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
۲. روی دکمه **"Contribute"** کلیک کرده و **"Open pull request"** را انتخاب کنید (یا روی دکمه **"Compare & pull request"** در نوار زرد رنگ کلیک کنید):

   <br/>

   <img src="../src/image5.png" alt="باز کردن pull request" width="450" />

   <br/>

۳. بررسی کنید که:
   - **Base repository:** `jaanque/good-first-issue` (شاخه `main`)
   - **Head repository:** فورک شما (شاخه شما)
۴. در عنوان و توضیحات به طور شفاف بنویسید که چه تغییری ایجاد کرده‌اید:
   - **عنوان:** یک عنوان مشخص بنویسید (مثال: `Add <نام-کاربری-شما> card`).
   - **توضیحات:** متنی کوتاه در مورد تغییرات خود بنویسید (مثال: افزودن کارت مشارکت در `assets/cards/<نام-کاربری-شما>.json`).
۵. روی دکمه سبز رنگ **Create pull request** کلیک کنید!

### اکنون فقط منتظر بررسی درخواست شما بمانید. پس از بررسی و تایید، کارت شما به صورت خودکار به ویترین مشارکت‌کنندگان افزوده می‌شود.
