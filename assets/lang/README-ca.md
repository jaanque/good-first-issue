##

És el teu primer cop fent servir Git i GitHub? **Ets al lloc correcte!**

Aquest repositori està dissenyat per ajudar-te a fer les teves primeres passes en el món de l'**Open Source** en un entorn segur, sense por de trencar res.

Crec que la millor manera d'aprendre és **fent**, així que he creat un projecte senzill que pots modificar i millorar fàcilment.

**La teva missió és simple:** Segueix les instruccions pas a pas per afegir el teu nom i la teva foto al projecte.

**A punt per començar?** Ves al **Pas 1** i fem una mica de màgia!

## 1. FES UN FORK DEL REPOSITORI

Un **fork** és la teva pròpia còpia d'aquest repositori al teu compte de GitHub. Et permet fer canvis amb seguretat sense afectar el projecte original!

1. Ves a la cantonada superior dreta d'aquesta pàgina i fes clic al botó **Fork**:

   <br/>

   <img src="../src/image.png" alt="Botó Fork" width="400" />

   <br/>

2. A la pàgina **Create a new fork**, deixa el nom del repositori tal com està i fes clic a **Create fork**.

3. Després d'uns segons, GitHub et redirigirà a la teva còpia acabada de crear a:

   `https://github.com/<el-teu-usuari>/good-first-issue`

🎉 **Genial!** Ara ja tens la teva pròpia còpia de treball del projecte.

## 2. CLONA EL REPOSITORI

Ara has de descarregar el repositori forkejat al teu ordinador per poder editar els fitxers localment.

1. A **la pàgina del teu repositori forkejat** a GitHub, fes clic al botó verd "**<> Code**".
2. Al menú desplegable, assegura't que la pestanya **HTTPS** estigui seleccionada i fes clic a la icona de copiar per copiar l'URL del teu repositori:

   <br/>

   <img src="../src/image2.png" alt="Clonar repositori" width="360" />

   <br/>

3. Obre la teva terminal i executa l'ordre `git clone` seguida de l'URL que has copiat:

   ```bash
   git clone https://github.com/<el-teu-usuari>/good-first-issue.git
   ```

> [!NOTE]
> Substitueix `<el-teu-usuari>` pel teu nom d'usuari real de GitHub!

4. Un cop completada la descàrrega, entra al directori del projecte:

   ```bash
   cd good-first-issue
   ```

🚀 **Bona feina!** Ja tens els fitxers del projecte a la teva màquina local i estàs a punt per fer els teus canvis.

## 3. CREA UNA NOVA BRANCA (BRANCH)

Abans de fer cap canvi, és una bona pràctica crear una nova branca. Treballar en una branca separada manté la teva feina organitzada i deixa la branca `main` neta.

1. A la teva terminal (dins de la carpeta `good-first-issue`), executa l'ordre `git switch -c` seguida del nom de la teva branca:

   ```bash
   git switch -c <nom-de-la-teva-branca>
   ```

   _(Posa-li un nom descriptiu, com ara `add-el-teu-nom` o `el-nom-de-branca-que-vulguis`)_

2. Git et confirmarà que has creat i canviat a la teva nova branca:

   <br/>

   <img src="../src/image3.png" alt="Crear nova branca" width="550" />

   <br/>

> [!NOTE]
> Consell: Si fas servir una versió més antiga de Git, també pots utilitzar `git checkout -b <nom-de-la-teva-branca>`.

🌿 **Tot a punt!** Qualsevol canvi que facis a partir d'ara es mantindrà a la teva nova branca.

## 4. OBRE EL PROJECTE AL TEU EDITOR DE CODI

Ara que tens el projecte localment i la teva branca està a punt, és hora d'obrir-lo al teu editor de codi. En aquesta guia farem servir **Visual Studio Code (VS Code)**, però pots fer servir l'editor que prefereixis.

Si tens VS Code configurat a la teva línia d'ordres, simplement executa la següent comanda des de la carpeta `good-first-issue`:

```bash
code .
```

Com a alternativa, pots obrir-lo manualment:

1. Obre **Visual Studio Code**.
2. Ves a **File** > **Open Folder...** (o prem `Ctrl + K, Ctrl + O` a Windows / `Cmd + O` a macOS).
3. Selecciona la carpeta `good-first-issue`.

Hauries de veure els fitxers del projecte a l'explorador:

<br/>

<img src="../src/image4.png" alt="Projecte obert a VS Code" width="310" />

<br/>

> [!NOTE]
> Encara no tens instal·lat VS Code? El pots descarregar gratuïtament des de [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Llest!** Ja tens el projecte obert al teu editor i estàs preparat per començar a editar.

## 5. AFEGEIX LA TEVA TARGETA DE COL·LABORADOR

Ara arriba la part divertida: afegir la teva pròpia targeta al projecte!

Dins del directori `assets/cards/`, crea un nou fitxer anomenat amb el teu nom d'usuari de GitHub seguit de `.json`:

📄 `assets/cards/<el-teu-usuari>.json` _(ex. `octocat.json`)_

### ESTRUCTURA

El teu fitxer ha de seguir exactament la mateixa estructura que `jan.json`:

```json
{
  "name": "<el-teu-usuari>",
  "img": "<url-del-teu-avatar>",
  "github": "https://github.com/<el-teu-usuari>"
}
```

### COM OBTENIR L'URL DE LA TEVA FOTO DE PERFIL (`IMG`):

1. Obre el teu perfil de GitHub al teu navegador (`https://github.com/<el-teu-usuari>`).
2. Fes clic dret a la teva foto de perfil i selecciona **"Copia l'adreça de la imatge"** (o **"Copy image address"**).
3. Enganxa aquest URL al camp `"img"`.

> [!NOTE]
> Truc ràpid: També pots fer servir `https://github.com/<el-teu-usuari>.png` com a URL de la teva imatge!

### EXEMPLE

Si el teu nom d'usuari és `octocat`, crearies `assets/cards/octocat.json` amb el següent contingut:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Desa el fitxer quan acabis. Un cop creat, ja estàs a punt per al següent pas!

## 6. FES COMMIT I PUSH DELS TEUS CANVIS

Abans de crear el Pull Request, has de desar els teus canvis i pujar la teva branca a GitHub.

1. Obre la teva terminal dins del directori del projecte i prepara el teu nou fitxer:

   ```bash
   git add assets/cards/<el-teu-usuari>.json
   ```

2. Fes commit dels canvis amb un missatge curt i descriptiu:

   ```bash
   git commit -m "feat: add <el-teu-usuari> card"
   ```

3. Puja la teva branca al teu fork de GitHub:

   ```bash
   git push origin <nom-de-la-teva-branca>
   ```

> [!NOTE]
> Si t'ho demana, també pots executar `git push -u origin <nom-de-la-teva-branca>`.

## 7. CREA EL PULL REQUEST

Ara que la teva branca està pujada a GitHub, és hora d'enviar la teva col·laboració al projecte!

1. Ves a la pàgina del teu fork a GitHub (o visita el repositori original: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Fes clic al botó **"Contribute"** i selecciona **"Open pull request"** (o fes clic al botó **"Compare & pull request"** del bàner groc):

   <br/>

   <img src="../src/image5.png" alt="Obrir pull request" width="450" />

   <br/>

3. Comprova que:
   - **Base repository:** `jaanque/good-first-issue` (branca `main`)
   - **Head repository:** el teu fork (la teva branca)
4. Al títol i a la descripció, descriu clarament el que has modificat:
   - **Títol:** Afegeix un títol descriptiu (ex. `Add <el-teu-usuari> card`).
   - **Descripció:** Escriu una breu descripció explicant què has modificat (ex. que has afegit la teva targeta de col·laborador a `assets/cards/<el-teu-usuari>.json`).
5. Fes clic al botó verd **Create pull request**!

### ARA NOMÉS QUEDA ESPERAR LA REVISIÓ DEL TEU PULL REQUEST. DESPRÉS DE LA REVISIÓ, SI ÉS ACCEPTAT, LA TEVA TARGETA S'AFEGIRÀ AUTOMÀTICAMENT A LA VITRINA DE COL·LABORADORS.

Pots veure el resultat en viu de les contribucions de tothom aquí:
👉 **[Els nostres col·laboradors](https://jaanque.github.io/good-first-issue/)**

##

Recorda, això és només el començament! Hi ha milers de projectes de codi obert esperant la teva col·laboració, i el flux de treball és pràcticament el mateix a tot arreu: fes un fork del repositori, crea una branca, fes els teus canvis i envia un pull request.
