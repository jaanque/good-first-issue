##

C'est la première fois que vous utilisez Git et GitHub ? **Vous êtes au bon endroit !**

Ce dépôt est conçu pour vous aider à faire vos premiers pas dans le monde de l'**Open Source** dans un environnement sûr, sans avoir peur de casser quoi que ce soit.

Je suis convaincu que la meilleure façon d'apprendre est **par la pratique**, c'est pourquoi j'ai créé un projet simple que vous pouvez facilement modifier et améliorer.

**Votre mission est simple :** Suivez les instructions étape par étape pour ajouter votre nom et votre photo au projet.

**Prêt à commencer ?** Rendez-vous à l'**Étape 1** et faisons opérer la magie !

## 1. Forker le dépôt

Un **fork** est votre propre copie de ce dépôt sur votre compte GitHub. Il vous permet d'effectuer des modifications en toute sécurité sans affecter le projet original !

1. Allez dans le coin supérieur droit de cette page et cliquez sur le bouton **Fork** :

   <br/>

   <img src="../src/image.png" alt="Bouton Fork" width="400" />

   <br/>

2. Sur la page **Create a new fork**, laissez le nom du dépôt tel quel et cliquez sur **Create fork**.

3. Après quelques secondes, GitHub vous redirigera vers votre toute nouvelle copie à l'adresse :

   `https://github.com/<votre-nom-d-utilisateur>/good-first-issue`

🎉 **Génial !** Vous avez désormais votre propre copie de travail du projet.

## 2. Cloner le dépôt

Vous devez maintenant télécharger votre dépôt forké sur votre ordinateur afin de pouvoir modifier les fichiers localement.

1. Sur **la page de votre dépôt forké** sur GitHub, cliquez sur le bouton vert "**<> Code**".
2. Dans le menu déroulant, assurez-vous que l'onglet **HTTPS** est sélectionné, puis cliquez sur l'icône de copie pour copier l'URL de votre dépôt :

   <br/>

   <img src="../src/image2.png" alt="Cloner le dépôt" width="360" />

   <br/>

3. Ouvrez votre terminal et exécutez la commande `git clone` suivie de l'URL que vous avez copiée :

   ```bash
   git clone https://github.com/<votre-nom-d-utilisateur>/good-first-issue.git
   ```

   > 💡 _Remplacez `<votre-nom-d-utilisateur>` par votre vrai nom d'utilisateur GitHub !_

4. Une fois le téléchargement terminé, accédez au répertoire du projet :

   ```bash
   cd good-first-issue
   ```

🚀 **Beau travail !** Vous avez maintenant les fichiers du projet sur votre machine locale et vous êtes prêt à apporter vos modifications.

## 3. Créer une nouvelle branche

Avant d'effectuer la moindre modification, il est recommandé de créer une nouvelle branche. Travailler sur une branche distincte permet de garder votre travail organisé et votre branche `main` propre.

1. Dans votre terminal (à l'intérieur du dossier `good-first-issue`), exécutez la commande `git switch -c` suivie du nom de votre branche :

   ```bash
   git switch -c <nom-de-votre-branche>
   ```

   _(Donnez-lui un nom descriptif, comme `add-votre-nom` ou `le-nom-de-branche-de-votre-choix`)_

2. Git confirmera la création et le basculement vers votre nouvelle branche :

   <br/>

   <img src="../src/image3.png" alt="Créer une nouvelle branche" width="550" />

   <br/>

   > 💡 _Astuce : Si vous utilisez une version plus ancienne de Git, vous pouvez également utiliser `git checkout -b <nom-de-votre-branche>`._

🌿 **Tout est prêt !** Toutes les modifications que vous effectuerez à partir de maintenant resteront sur votre nouvelle branche.

## 4. Ouvrir le projet dans votre éditeur de code

Maintenant que vous avez le projet en local et que votre branche est prête, il est temps de l'ouvrir dans votre éditeur de code. Dans ce guide, nous utiliserons **Visual Studio Code (VS Code)**, mais vous pouvez utiliser l'éditeur de votre choix.

Si vous avez configuré VS Code dans votre ligne de commande, exécutez simplement la commande suivante depuis le dossier `good-first-issue` :

```bash
code .
```

Sinon, vous pouvez l'ouvrir manuellement :

1. Lancez **Visual Studio Code**.
2. Allez dans **Fichier** > **Ouvrir le dossier...** (ou appuyez sur `Ctrl + K, Ctrl + O` sur Windows / `Cmd + O` sur macOS).
3. Sélectionnez le dossier `good-first-issue`.

Vous devriez voir les fichiers du projet dans l'explorateur :

<br/>

<img src="../src/image4.png" alt="Projet ouvert dans VS Code" width="310" />

<br/>

> 💡 _Vous n'avez pas encore installé VS Code ? Vous pouvez le télécharger gratuitement sur [code.visualstudio.com](https://code.visualstudio.com/)._

💻 **Tout est paré !** Le projet est ouvert dans votre éditeur et vous êtes prêt à commencer les modifications.

## 5. Ajouter votre carte de contributeur

Place à la partie amusante : ajouter votre propre carte au projet !

Dans le répertoire `assets/cards/`, créez un nouveau fichier nommé avec votre nom d'utilisateur GitHub suivi de `.json` :

📄 `assets/cards/<votre-nom-d-utilisateur>.json` _(par ex. `octocat.json`)_

### Structure

Votre fichier doit respecter exactement la même structure que `jan.json` :

```json
{
  "name": "<votre-nom-d-utilisateur>",
  "img": "<url-de-votre-avatar>",
  "github": "https://github.com/<votre-nom-d-utilisateur>"
}
```

### Comment obtenir l'URL de votre image de profil (`img`) :

1. Ouvrez votre profil GitHub dans votre navigateur (`https://github.com/<votre-nom-d-utilisateur>`).
2. Faites un clic droit sur votre photo de profil et sélectionnez **"Copier l'adresse de l'image"** (ou **"Copy image address"**).
3. Collez cette URL copiée dans le champ `"img"`.

> 💡 _Astuce rapide : Vous pouvez également utiliser `https://github.com/<votre-nom-d-utilisateur>.png` comme URL pour votre image !_

### Exemple

Si votre nom d'utilisateur est `octocat`, vous créeriez `assets/cards/octocat.json` avec le contenu suivant :

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Enregistrez le fichier quand vous avez terminé. Une fois créé, vous êtes prêt pour l'étape suivante !

## 6. Commiter et pusher vos modifications

Avant de créer la Pull Request, vous devez enregistrer vos modifications et envoyer votre branche sur GitHub.

1. Ouvrez votre terminal dans le répertoire du projet et ajoutez votre nouveau fichier :

   ```bash
   git add assets/cards/<votre-nom-d-utilisateur>.json
   ```

2. Commitez les modifications avec un message court et descriptif :

   ```bash
   git commit -m "feat: add <votre-nom-d-utilisateur> card"
   ```

3. Envoyez (push) votre branche vers votre fork GitHub :

   ```bash
   git push origin <nom-de-votre-branche>
   ```

   > 💡 _Si vous y êtes invité, vous pouvez également exécuter `git push -u origin <nom-de-votre-branche>`._

## 7. Créer la Pull Request

Maintenant que votre branche est en ligne sur GitHub, il est temps de soumettre votre contribution au projet !

1. Rendez-vous sur la page de votre fork sur GitHub (ou visitez le dépôt d'origine : [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Cliquez sur le bouton **"Contribute"** et sélectionnez **"Open pull request"** (ou cliquez sur le bouton **"Compare & pull request"** dans la bannière jaune) :

   <br/>

   <img src="../src/image5.png" alt="Ouvrir une pull request" width="450" />

   <br/>

3. Vérifiez que :
   - **Base repository :** `jaanque/good-first-issue` (branche `main`)
   - **Head repository :** votre fork (votre branche)
4. Dans le titre et la description, décrivez clairement ce que vous avez modifié :
   - **Titre :** Ajoutez un titre descriptif (par ex. `Add <votre-nom-d-utilisateur> card`).
   - **Description :** Écrivez une courte description expliquant vos modifications (par ex. que vous avez ajouté votre carte de contributeur dans `assets/cards/<votre-nom-d-utilisateur>.json`).
5. Cliquez sur le bouton vert **Create pull request** !

### Il ne vous reste plus qu'à attendre la revue de votre pull request. Après validation, si elle est acceptée, votre carte sera automatiquement ajoutée à la galerie des contributeurs.

Vous pouvez voir le résultat en direct des contributions de chacun ici :
👉 **[Nos Contributeurs](https://jaanque.github.io/good-first-issue/)**

##

Rappelez-vous, ce n'est que le début ! Des milliers de projets open source attendent vos contributions, et le processus est essentiellement le même partout : forker le dépôt, créer une branche, apporter ses modifications et soumettre une pull request.

## 🎉 **Félicitations !**

Vous venez de soumettre votre toute première contribution Open Source ! Une fois fusionnée, votre carte apparaîtra automatiquement dans la vitrine des contributeurs.
