##

È la prima volta che usi Git e GitHub? **Sei nel posto giusto!**

Questo repository è pensato per aiutarti a muovere i tuoi primi passi nel mondo dell'**Open Source** in un ambiente sicuro, senza paura di rompere nulla.

Credo che il modo migliore per imparare sia **facendo**, quindi ho creato un progetto semplice che puoi modificare e migliorare facilmente.

**La tua missione è semplice:** Segui le istruzioni passo dopo passo per aggiungere il tuo nome e la tua foto al progetto.

**Pronto a iniziare?** Vai al **Passo 1** e facciamo un po' di magia!

## 1. FAI IL FORK DEL REPOSITORY

Un **fork** è la tua copia personale di questo repository nel tuo account GitHub. Ti permette di apportare modifiche in totale sicurezza senza influenzare il progetto originale!

1. Vai nell'angolo in alto a destra di questa pagina e fai clic sul pulsante **Fork**:

   <br/>

   <img src="../src/image.png" alt="Pulsante Fork" width="400" />

   <br/>

2. Nella pagina **Create a new fork**, lascia il nome del repository così com'è e fai clic su **Create fork**.

3. Dopo pochi secondi, GitHub ti reindirizzerà alla tua nuova copia all'indirizzo:

   `https://github.com/<tuo-username>/good-first-issue`

🎉 **Fantastico!** Ora hai la tua copia di lavoro del progetto.

## 2. CLONA IL REPOSITORY

Ora devi scaricare il repository che hai forked sul tuo computer per poter modificare i file localmente.

1. Nella **pagina del tuo repository forked** su GitHub, fai clic sul pulsante verde "**<> Code**".
2. Nel menu a discesa, assicurati che sia selezionata la scheda **HTTPS** e fai clic sull'icona di copia per copiare l'URL del repository:

   <br/>

   <img src="../src/image2.png" alt="Clona repository" width="360" />

   <br/>

3. Apri il terminale ed esegui il comando `git clone` seguito dall'URL copiato:

   ```bash
   git clone https://github.com/<tuo-username>/good-first-issue.git
   ```

> [!NOTE]
> Sostituisci `<tuo-username>` con il tuo vero nome utente di GitHub!

4. Una volta completato il download, entra nella cartella del progetto:

   ```bash
   cd good-first-issue
   ```

🚀 **Ottimo lavoro!** Ora hai i file del progetto sul tuo computer locale e sei pronto per apportare le tue modifiche.

## 3. CREA UN NUOVO BRANCH

Prima di apportare qualsiasi modifica, è buona norma creare un nuovo branch. Lavorare su un branch separato mantiene il tuo lavoro organizzato e lascia pulito il branch `main`.

1. Nel terminale (all'interno della cartella `good-first-issue`), esegui il comando `git switch -c` seguito dal nome del tuo branch:

   ```bash
   git switch -c <nome-del-tuo-branch>
   ```

   _(Assegna un nome descrittivo, come `add-tuo-nome` o `il-nome-del-branch-che-vuoi`)_

2. Git confermerà di aver creato il nuovo branch e di esservisi spostato:

   <br/>

   <img src="../src/image3.png" alt="Crea nuovo branch" width="550" />

   <br/>

> [!NOTE]
> Suggerimento: se usi una versione precedente di Git, puoi anche utilizzare `git checkout -b <nome-del-tuo-branch>`.

🌿 **Tutto pronto!** Tutte le modifiche che farai d'ora in avanti rimarranno nel tuo nuovo branch.

## 4. APRI IL PROGETTO NEL TUO EDITOR DI CODICE

Ora che hai il progetto in locale e il tuo branch è pronto, è il momento di aprirlo nel tuo editor di codice. In questa guida utilizzeremo **Visual Studio Code (VS Code)**, ma puoi usare qualsiasi editor tu preferisca.

Se hai configurato VS Code nella riga di comando, esegui semplicemente questo comando dall'interno della cartella `good-first-issue`:

```bash
code .
```

In alternativa, puoi aprirlo manualmente:

1. Apri **Visual Studio Code**.
2. Vai su **File** > **Apri cartella...** (o premi `Ctrl + K, Ctrl + O` su Windows / `Cmd + O` su macOS).
3. Seleziona la cartella `good-first-issue`.

Dovresti vedere i file del progetto nella barra laterale dell'esploratore:

<br/>

<img src="../src/image4.png" alt="Progetto aperto in VS Code" width="310" />

<br/>

> [!NOTE]
> Non hai ancora installato VS Code? Puoi scaricarlo gratuitamente da [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Tutto pronto!** Ora hai il progetto aperto nel tuo editor e sei pronto per iniziare a modificarlo.

## 5. AGGIUNGI LA TUA SCHEDA DI COLLABORATORE

Ora arriva la parte divertente: aggiungere la tua scheda al progetto!

All'interno della cartella `assets/cards/`, crea un nuovo file con il tuo nome utente GitHub seguito da `.json`:

📄 `assets/cards/<tuo-username>.json` _(es. `octocat.json`)_

### STRUTTURA

Il tuo file deve seguire esattamente la stessa struttura di `jan.json`:

```json
{
  "name": "<tuo-username>",
  "img": "<url-del-tuo-avatar>",
  "github": "https://github.com/<tuo-username>"
}
```

### COME OTTENERE L'URL DELL'IMMAGINE DEL TUO PROFILO (`IMG`):

1. Apri la pagina del tuo profilo GitHub nel browser (`https://github.com/<tuo-username>`).
2. Fai clic con il tasto destro del mouse sulla tua immagine del profilo e seleziona **"Copia indirizzo dell'immagine"** (o **"Copy image address"**).
3. Incolla l'URL copiato nel campo `"img"`.

> [!NOTE]
> Trucco veloce: Puoi anche usare `https://github.com/<tuo-username>.png` come URL della tua immagine!

### ESEMPIO

Se il tuo nome utente è `octocat`, creeresti `assets/cards/octocat.json` con il seguente contenuto:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Salva il file al termine. Una volta creato, sei pronto per il passo successivo!

## 6. ESEGUI IL COMMIT E IL PUSH DELLE MODIFICHE

Prima di creare la Pull Request, devi salvare le tue modifiche e caricare il tuo branch su GitHub.

1. Apri il terminale all'interno della cartella del progetto e aggiungi il tuo nuovo file:

   ```bash
   git add assets/cards/<tuo-username>.json
   ```

2. Esegui il commit delle modifiche con un messaggio breve e descrittivo:

   ```bash
   git commit -m "feat: add <tuo-username> card"
   ```

3. Invia il tuo branch al tuo fork su GitHub:

   ```bash
   git push origin <nome-del-tuo-branch>
   ```

> [!NOTE]
> Se richiesto, puoi anche eseguire `git push -u origin <nome-del-tuo-branch>`.

## 7. CREA LA PULL REQUEST

Ora che il tuo branch è caricato su GitHub, è il momento di inviare il tuo contributo al progetto!

1. Vai alla pagina del tuo fork su GitHub (o visita il repository originale: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Fai clic sul pulsante **"Contribute"** e seleziona **"Open pull request"** (oppure fai clic sul pulsante **"Compare & pull request"** nel banner giallo):

   <br/>

   <img src="../src/image5.png" alt="Apri pull request" width="450" />

   <br/>

3. Verifica che:
   - **Base repository:** `jaanque/good-first-issue` (branch `main`)
   - **Head repository:** il tuo fork (il tuo branch)
4. Nel titolo e nella descrizione, descrivi chiaramente cosa hai modificato:
   - **Titolo:** Aggiungi un titolo descrittivo (es. `Add <tuo-username> card`).
   - **Descrizione:** Scrivi una breve descrizione che spieghi cosa hai modificato (es. di aver aggiunto la tua scheda collaboratore in `assets/cards/<tuo-username>.json`).
5. Fai clic sul pulsante verde **Create pull request**!

### ORA DEVI SOLO ATTENDERE LA REVISIONE DELLA TUA PULL REQUEST. DOPO LA REVISIONE, SE ACCETTATA, LA TUA SCHEDA VERRÀ AGGIUNTA AUTOMATICAMENTE ALLA VETRINA DEI COLLABORATORI.

Puoi vedere il risultato in tempo reale dei contributi di tutti qui:
👉 **[I nostri collaboratori](https://jaanque.github.io/good-first-issue/)**
