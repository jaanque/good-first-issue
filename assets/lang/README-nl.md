##

Is dit de eerste keer dat je Git en GitHub gebruikt? **Dan ben je hier aan het juiste adres!**

Deze repository is ontworpen om je te helpen je eerste stappen te zetten in de wereld van **Open Source** in een veilige omgeving, zonder bang te hoeven zijn dat je iets kapotmaakt.

Ik geloof dat de beste manier van leren **door te doen** is, dus heb ik een eenvoudig project gemaakt dat je makkelijk kunt aanpassen en verbeteren.

**Je missie is simpel:** Volg de stapsgewijze instructies om je naam en foto aan het project toe te voegen.

**Klaar om te beginnen?** Ga naar **Stap 1** en laten we aan de slag gaan!

## 1. FORK DE REPOSITORY

Een **fork** is je eigen kopie van deze repository onder jouw GitHub-account. Hiermee kun je veilig wijzigingen aanbrengen zonder het oorspronkelijke project te beïnvloeden!

1. Ga naar de rechterbovenhoek van deze pagina en klik op de knop **Fork**:

   <br/>

   <img src="../src/image.png" alt="Fork-knop" width="400" />

   <br/>

2. Laat op de pagina **Create a new fork** de repositorynaam ongewijzigd en klik op **Create fork**.

3. Na enkele seconden leidt GitHub je door naar je nieuw gemaakte kopie op:

   `https://github.com/<jouw-gebruikersnaam>/good-first-issue`

🎉 **Geweldig!** Je hebt nu je eigen werkkopie van het project.

## 2. KLOON DE REPOSITORY

Nu moet je de geforkte repository downloaden naar je computer zodat je de bestanden lokaal kunt bewerken.

1. Klik op **de pagina van je geforkte repository** op GitHub op de groene knop "**<> Code**".
2. Zorg ervoor dat in het dropdown-menu het tabblad **HTTPS** is geselecteerd en klik op het kopieericoon om de URL van je repository te kopiëren:

   <br/>

   <img src="../src/image2.png" alt="Repository klonen" width="360" />

   <br/>

3. Open je terminal en voer het commando `git clone` uit, gevolgd door de URL die je hebt gekopieerd:

   ```bash
   git clone https://github.com/<jouw-gebruikersnaam>/good-first-issue.git
   ```

> [!NOTE]
> Vervang `<jouw-gebruikersnaam>` door je daadwerkelijke GitHub-gebruikersnaam!

4. Zodra het downloaden is voltooid, navigeer je naar de projectmap:

   ```bash
   cd good-first-issue
   ```

🚀 **Goed gedaan!** Je hebt nu de projectbestanden op je lokale machine en bent klaar om wijzigingen aan te brengen.

## 3. MAAK EEN NIEUWE BRANCH AAN

Voordat je wijzigingen aanbrengt, is het een best practice om een nieuwe branch aan te maken. Werken op een aparte branch houdt je werk overzichtelijk en laat de `main`-branch schoon.

1. Voer in je terminal (binnen de map `good-first-issue`) het commando `git switch -c` uit, gevolgd door de naam van je branch:

   ```bash
   git switch -c <jouw-branch-naam>
   ```

   _(Geef het een duidelijke naam, zoals `add-jouw-naam` of `de-gewenste-branch-naam`)_

2. Git bevestigt dat je een nieuwe branch hebt aangemaakt en ernaartoe bent overgeschakeld:

   <br/>

   <img src="../src/image3.png" alt="Nieuwe branch aanmaken" width="550" />

   <br/>

> [!NOTE]
> Tip: Als je een oudere versie van Git gebruikt, kun je ook `git checkout -b <jouw-branch-naam>` gebruiken.

🌿 **Helemaal klaar!** Alle wijzigingen die je vanaf nu aanbrengt, blijven op je nieuwe branch.

## 4. OPEN HET PROJECT IN JE CODE-EDITOR

Nu je het project lokaal hebt en je branch klaar is, is het tijd om het te openen in je code-editor. In deze gids gebruiken we **Visual Studio Code (VS Code)**, maar je kunt elke editor gebruiken die je prettig vindt.

Als je VS Code hebt ingesteld voor de commandoregel, voer je eenvoudig het volgende commando uit vanuit de map `good-first-issue`:

```bash
code .
```

Als alternatief kun je het handmatig openen:

1. Start **Visual Studio Code**.
2. Ga naar **File** > **Open Folder...** (of druk op `Ctrl + K, Ctrl + O` op Windows / `Cmd + O` op macOS).
3. Selecteer de map `good-first-issue`.

Je zou de projectbestanden in de verkenner moeten zien:

<br/>

<img src="../src/image4.png" alt="Project geopend in VS Code" width="310" />

<br/>

> [!NOTE]
> Heb je VS Code nog niet geïnstalleerd? Je kunt het gratis downloaden via [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Alles klaar!** Je hebt nu het project geopend in je editor en kunt beginnen met bewerken.

## 5. VOEG JE CONTRIBUTOR-KAART TOE

Nu komt het leukste deel: je eigen kaart toevoegen aan het project!

Maak in de map `assets/cards/` een nieuw bestand aan met je GitHub-gebruikersnaam gevolgd door `.json`:

📄 `assets/cards/<jouw-gebruikersnaam>.json` _(bijv. `octocat.json`)_

### STRUCTUUR

Je bestand moet exact dezelfde structuur volgen als `jan.json`:

```json
{
  "name": "<jouw-gebruikersnaam>",
  "img": "<url-naar-je-avatar>",
  "github": "https://github.com/<jouw-gebruikersnaam>"
}
```

### HOE VIND JE DE URL VAN JE PROFIELFOTO (`IMG`):

1. Open je GitHub-profielpagina in je browser (`https://github.com/<jouw-gebruikersnaam>`).
2. Klik met de rechtermuisknop op je profielfoto en kies **"Afbeeldingsadres kopiëren"** (of **"Copy image address"**).
3. Plak die gekopieerde URL in het veld `"img"`.

> [!NOTE]
> Handige tip: Je kunt ook `https://github.com/<jouw-gebruikersnaam>.png` direct gebruiken als URL voor je afbeelding!

### VOORBEELD

Als je gebruikersnaam `octocat` is, maak je `assets/cards/octocat.json` aan met de volgende inhoud:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Sla het bestand op als je klaar bent. Zodra het is aangemaakt, ben je klaar voor de volgende stap!

## 6. COMMIT EN PUSH JE WIJZIGINGEN

Voordat je de Pull Request aanmaakt, moet je je wijzigingen opslaan en je branch naar GitHub uploaden.

1. Open je terminal in de projectmap en voeg je nieuwe bestand toe:

   ```bash
   git add assets/cards/<jouw-gebruikersnaam>.json
   ```

2. Commit de wijzigingen met een kort en duidelijk bericht:

   ```bash
   git commit -m "feat: add <jouw-gebruikersnaam> card"
   ```

3. Push je branch naar je GitHub-fork:

   ```bash
   git push origin <jouw-branch-naam>
   ```

> [!NOTE]
> Indien gevraagd, kun je ook `git push -u origin <jouw-branch-naam>` uitvoeren.

## 7. MAAK DE PULL REQUEST AAN

Nu je branch op GitHub staat, is het tijd om je bijdrage in te dienen bij het project!

1. Ga naar je fork-pagina op GitHub (of bezoek de originele repository: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Klik op de knop **"Contribute"** en selecteer **"Open pull request"** (of klik op de knop **"Compare & pull request"** in de gele banner):

   <br/>

   <img src="../src/image5.png" alt="Pull request openen" width="450" />

   <br/>

3. Controleer of:
   - **Base repository:** `jaanque/good-first-issue` (branch `main`)
   - **Head repository:** jouw fork (jouw branch)
4. Beschrijf in de titel en beschrijving duidelijk wat je hebt gewijzigd:
   - **Titel:** Voeg een duidelijke titel toe (bijv. `Add <jouw-gebruikersnaam> card`).
   - **Beschrijving:** Schrijf een korte uitleg over wat je hebt gewijzigd (bijv. dat je je contributor-kaart hebt toegevoegd in `assets/cards/<jouw-gebruikersnaam>.json`).
5. Klik op de groene knop **Create pull request**!

Onthoud: dit is pas het begin! Er wachten duizenden open source-projecten op jouw bijdrage, en de workflow is vrijwel overal hetzelfde: fork de repository, maak een branch aan, voer je wijzigingen door en dien een pull request in.
