##

Verwendest du Git und GitHub zum ersten Mal? **Hier bist du genau richtig!**

Dieses Repository soll dir dabei helfen, deine ersten Schritte in der **Open-Source**-Welt in einer sicheren Umgebung zu machen, ohne Angst haben zu müssen, etwas kaputt zu machen.

Ich glaube, dass man am besten lernt, indem man **es selbst tut**. Deshalb habe ich ein einfaches Projekt erstellt, das du leicht anpassen und verbessern kannst.

**Deine Mission ist ganz einfach:** Folge den Schritt-für-Schritt-Anweisungen, um deinen Namen und dein Foto zum Projekt hinzuzufügen.

**Bereit loszulegen?** Gehe zu **Schritt 1** und lass uns loslegen!

## 1. Forke das Repository

Ein **Fork** ist deine eigene Kopie dieses Repositorys unter deinem GitHub-Konto. Damit kannst du sicher Änderungen vornehmen, ohne das Originalprojekt zu beeinträchtigen!

1. Gehe in die obere rechte Ecke dieser Seite und klicke auf die Schaltfläche **Fork**:

   <br/>

   <img src="../src/image.png" alt="Fork-Button" width="400" />

   <br/>

2. Lass auf der Seite **Create a new fork** den Repository-Namen unverändert und klicke auf **Create fork**.

3. Nach wenigen Sekunden leitet GitHub dich zu deiner neu erstellten Kopie weiter unter:

   `https://github.com/<dein-benutzername>/good-first-issue`

🎉 **Klasse!** Jetzt hast du deine eigene Arbeitskopie des Projekts.

## 2. Klone das Repository

Jetzt musst du dein geforktes Repository auf deinen Computer herunterladen, um die Dateien lokal bearbeiten zu können.

1. Klicke auf **deiner geforkten Repository-Seite** auf GitHub auf die grüne Schaltfläche "**<> Code**".
2. Vergewissere dich im Dropdown-Menü, dass der Reiter **HTTPS** ausgewählt ist, und klicke auf das Kopiersymbol, um die URL deines Repositorys zu kopieren:

   <br/>

   <img src="../src/image2.png" alt="Repository klonen" width="360" />

   <br/>

3. Öffne dein Terminal und führe den Befehl `git clone` gefolgt von der kopierten URL aus:

   ```bash
   git clone https://github.com/<dein-benutzername>/good-first-issue.git
   ```

   > 💡 _Ersetze `<dein-benutzername>` durch deinen tatsächlichen GitHub-Benutzernamen!_

4. Sobald der Download abgeschlossen ist, navigiere in das Projektverzeichnis:

   ```bash
   cd good-first-issue
   ```

🚀 **Großartige Arbeit!** Du hast die Projektdateien nun auf deinem lokalen Rechner und kannst mit den Änderungen beginnen.

## 3. Erstelle einen neuen Branch

Bevor du Änderungen vornimmst, empfiehlt es sich, einen neuen Branch zu erstellen. Das Arbeiten in einem separaten Branch hält deine Arbeit übersichtlich und den `main`-Branch sauber.

1. Führe im Terminal (innerhalb des Ordners `good-first-issue`) den Befehl `git switch -c` gefolgt vom Namen deines neuen Branches aus:

   ```bash
   git switch -c <dein-branch-name>
   ```

   _(Gib ihm einen aussagekräftigen Namen wie `add-dein-name` oder `ein-branch-name-deiner-wahl`)_

2. Git bestätigt, dass der neue Branch erstellt und ausgewählt wurde:

   <br/>

   <img src="../src/image3.png" alt="Neuen Branch erstellen" width="550" />

   <br/>

   > 💡 _Tipp: Wenn du eine ältere Git-Version verwendest, kannst du stattdessen `git checkout -b <dein-branch-name>` ausführen._

🌿 **Alles bereit!** Alle Änderungen, die du ab jetzt machst, bleiben in deinem neuen Branch.

## 4. Öffne das Projekt in deinem Code-Editor

Jetzt, wo du das Projekt lokal hast und dein Branch bereitsteht, kannst du es in deinem Code-Editor öffnen. In dieser Anleitung verwenden wir **Visual Studio Code (VS Code)**, aber du kannst jeden beliebigen Editor verwenden.

Wenn du VS Code in der Befehlszeile eingerichtet hast, führe einfach den folgenden Befehl im Ordner `good-first-issue` aus:

```bash
code .
```

Alternativ kannst du es manuell öffnen:

1. Starte **Visual Studio Code**.
2. Gehe auf **Datei** > **Ordner öffnen...** (oder drücke `Strg + K, Strg + O` unter Windows / `Cmd + O` unter macOS).
3. Wähle den Ordner `good-first-issue` aus.

Die Projektdateien sollten nun im Explorer sichtbar sein:

<br/>

<img src="../src/image4.png" alt="Projekt in VS Code geöffnet" width="310" />

<br/>

> 💡 _Hast du VS Code noch nicht installiert? Du kannst es kostenlos unter [code.visualstudio.com](https://code.visualstudio.com/) herunterladen._

💻 **Alles startklar!** Das Projekt ist in deinem Editor geöffnet und du kannst mit dem Bearbeiten beginnen.

## 5. Füge deine Contributor-Karte hinzu

Jetzt kommt der beste Teil: Füge deine eigene Karte zum Projekt hinzu!

Erstelle im Verzeichnis `assets/cards/` eine neue Datei mit deinem GitHub-Benutzernamen gefolgt von `.json`:

📄 `assets/cards/<dein-benutzername>.json` _(z. B. `octocat.json`)_

### Struktur

Deine Datei muss genau denselben Aufbau wie `jan.json` haben:

```json
{
  "name": "<dein-benutzername>",
  "img": "<deine-avatar-url>",
  "github": "https://github.com/<dein-benutzername>"
}
```

### So erhältst du die URL deines Profilbilds (`img`):

1. Öffne deine GitHub-Profilseite im Browser (`https://github.com/<dein-benutzername>`).
2. Klicke mit der rechten Maustaste auf dein Profilbild und wähle **"Grafikadresse kopieren"** (bzw. **"Copy image address"**).
3. Füge die kopierte URL in das Feld `"img"` ein.

> 💡 _Schneller Trick: Du kannst auch `https://github.com/<dein-benutzername>.png` als Bild-URL verwenden!_

### Beispiel

Wenn dein Benutzername `octocat` lautet, erstellst du `assets/cards/octocat.json` mit folgendem Inhalt:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Speichere die Datei, wenn du fertig bist. Sobald sie erstellt ist, bist du bereit für den nächsten Schritt!

## 6. Committe und pushe deine Änderungen

Bevor du den Pull Request erstellst, musst du deine Änderungen speichern und deinen Branch zu GitHub hochladen.

1. Öffne dein Terminal im Projektverzeichnis und füge die neue Datei zur Staging-Area hinzu:

   ```bash
   git add assets/cards/<dein-benutzername>.json
   ```

2. Committe die Änderungen mit einer kurzen, aussagekräftigen Nachricht:

   ```bash
   git commit -m "feat: add <dein-benutzername> card"
   ```

3. Pushe deinen Branch zu deinem GitHub-Fork:

   ```bash
   git push origin <dein-branch-name>
   ```

   > 💡 _Falls aufgefordert, kannst du auch `git push -u origin <dein-branch-name>` ausführen._

## 7. Erstelle den Pull Request

Da dein Branch nun auf GitHub hochgeladen ist, kannst du deinen Beitrag zum Projekt einreichen!

1. Gehe zu deiner Fork-Seite auf GitHub (oder rufe das Original-Repository auf: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Klicke auf die Schaltfläche **"Contribute"** und wähle **"Open pull request"** (oder klicke auf die Schaltfläche **"Compare & pull request"** im gelben Banner):

   <br/>

   <img src="../src/image5.png" alt="Pull Request erstellen" width="450" />

   <br/>

3. Überprüfe folgende Angaben:
   - **Base repository:** `jaanque/good-first-issue` (Branch `main`)
   - **Head repository:** dein Fork (dein Branch)
4. Beschreibe in Titel und Beschreibung verständlich, was du geändert hast:
   - **Titel:** Gib einen aussagekräftigen Titel ein (z. B. `Add <dein-benutzername> card`).
   - **Beschreibung:** Schreibe eine kurze Beschreibung deiner Änderungen (z. B. dass du deine Contributor-Karte unter `assets/cards/<dein-benutzername>.json` hinzugefügt hast).
5. Klicke auf den grünen Button **Create pull request**!

### Jetzt musst du nur noch auf das Review deines Pull Requests warten. Nach erfolgreicher Prüfung wird deine Karte automatisch zur Contributor-Übersicht hinzugefügt.
