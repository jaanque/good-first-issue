## 1. ریپوزٹری کو Fork کریں

ایک **Fork** آپ کے GitHub اکاؤنٹ کے تحت اس ریپوزٹری کی اپنی کاپی ہے۔ یہ آپ کو اصل پروجیکٹ پر اثر انداز ہوئے بغیر محفوظ طریقے سے تبدیلیاں کرنے دیتا ہے!

1. اس صفحے کے اوپری دائیں کونے پر جائیں اور **Fork** بٹن پر کلک کریں:

   <br/>

   <img src="../src/image.png" alt="Fork بٹن" width="400" />

   <br/>

2. **Create a new fork** صفحے پر، ریپوزٹری کا نام ویسا ہی رہنے دیں اور **Create fork** پر کلک کریں۔

3. چند سیکنڈ کے بعد GitHub آپ کو آپ کی نئی بنائی گئی کاپی پر بھیج دے گا:

   `https://github.com/<آپ-کا-صارف-نام>/good-first-issue`

🎉 **بہت عمدہ!** اب آپ کے پاس پروجیکٹ کی اپنی کاپی موجود ہے۔

## 2. ریپوزٹری کو Clone کریں

اب آپ کو اپنی فورک کی گئی ریپوزٹری کو اپنے کمپیوٹر پر ڈاؤن لوڈ کرنا ہوگا تاکہ آپ فائلوں کو مقامی طور پر ایڈٹ کر سکیں۔

1. GitHub پر **اپنی فورک کردہ ریپوزٹری کے صفحے** پر سبز رنگ کے "**<> Code**" بٹن پر کلک کریں۔
2. ڈراپ ڈاؤن مینو میں یقینی بنائیں کہ **HTTPS** ٹیب منتخب ہے، اور ریپوزٹری URL کاپی کرنے کے لیے کاپی آئیکن پر کلک کریں:

   <br/>

   <img src="../src/image2.png" alt="ریپوزٹری کلون کریں" width="360" />

   <br/>

3. اپنا ٹرمینل کھولیں اور `git clone` کمانڈ کے بعد کاپی کیا گیا URL چلا کر چلائیں:

   ```bash
   git clone https://github.com/<آپ-کا-صارف-نام>/good-first-issue.git
   ```

   > 💡 _`<آپ-کا-صارف-نام>` کو اپنے اصل GitHub صارف نام سے تبدیل کریں!_

4. ڈاؤن لوڈ مکمل ہونے کے بعد، پروجیکٹ ڈائرکٹری میں جائیں:

   ```bash
   cd good-first-issue
   ```

🚀 **شاندار!** پروجیکٹ کی فائلیں اب آپ کے کمپیوٹر پر موجود ہیں اور آپ تبدیلیاں کرنے کے لیے تیار ہیں۔

## 3. ایک نئی برانچ (Branch) بنائیں

کوئی بھی تبدیلی کرنے سے پہلے نئی برانچ بنانا بہترین طریقہ ہے۔ الگ برانچ پر کام کرنے سے آپ کا کام منظم رہتا ہے اور `main` برانچ صاف رہتی ہے۔

1. اپنے ٹرمینل میں (`good-first-issue` فولڈر کے اندر)، `git switch -c` کمانڈ کے بعد اپنی برانچ کا نام لکھ کر چلائیں:

   ```bash
   git switch -c <آپ-کی-برانچ-کا-نام>
   ```

   _(اسے کوئی واضح نام دیں، جیسے `add-آپ-کا-نام` یا `کوئی-بھی-برانچ-نام`)_

2. Git تصدیق کرے گا کہ آپ نے نئی برانچ بنا لی ہے اور اس پر سوئچ کر لیا ہے:

   <br/>

   <img src="../src/image3.png" alt="نئی برانچ بنائیں" width="550" />

   <br/>

   > 💡 _مشورہ: اگر آپ Git کا پرانا ورژن استعمال کر رہے ہیں تو آپ `git checkout -b <آپ-کی-برانچ-کا-نام>` بھی استعمال کر سکتے ہیں۔_

🌿 **سب تیار ہے!** اب آپ جو بھی تبدیلیاں کریں گے وہ آپ کی نئی برانچ میں محفوظ رہیں گی۔

## 4. پروجیکٹ کو اپنے کوڈ ایڈیٹر میں کھولیں

اب جب کہ آپ کے پاس پروجیکٹ مقامی طور پر موجود ہے اور برانچ تیار ہے، اسے اپنے کوڈ ایڈیٹر میں کھولنے کا وقت آگیا ہے۔ اس گائیڈ میں ہم **Visual Studio Code (VS Code)** استعمال کریں گے، لیکن آپ اپنی پسند کا کوئی بھی ایڈیٹر استعمال کر سکتے ہیں۔

اگر آپ کے پاس کمانڈ لائن میں VS Code سیٹ ہے، تو `good-first-issue` فولڈر کے اندر سے بس یہ کمانڈ چلائیں:

```bash
code .
```

متبادل طور پر، آپ اسے دستی طور پر بھی کھول سکتے ہیں:

1. **Visual Studio Code** کھولیں۔
2. **File** > **Open Folder...** پر جائیں (یا Windows پر `Ctrl + K, Ctrl + O` / macOS پر `Cmd + O` دبائیں)۔
3. `good-first-issue` فولڈر منتخب کریں۔

آپ کو ایکسپلورر میں پروجیکٹ فائلیں نظر آئیں گی:

<br/>

<img src="../src/image4.png" alt="VS Code میں کھلا پروجیکٹ" width="310" />

<br/>

> 💡 _کیا آپ کے پاس ابھی تک VS Code انسٹال نہیں ہے؟ آپ اسے [code.visualstudio.com](https://code.visualstudio.com/) سے مفت ڈاؤن لوڈ کر سکتے ہیں۔_

💻 **سب تیار!** اب پروجیکٹ آپ کے ایڈیٹر میں کھلا ہے اور آپ ایڈیٹنگ شروع کرنے کے لیے تیار ہیں۔

## 5. اپنا کنٹری بیوٹر کارڈ شامل کریں

اب سب سے دلچسپ مرحلہ آتا ہے: پروجیکٹ میں اپنا کارڈ شامل کرنا!

`assets/cards/` ڈائرکٹری کے اندر، اپنے GitHub صارف نام کے بعد `.json` لگا کر ایک نئی فائل بنائیں:

📄 `assets/cards/<آپ-کا-صارف-نام>.json` _(مثلاً `octocat.json`)_

### ساخت

آپ کی فائل کی ساخت بالکل `jan.json` کی طرح ہونی چاہیے:

```json
{
  "name": "<آپ-کا-صارف-نام>",
  "img": "<آپ-کی-تصویر-کا-url>",
  "github": "https://github.com/<آپ-کا-صارف-نام>"
}
```

### اپنی پروفائل تصویر کا URL (`img`) حاصل کرنے کا طریقہ:

1. براؤزر میں اپنا GitHub پروفائل پیج کھولیں (`https://github.com/<آپ-کا-صارف-نام>`)۔
2. اپنی پروفائل تصویر پر رائٹ کلک کریں اور **"Copy image address"** منتخب کریں۔
3. اس کاپی شدہ URL کو `"img"` فیلڈ میں پیسٹ کریں۔

> 💡 _فوری ٹرک: آپ اپنی تصویر کے URL کے طور پر براہ راست `https://github.com/<آپ-کا-صارف-نام>.png` بھی استعمال کر سکتے ہیں!_

### مثال

اگر آپ کا صارف نام `octocat` ہے تو آپ درج ذیل مواد کے ساتھ `assets/cards/octocat.json` فائل بنائیں گے:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

مکمل ہونے پر فائل کو محفوظ کریں۔ فائل بن جانے کے بعد آپ اگلے مرحلے کے لیے تیار ہیں!

## 6. اپنی تبدیلیاں Commit اور Push کریں

Pull Request بنانے سے پہلے، آپ کو اپنی تبدیلیاں محفوظ کرنی ہوں گی اور اپنی برانچ کو GitHub پر اپ لوڈ کرنا ہوگا۔

1. پروجیکٹ ڈائرکٹری میں ٹرمینل کھولیں اور اپنی نئی فائل شامل کریں:

   ```bash
   git add assets/cards/<آپ-کا-صارف-نام>.json
   ```

2. ایک مختصر اور واضح پیغام کے ساتھ تبدیلیوں کو کمٹ کریں:

   ```bash
   git commit -m "feat: add <آپ-کا-صارف-نام> card"
   ```

3. اپنی برانچ کو اپنے GitHub فورک پر پش کریں:

   ```bash
   git push origin <آپ-کی-برانچ-کا-نام>
   ```

   > 💡 _پوچھے جانے پر، آپ `git push -u origin <آپ-کی-برانچ-کا-نام>` بھی چلا سکتے ہیں۔_

## 7. Pull Request بنائیں

اب جب کہ آپ کی برانچ GitHub پر اپ لوڈ ہو چکی ہے، پروجیکٹ میں اپنی شراکت جمع کرانے کا وقت آگیا ہے!

1. GitHub پر اپنے فورک صفحے پر جائیں (یا اصل ریپوزٹری دیکھیں: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue))۔
2. **"Contribute"** بٹن پر کلک کریں اور **"Open pull request"** منتخب کریں (یا پیلے بینر میں **"Compare & pull request"** بٹن پر کلک کریں):

   <br/>

   <img src="../src/image5.png" alt="Pull request کھولیں" width="450" />

   <br/>

3. تصدیق کریں کہ:
   - **Base repository:** `jaanque/good-first-issue` (برانچ `main`)
   - **Head repository:** آپ کا فورک (آپ کی برانچ)
4. عنوان اور تفصیل میں واضح طور پر بتائیں کہ آپ نے کیا تبدیل کیا ہے:
   - **عنوان:** ایک وضاحتی عنوان دیں (مثلاً `Add <آپ-کا-صارف-نام> card`)۔
   - **تفصیل:** ایک مختصر تفصیل لکھیں جس میں بتایا گیا ہو کہ آپ نے کیا تبدیل کیا ہے (مثلاً آپ نے `assets/cards/<آپ-کا-صارف-نام>.json` میں اپنا کنٹری بیوٹر کارڈ شامل کیا ہے)۔
5. سبز رنگ کے **Create pull request** بٹن پر کلک کریں!
