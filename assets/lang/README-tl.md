##

Unang beses mo bang gagamit ng Git at GitHub? **Nasa tamang lugar ka!**

Ang repositoryong ito ay idinisenyo upang tulungan kang gawin ang iyong mga unang hakbang sa mundo ng **Open Source** sa isang ligtas na kapaligiran, nang walang takot na may masira.

Naniniwala ako na ang pinakamahusay na paraan ng pagkatuto ay **sa pamamagitan ng paggawa**, kaya gumawa ako ng simpleng proyekto na madali mong mababago at mapapahusay.

**Simple lang ang iyong misyon:** Sundin ang sunod-sunod na gabay upang idagdag ang iyong pangalan at larawan sa proyekto.

**Handa ka na bang magsimula?** Pumunta sa **Hakbang 1** at simulan na natin!

## 1. I-FORK ANG REPOSITORY

Ang **fork** ay ang sarili mong kopya ng repositoryong ito sa ilalim ng iyong GitHub account. Nagbibigay-daan ito upang makagawa ka ng mga pagbabago nang ligtas nang hindi naaapektuhan ang orihinal na proyekto!

1. Pumunta sa kanang bahagi sa itaas ng pahinang ito at i-click ang **Fork** button:

   <br/>

   <img src="../src/image.png" alt="Fork button" width="400" />

   <br/>

2. Sa pahina ng **Create a new fork**, panatilihin ang pangalan ng repository at i-click ang **Create fork**.

3. Pagkalipas ng ilang segundo, ire-redirect ka ng GitHub sa iyong bagong gawang kopya sa:

   `https://github.com/<iyong-username>/good-first-issue`

🎉 **Napakagaling!** Mayroon ka nang sariling kopya ng proyekto.

## 2. I-CLONE ANG REPOSITORY

Ngayon ay kailangan mong i-download ang na-fork na repository sa iyong kompyuter upang ma-edit ang mga file nang lokal.

1. Sa **pahina ng iyong na-fork na repository** sa GitHub, i-click ang berdeng pindutan na "**<> Code**".
2. Sa dropdown menu, tiyaking napili ang tab na **HTTPS**, at i-click ang icon ng kopya upang kopyahin ang URL ng iyong repository:

   <br/>

   <img src="../src/image2.png" alt="I-clone ang repository" width="360" />

   <br/>

3. Buksan ang iyong terminal at patakbuhin ang utos na `git clone` kasunod ang kinopyang URL:

   ```bash
   git clone https://github.com/<iyong-username>/good-first-issue.git
   ```

> [!NOTE]
> Palitan ang `<iyong-username>` ng iyong totoong username sa GitHub!

4. Kapag natapos na ang pag-download, mag-navigate papunta sa direktoryo ng proyekto:

   ```bash
   cd good-first-issue
   ```

🚀 **Magaling!** Nasa iyong lokal na makina na ang mga file ng proyekto at handa ka nang gumawa ng mga pagbabago.

## 3. GUMAWA NG BAGONG BRANCH

Bago gumawa ng anumang pagbabago, pinakamainam na kasanayan ang paggawa ng bagong branch. Ang pagtatrabaho sa hiwalay na branch ay nagpapanatili ng ayos ng iyong gawa at pinapanatiling malinis ang `main` branch.

1. Sa iyong terminal (sa loob ng `good-first-issue` folder), patakbuhin ang `git switch -c` kasunod ang pangalan ng iyong branch:

   ```bash
   git switch -c <pangalan-ng-iyong-branch>
   ```

   _(Bigyan ito ng malinaw na pangalan, tulad ng `add-iyong-pangalan` o `pangalan-ng-branch-na-nais-mo`)_

2. Kukumpirmahin ng Git na nagawa mo na at lumipat ka na sa iyong bagong branch:

   <br/>

   <img src="../src/image3.png" alt="Gumawa ng bagong branch" width="550" />

   <br/>

> [!NOTE]
> Tip: Kung gumagamit ka ng mas lumang bersyon ng Git, maaari mo ring gamitin ang `git checkout -b <pangalan-ng-iyong-branch>`.

🌿 **Handa na ang lahat!** Anumang pag-edit na gagawin mo mula ngayon ay mananatili sa iyong bagong branch.

## 4. BUKSAN ANG PROYEKTO SA IYONG CODE EDITOR

Ngayong nasa lokal mo na ang proyekto at handa na ang branch, oras na para buksan ito sa iyong code editor. Sa gabay na ito, gagamitin natin ang **Visual Studio Code (VS Code)**, ngunit maaari kang gumamit ng anumang editor na nais mo.

Kung naka-configure ang VS Code sa iyong command line, patakbuhin lang ang sumusunod na utos mula sa loob ng `good-first-issue` folder:

```bash
code .
```

Bilang kahalili, maaari mo itong buksan nang manu-mano:

1. Buksan ang **Visual Studio Code**.
2. Pumunta sa **File** > **Open Folder...** (o pindutin ang `Ctrl + K, Ctrl + O` sa Windows / `Cmd + O` sa macOS).
3. Piliin ang `good-first-issue` folder.

Dapat mong makita ang mga file ng proyekto sa explorer:

<br/>

<img src="../src/image4.png" alt="Proyekto na nakabukas sa VS Code" width="310" />

<br/>

> [!NOTE]
> Wala ka pa bang VS Code? Maaari mo itong i-download nang libre mula sa [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Ayos na!** Nakabukas na ang proyekto sa iyong editor at handa ka nang magsimulang mag-edit.

## 5. IDAGDAG ANG IYONG CONTRIBUTOR CARD

Ngayon ang pinakamasayang bahagi: pagdaragdag ng sarili mong card sa proyekto!

Sa loob ng direktoryo ng `assets/cards/`, gumawa ng bagong file na ipinangalan sa iyong GitHub username na sinusundan ng `.json`:

📄 `assets/cards/<iyong-username>.json` _(hal. `octocat.json`)_

### ESTRUKTURA

Ang iyong file ay dapat sumunod sa eksaktong estruktura tulad ng `jan.json`:

```json
{
  "name": "<iyong-username>",
  "img": "<url-ng-iyong-avatar>",
  "github": "https://github.com/<iyong-username>"
}
```

### PAANO MAKUHA ANG URL NG LARAWAN NG IYONG PROFILE (`IMG`):

1. Buksan ang pahina ng iyong profile sa GitHub sa browser (`https://github.com/<iyong-username>`).
2. I-right click ang larawan ng iyong profile at piliin ang **"Copy image address"**.
3. I-paste ang kinopyang URL sa field na `"img"`.

> [!NOTE]
> Mabilis na tip: Maaari mo ring gamitin ang `https://github.com/<iyong-username>.png` bilang direktang URL ng iyong larawan!

### HALIMBAWA

Kung ang iyong username ay `octocat`, gagawa ka ng `assets/cards/octocat.json` na may sumusunod na nilalaman:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

I-save ang file kapag tapos ka na. Kapag nagawa na, handa ka na para sa susunod na hakbang!

## 6. I-COMMIT AT I-PUSH ANG IYONG MGA PAGBABAGO

Bago gumawa ng Pull Request, kailangan mong i-save ang iyong mga pagbabago at i-upload ang iyong branch sa GitHub.

1. Buksan ang iyong terminal sa loob ng direktoryo ng proyekto at i-stage ang bagong file:

   ```bash
   git add assets/cards/<iyong-username>.json
   ```

2. I-commit ang mga pagbabago gamit ang maikli at malinaw na mensahe:

   ```bash
   git commit -m "feat: add <iyong-username> card"
   ```

3. I-push ang iyong branch sa iyong GitHub fork:

   ```bash
   git push origin <pangalan-ng-iyong-branch>
   ```

> [!NOTE]
> Kung hihingin, maaari mo ring patakbuhin ang `git push -u origin <pangalan-ng-iyong-branch>`.

## 7. GUMAWA NG PULL REQUEST

Ngayong naka-upload na ang iyong branch sa GitHub, oras na para isumite ang iyong ambag sa proyekto!

1. Pumunta sa pahina ng iyong fork sa GitHub (o bisitahin ang orihinal na repository: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. I-click ang **"Contribute"** button at piliin ang **"Open pull request"** (o i-click ang **"Compare & pull request"** button sa dilaw na banner):

   <br/>

   <img src="../src/image5.png" alt="Magbukas ng pull request" width="450" />

   <br/>

3. Tiyaking:
   - **Base repository:** `jaanque/good-first-issue` (branch `main`)
   - **Head repository:** ang iyong fork (ang iyong branch)
4. Sa pamagat at paglalarawan, malinaw na ipaliwanag kung ano ang iyong binago:
   - **Pamagat:** Maglagay ng malinaw na pamagat (hal. `Add <iyong-username> card`).
   - **Paglalarawan:** Sumulat ng maikling paglalarawan na nagpapaliwanag sa iyong binago (hal. idinagdag mo ang iyong contributor card sa `assets/cards/<iyong-username>.json`).
5. I-click ang berdeng pindutan na **Create pull request**!
