আপনি কি প্রথমবারের মতো Git এবং GitHub ব্যবহার করছেন? **আপনি একদম সঠিক জায়গায় এসেছেন!**

এই রিপোজিটরিটি তৈরি করা হয়েছে একটি নিরাপদ পরিবেশে কোনো কিছু নষ্ট করার ভয় ছাড়াই **ওপেন সোর্স (Open Source)** জগতে আপনার প্রথম পদক্ষেপ নিতে সহায়তা করার জন্য।

আমি বিশ্বাস করি শেখার সেরা উপায় হলো **হাতে-কলমে কাজ করা**, তাই আমি একটি সহজ প্রজেক্ট তৈরি করেছি যা আপনি সহজেই পরিবর্তন ও উন্নত করতে পারেন।

**আপনার উদ্দেশ্য সহজ:** প্রজেক্টে আপনার নাম এবং ছবি যোগ করার জন্য নিচের ধাপগুলো অনুসরণ করুন।

## ১. রিপোজিটরিটি FORK করুন

একটি **Fork** হলো আপনার নিজস্ব GitHub অ্যাকাউন্টে এই রিপোজিটরির একটি অনুলিপি। এটি মূল প্রজেক্টকে প্রভাবিত না করে নিরাপদে পরিবর্তন করার সুযোগ দেয়!

১. এই পৃষ্ঠার ওপরের ডানদিকের কোণায় যান এবং **Fork** বোতামে ক্লিক করুন:

   <br/>

   <img src="../src/image.png" alt="Fork বোতাম" width="400" />

   <br/>

২. **Create a new fork** পৃষ্ঠায়, রিপোজিটরির নাম অপরিবর্তিত রেখে **Create fork**-এ ক্লিক করুন।

৩. কয়েক সেকেন্ডের মধ্যে GitHub আপনাকে আপনার সদ্য তৈরি করা অনুলিপিতে নিয়ে যাবে:

   `https://github.com/<আপনার-ইউজারনেম>/good-first-issue`

🎉 **চমৎকার!** এখন আপনার কাছে প্রজেক্টের নিজস্ব কপি রয়েছে।

## ২. রিপোজিটরিটি CLONE করুন

এখন স্থানীয়ভাবে ফাইলগুলো সম্পাদনা করার জন্য আপনার কম্পিউটারে ফর্ক করা রিপোজিটরিটি ডাউনলোড করতে হবে।

১. GitHub-এ **আপনার ফর্ক করা রিপোজিটরি পৃষ্ঠায়**, সবুজ রঙের "**<> Code**" বোতামে ক্লিক করুন।
২. ড্রপডাউন মেনু থেকে **HTTPS** ট্যাবটি নির্বাচিত আছে তা নিশ্চিত করুন এবং কপি আইকনে ক্লিক করে রিপোজিটরি URL কপি করুন:

   <br/>

   <img src="../src/image2.png" alt="রিপোজিটরি ক্লোন করুন" width="360" />

   <br/>

৩. আপনার টার্মিনাল খুলুন এবং `git clone` কমান্ড লিখে তার পাশে কপি করা URL বসিয়ে চালান:

   ```bash
   git clone https://github.com/<আপনার-ইউজারনেম>/good-first-issue.git
   ```

   > [!IMPORTANT]
   > `<আপনার-ইউজারনেম>`-এর স্থানে আপনার আসল GitHub ইউজারনেম ব্যবহার করুন!

৪. ডাউনলোড সম্পন্ন হলে প্রজেক্ট ডিরেক্টরিতে প্রবেশ করুন:

   ```bash
   cd good-first-issue
   ```

🚀 **দুর্দান্ত!** প্রজেক্টের ফাইলগুলো এখন আপনার কম্পিউটারে রয়েছে এবং আপনি কাজ শুরু করতে প্রস্তুত।

## ৩. একটি নতুন ব্রাঞ্চ (BRANCH) তৈরি করুন

কোনো পরিবর্তন করার আগে একটি নতুন ব্রাঞ্চ তৈরি করা সর্বোত্তম পন্থা। আলাদা ব্রাঞ্চে কাজ করলে কাজ গোছানো থাকে এবং মূল `main` ব্রাঞ্চ সুরক্ষিত থাকে।

১. আপনার টার্মিনালে (`good-first-issue` ফোল্ডারের ভেতর), `git switch -c` কমান্ডের পাশে আপনার ব্রাঞ্চের নাম লিখে চালান:

   ```bash
   git switch -c <আপনার-ব্রাঞ্চের-নাম>
   ```

   _(একটি অর্থপূর্ণ নাম দিন, যেমন `add-আপনার-নাম` বা `যেকোনো-ব্রাঞ্চের-নাম`)_

২. Git নিশ্চিত করবে যে একটি নতুন ব্রাঞ্চ তৈরি হয়েছে এবং আপনি সেখানে স্থানান্তরিত হয়েছেন:

   <br/>

   <img src="../src/image3.png" alt="নতুন ব্রাঞ্চ তৈরি করুন" width="550" />

   <br/>

   > [!TIP]
   > পরামর্শ: আপনি যদি Git-এর পুরোনো সংস্করণ ব্যবহার করেন, তবে `git checkout -b <আপনার-ব্রাঞ্চের-নাম>` কমান্ডটিও ব্যবহার করতে পারেন।

🌿 **সব প্রস্তুত!** এখন থেকে আপনি যা পরিবর্তন করবেন তা এই নতুন ব্রাঞ্চেই সংরক্ষিত থাকবে।

## ৪. কোড এডিটরে প্রজেক্টটি খুলুন

এখন যখন আপনার কম্পিউটারে প্রজেক্টটি রয়েছে এবং ব্রাঞ্চ প্রস্তুত, তখন কোড এডিটরে এটি খোলার সময় এসেছে। এই নির্দেশিকায় আমরা **Visual Studio Code (VS Code)** ব্যবহার করছি, তবে আপনি আপনার পছন্দের যেকোনো এডিটর ব্যবহার করতে পারেন।

আপনার কমান্ড লাইনে VS Code কনফিগার করা থাকলে, `good-first-issue` ফোল্ডারের ভেতর থেকে নিচের কমান্ডটি চালান:

```bash
code .
```

বিকল্পভাবে, আপনি এটি ম্যানুয়ালি খুলতে পারেন:

১. **Visual Studio Code** চালু করুন।
২. **File** > **Open Folder...**-এ যান (বা Windows-এ `Ctrl + K, Ctrl + O` / macOS-এ `Cmd + O` চাপুন)।
৩. `good-first-issue` ফোল্ডারটি নির্বাচন করুন।

আপনি ফাইল এক্সপ্লোরারে প্রজেক্টের ফাইলগুলো দেখতে পাবেন:

<br/>

<img src="../src/image4.png" alt="VS Code-এ খোলা প্রজেক্ট" width="310" />

<br/>

> [!NOTE]
> এখনও VS Code ইনস্টল করা নেই? আপনি [code.visualstudio.com](https://code.visualstudio.com/) থেকে এটি বিনামূল্যে ডাউনলোড করতে পারেন।

💻 **সব প্রস্তুত!** প্রজেক্টটি এডিটরে খোলা হয়েছে এবং আপনি পরিবর্তন শুরু করতে পারেন।

## ৫. আপনার কন্ট্রিবিউটর কার্ড যোগ করুন

এবার সবচেয়ে আকর্ষণীয় ধাপ: প্রজেক্টে আপনার নিজস্ব কার্ড যোগ করা!

`assets/cards/` ডিরেক্টরির ভেতর, আপনার GitHub ইউজারনেম এবং শেষে `.json` যুক্ত করে একটি নতুন ফাইল তৈরি করুন:

📄 `assets/cards/<আপনার-ইউজারনেম>.json` _(যেমন `octocat.json`)_

### কাঠামো

আপনার ফাইলটির গঠন অবশ্যই `jan.json`-এর মতো হতে হবে:

```json
{
  "name": "<আপনার-ইউজারনেম>",
  "img": "<আপনার-প্রোফাইল-ছবির-url>",
  "github": "https://github.com/<আপনার-ইউজারনেম>"
}
```

### আপনার প্রোফাইল ছবির URL (`IMG`) যেভাবে পাবেন:

১. ব্রাউজারে আপনার GitHub প্রোফাইল পৃষ্ঠা খুলুন (`https://github.com/<আপনার-ইউজারনেম>`)।
২. আপনার প্রোফাইল ছবিতে রাইট-ক্লিক করুন এবং **"Copy image address"** নির্বাচন করুন।
৩. কপি করা সেই URL-টি `"img"` ফিল্ডে পেস্ট করুন।

> [!TIP]
> সহজ কৌশল: আপনি ছবির URL হিসেবে সরাসরি `https://github.com/<আপনার-ইউজারনেম>.png` ব্যবহার করতে পারেন!

### উদাহরণ

যদি আপনার ইউজারনেম `octocat` হয়, তবে আপনি `assets/cards/octocat.json` ফাইল তৈরি করে নিচের কোডটি লিখবেন:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

লেখা শেষ হলে ফাইলটি সেভ করুন। ফাইল তৈরি হলে আপনি পরবর্তী ধাপের জন্য প্রস্তুত!

## ৬. পরিবর্তনগুলো COMMIT এবং PUSH করুন

Pull Request তৈরির আগে আপনাকে পরিবর্তনগুলো সেভ করতে হবে এবং আপনার ব্রাঞ্চটি GitHub-এ আপলোড করতে হবে।

১. প্রজেক্ট ডিরেক্টরিতে টার্মিনাল খুলে নতুন ফাইলটি স্টেজ করুন:

   ```bash
   git add assets/cards/<আপনার-ইউজারনেম>.json
   ```

২. একটি সংক্ষিপ্ত এবং সুস্পষ্ট বার্তাসহ পরিবর্তনগুলো কমিট করুন:

   ```bash
   git commit -m "feat: add <আপনার-ইউজারনেম> card"
   ```

৩. ব্রাঞ্চটি আপনার GitHub ফর্কে পুশ করুন:

   ```bash
   git push origin <আপনার-ব্রাঞ্চের-নাম>
   ```

   > [!NOTE]
   > প্রয়োজনে আপনি `git push -u origin <আপনার-ব্রাঞ্চের-নাম>` কমান্ডটিও চালাতে পারেন।

## ৭. PULL REQUEST তৈরি করুন

এখন আপনার ব্রাঞ্চ GitHub-এ আপলোড হয়ে গেছে, এবার প্রজেক্টে আপনার অবদান জমা দেওয়ার সময়!

১. GitHub-এ আপনার ফর্ক পৃষ্ঠায় যান (বা মূল রিপোজিটরিতে যান: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue))।
২. **"Contribute"** বোতামে ক্লিক করে **"Open pull request"** নির্বাচন করুন (বা হলুদ ব্যানারের **"Compare & pull request"** বোতামে ক্লিক করুন):

   <br/>

   <img src="../src/image5.png" alt="Pull request খুলুন" width="450" />

   <br/>

৩. নিশ্চিত করুন যে:
   - **Base repository:** `jaanque/good-first-issue` (`main` ব্রাঞ্চ)
   - **Head repository:** আপনার ফর্ক (আপনার ব্রাঞ্চ)
৪. শিরোনাম ও বিবরণে আপনি কী পরিবর্তন করেছেন তা স্পষ্টভাবে লিখুন:
   - **Title (শিরোনাম):** একটি উপযুক্ত শিরোনাম দিন (যেমন `Add <আপনার-ইউজারনেম> card`)।
   - **Description (বিবরণ):** আপনি কী পরিবর্তন করেছেন তা সংক্ষেপে লিখুন (যেমন আপনি `assets/cards/<আপনার-ইউজারনেম>.json`-এ আপনার কন্ট্রিবিউটর কার্ড যোগ করেছেন)।
৫. সবুজ **Create pull request** বোতামে ক্লিক করুন!

### এবার কেবল আপনার PULL REQUEST পর্যালোচনার জন্য অপেক্ষা করুন। পর্যালোচনায় গৃহীত হলে আপনার কার্ডটি স্বয়ংক্রিয়ভাবে কন্ট্রিবিউটর শোকেসে যুক্ত হয়ে যাবে।

সবার অবদানের সরাসরি ফলাফল আপনি এখানে দেখতে পারেন:
