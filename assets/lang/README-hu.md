##

Először használsz Git-et és GitHub-ot? **A legjobb helyen jársz!**

Ez a tárhely azért készült, hogy segítsen megtenni az első lépéseket a **Nyílt Forráskód (Open Source)** világában egy biztonságos környezetben, anélkül, hogy félned kellene bármi elrontásától.

Hiszek abban, hogy a tanulás legjobb módja a **gyakorlat**, ezért készítettem egy egyszerű projektet, amelyet könnyedén módosíthatsz és bővíthetsz.

**A küldetésed egyszerű:** Kövesd a lépésről lépésre szóló utasításokat, hogy hozzáadd a neved és képed a projekthez.

**Készen állsz?** Ugorj az **1. lépésre**, és hozzunk létre valami varázslatosat!

## 1. FORKOLD A REPOZITÓRIUMOT

A **fork** a saját másolatod erről a repozitóriumról a GitHub fiókodon. Lehetővé teszi, hogy biztonságosan módosíts dolgokat anélkül, hogy az eredeti projektet érintenéd!

1. Lépj az oldal jobb felső sarkába, és kattints a **Fork** gombra:

   <br/>

   <img src="../src/image.png" alt="Fork gomb" width="400" />

   <br/>

2. A **Create a new fork** oldalon hagyd a repozitórium nevét úgy, ahogy van, és kattints a **Create fork** gombra.

3. Pár másodperc múlva a GitHub átirányít az újonnan létrehozott másolatodra:

   `https://github.com/<felhasznaloneved>/good-first-issue`

🎉 **Nagyszerű!** Most már van egy saját munkapéldányod a projektből.

## 2. KLÓNOZD A REPOZITÓRIUMOT

Most le kell töltened a forkrepódat a számítógépedre, hogy helyben szerkeszthesd a fájlokat.

1. A **forkolt repozitóriumod oldalán** a GitHubon kattints a zöld "**<> Code**" gombra.
2. A legördülő menüben ellenőrizd, hogy a **HTTPS** fül van-e kiválasztva, majd kattints a másolás ikonra a repozitórium URL-jének másolásához:

   <br/>

   <img src="../src/image2.png" alt="Repozitórium klónozása" width="360" />

   <br/>

3. Nyisd meg a terminált, és futtasd a `git clone` parancsot a másolt URL-lel:

   ```bash
   git clone https://github.com/<felhasznaloneved>/good-first-issue.git
   ```

> [!NOTE]
> Cseréld le a `<felhasznaloneved>` részt a valódi GitHub felhasználónevedre!

4. Ha a letöltés befejeződött, lépj be a projekt könyvtárába:

   ```bash
   cd good-first-issue
   ```

🚀 **Szép munka!** Most már megvannak a projektfájlok a helyi gépeden, és készen állsz a módosításokra.

## 3. HOZZ LÉTRE EGY ÚJ ÁGAT (BRANCH)

Mielőtt bármit módosítanál, érdemes egy új ágat létrehozni. A külön ágon végzett munka rendszerezett marad, és a `main` ágat tisztán tartja.

1. A terminálban (a `good-first-issue` mappán belül) futtasd a `git switch -c` parancsot az új ág nevével:

   ```bash
   git switch -c <uj-ag-neve>
   ```

   _(Adj neki egy leíró nevet, például `add-neved` vagy amit szeretnél)_

2. A Git megerősíti, hogy létrehozta az új ágat, és átváltott rá:

   <br/>

   <img src="../src/image3.png" alt="Új ág létrehozása" width="550" />

   <br/>

> [!NOTE]
> Tipp: Ha régebbi Git verziót használsz, a `git checkout -b <uj-ag-neve>` parancsot is használhatod.

🌿 **Minden kész!** Bármilyen módosítást végzel ezután, az az új ágadban marad.

## 4. NYISD MEG A PROJEKTET A KÓDSZERKESZTŐDBEN

Most, hogy helyben megvan a projekt, és az ágad is készen áll, ideje megnyitni a kódszerkesztőben. Ebben az útmutatóban a **Visual Studio Code (VS Code)**-ot használjuk, de bármilyen szerkesztőt használhatsz.

Ha a VS Code be van állítva a parancssorban, egyszerűen futtasd a következő parancsot a `good-first-issue` mappából:

```bash
code .
```

Alternatív megoldásként manuálisan is megnyithatod:

1. Nyisd meg a **Visual Studio Code**-ot.
2. Menj a **Fájl** > **Mappa megnyitása...** menüpontra (vagy nyomd le a `Ctrl + K, Ctrl + O` billentyűket Windowson / `Cmd + O` billentyűket macOS-en).
3. Válaszd ki a `good-first-issue` mappát.

A projektfájlokat látnod kell az intézőben:

<br/>

<img src="../src/image4.png" alt="VS Code-ban megnyitott projekt" width="310" />

<br/>

> [!NOTE]
> Még nincs telepítve a VS Code? Ingyesen letöltheted a [code.visualstudio.com](https://code.visualstudio.com/) oldalról.

💻 **Kész!** A projekt nyitva van a szerkesztődben, és készen állsz a szerkesztésre.

## 5. ADD HOZZÁ A KÖZREMŰKÖDŐI KÁRTYÁDAT

Most jön a szórakoztató rész: add hozzá a saját kártyádat a projekthez!

Az `assets/cards/` könyvtárban hozz létre egy új fájlt a GitHub felhasználóneveddel, amelyet `.json` követ:

📄 `assets/cards/<felhasznaloneved>.json` _(pl. `octocat.json`)_

### FELÉPÍTÉS

A fájlodnak pontosan ugyanazt a szerkezetet kell követnie, mint a `jan.json`-nak:

```json
{
  "name": "<felhasznaloneved>",
  "img": "<profilkeped-urlje>",
  "github": "https://github.com/<felhasznaloneved>"
}
```

### HOGYAN SZEREZD MEG A PROFILKÉPED URL-JÉT (`IMG`):

1. Nyisd meg a GitHub profilodat a böngészőben (`https://github.com/<felhasznaloneved>`).
2. Kattints jobb gombbal a profilképedre, és válaszd a **"Kép címének másolása"** (vagy **"Copy image address"**) lehetőséget.
3. Illeszd be a másolt URL-t az `"img"` mezőbe.

> [!NOTE]
> Gyors tipp: A `https://github.com/<felhasznaloneved>.png` címet is használhatod képed URL-jeként!

### PÉLDA

Ha a felhasználóneved `octocat`, akkor az `assets/cards/octocat.json` fájlt hoznád létre a következő tartalommal:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Mentsd el a fájlt, ha végeztél. Miután elkészült, készen állsz a következő lépésre!

## 6. COMMITOLD ÉS PUSHOLD A VÁLTOZTATÁSAIDAT

A Pull Request létrehozása előtt el kell mentened a változtatásokat, és fel kell töltened az ágad a GitHubra.

1. Nyisd meg a terminált a projekt könyvtárában, és add hozzá az új fájlt:

   ```bash
   git add assets/cards/<felhasznaloneved>.json
   ```

2. Végezz commitot egy rövid és leíró üzenettel:

   ```bash
   git commit -m "feat: add <felhasznaloneved> card"
   ```

3. Töltsd fel (push) az ágat a GitHub forkodba:

   ```bash
   git push origin <uj-ag-neve>
   ```

> [!NOTE]
> Ha kéri, a `git push -u origin <uj-ag-neve>` parancsot is futtathatod.

## 7. HOZD LÉTRE A PULL REQUESTET

Most, hogy az ágad felkerült a GitHubra, ideje beküldeni a hozzájárulásodat a projektbe!

1. Nyisd meg a forkod oldalát a GitHubon (vagy látogass el az eredeti repozitóriumhoz: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Kattints a **"Contribute"** gombra, és válaszd az **"Open pull request"** lehetőséget (vagy kattints a sárga sávban található **"Compare & pull request"** gombra):

   <br/>

   <img src="../src/image5.png" alt="Pull request megnyitása" width="450" />

   <br/>

3. Ellenőrizd:
   - **Base repository:** `jaanque/good-first-issue` (`main` ág)
   - **Head repository:** a te forkod (a te ágad)
4. A címben és leírásban pontosan mutasd be a módosításokat:
   - **Cím:** Adj meg egy leíró címet (pl. `Add <felhasznaloneved> card`).
   - **Leírás:** Írj egy rövid magyarázatot arról, mit változtattál (pl. hogy hozzáadtad a közreműködői kártyádat az `assets/cards/<felhasznaloneved>.json` fájlban).
5. Kattints a zöld **Create pull request** gombra!

### MOST MÁR CSAK VÁRNOD KELL A PULL REQUEST ÁTTEKINTÉSÉRE. AZ ELLENŐRZÉS ÉS ELFOGADÁS UTÁN A KÁRTYÁD AUTOMATIKUSAN MEGJELENIK A KÖZREMŰKÖDŐK BEMUTATÓFALÁN.

Itt tekintheted meg élőben az összes közreműködő munkáját:
