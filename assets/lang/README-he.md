##

זו הפעם הראשונה שלכם עם Git ו-GitHub? **הגעתם למקום הנכון!**

מאגר זה נועד לעזור לכם לעשות את צעדיכם הראשונים בעולם ה-**קוד פתוח (Open Source)** בסביבה בטוחה, ללא חשש לשבור שום דבר.

אני מאמין שהדרך הטובה ביותר ללמוד היא על ידי **עשייה בפועל**, לכן יצרתי פרויקט פשוט שתוכלו לערוך ולשפר בקלות.

**המשימה שלכם פשוטה:** עקבו אחר ההוראות שלב אחר שלב כדי להוסיף את שמכם ותמונתכם לפרויקט.

**מוכנים להתחיל?** עברו אל **שלב 1** ובואו ניצור קסם!

| :--- | :---: | :--- | :--- |
| **חשבון GitHub** | <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/github/github-original.svg" width="30" height="30" alt="GitHub" /> | צרו חשבון כדי לאחסן קוד ולתרום לפרויקטים | [הרשמה](https://github.com/signup) |

## 1. בצעו FORK למאגר

**Fork** הוא עותק משלכם של מאגר זה בחשבון ה-GitHub שלכם. הוא מאפשר לכם לבצע שינויים בבטחה מבלי להשפיע על הפרויקט המקורי!

1. עברו לפינה הימנית העליונה (או השמאלית העליונה) של עמוד זה ולחצו על כפתור ה-**Fork**:

   <br/>

   <img src="../src/image.png" alt="כפתור Fork" width="400" />

   <br/>

2. בעמוד **Create a new fork**, השאירו את שם המאגר כפי שהוא ולחצו על **Create fork**.

3. לאחר מספר שניות, GitHub יעביר אתכם לעותק החדש שיצרתם בכתובת:

   `https://github.com/<your-username>/good-first-issue`

🎉 **מצוין!** כעת יש לכם עותק עבודה אישי של הפרויקט.

## 2. שכבלו (CLONE) את המאגר

כעת עליכם להוריד את המאגר המשוכפל למחשב שלכם כדי לערוך את הקבצים באופן מקומי.

1. ב-**עמוד המאגר המשוכפל שלכם** ב-GitHub, לחצו על הכפתור הירוק "**<> Code**".
2. בתפריט שנפתח, ודאו שלשונית ה-**HTTPS** נבחרה ולחצו על סמל ההעתקה כדי להעתיק את כתובת ה-URL של המאגר:

   <br/>

   <img src="../src/image2.png" alt="שכפול מאגר" width="360" />

   <br/>

3. פתחו את הטרמינל והריצו את הפקודה `git clone` בצירוף ה-URL שהעתקתם:

   ```bash
   git clone https://github.com/<your-username>/good-first-issue.git
   ```

   > [!IMPORTANT]
   > החליפו את `<your-username>` בשם המשתמש האמיתי שלכם ב-GitHub!

4. לאחר סיום ההורדה, היכנסו לתיקיית הפרויקט:

   ```bash
   cd good-first-issue
   ```

🚀 **עבודה מעולה!** קבצי הפרויקט נמצאים כעת במחשב שלכם ואתם מוכנים לבצע שינויים.

## 3. צרו ענף (BRANCH) חדש

לפני ביצוע שינויים כלשהם, מומלץ ליצור ענף חדש. עבודה בענף נפרד שומרת על הסדר ומותירה את ענף ה-`main` נקי.

1. בטרמינל (בתוך תיקיית `good-first-issue`), הריצו את הפקודה `git switch -c` בצירוף שם הענף שלכם:

   ```bash
   git switch -c <branch-name>
   ```

   _(בחרו שם תיאורי, למשל `add-your-name` או כל שם שתרצו)_

2. Git יאשר שיצרתם ועברתם לענף החדש:

   <br/>

   <img src="../src/image3.png" alt="יצירת ענף חדש" width="550" />

   <br/>

   > [!TIP]
   > טיפ: אם אתם משתמשים בגרסה ישנה יותר של Git, תוכלו להשתמש גם ב-`git checkout -b <branch-name>`.

🌿 **הכל מוכן!** כל שינוי שתבצעו מעתה והלאה יישמר בענף החדש שלכם.

## 4. פתחו את הפרויקט בעורך הקוד שלכם

כעת, כשהפרויקט אצלכם במחשב והענף מוכן, הגיע הזמן לפתוח אותו בעורך הקוד. במדריך זה נשתמש ב-**Visual Studio Code (VS Code)**, אך תוכלו להשתמש בכל עורך אחר שתבחרו.

אם VS Code מוגדר אצלכם בשורת הפקודה, פשוט הריצו את הפקודה הבאה מתוך תיקיית `good-first-issue`:

```bash
code .
```

לחלופין, תוכלו לפתוח אותו ידנית:

1. פתחו את **Visual Studio Code**.
2. גשו אל **File** > **Open Folder...** (או לחצו על `Ctrl + K, Ctrl + O` ב-Windows / `Cmd + O` ב-macOS).
3. בחרו בתיקיית `good-first-issue`.

כעת תראו את קבצי הפרויקט בסייר הקבצים:

<br/>

<img src="../src/image4.png" alt="פרויקט פתוח ב-VS Code" width="310" />

<br/>

> [!NOTE]
> עדיין לא התקנתם את VS Code? תוכלו להוריד אותו בחינם מ-[code.visualstudio.com](https://code.visualstudio.com/).

💻 **מוכן!** הפרויקט פתוח כעת בעורך שלכם ואתם מוכנים להתחיל לערוך.

## 5. הוסיפו את כרטיס התורם שלכם

עכשיו מגיע החלק המהנה: הוספת הכרטיס האישי שלכם לפרויקט!

בתוך התיקייה `assets/cards/`, צרו קובץ חדש עם שם המשתמש שלכם ב-GitHub ואחריו `.json`:

📄 `assets/cards/<your-username>.json` _(לדוגמה `octocat.json`)_

### מבנה

הקובץ שלכם חייב להיות בעל מבנה זהה בדיוק לזה של `jan.json`:

```json
{
  "name": "<your-username>",
  "img": "<avatar-url>",
  "github": "https://github.com/<your-username>"
}
```

### כיצד להשיג את כתובת ה-URL של תמונת הפרופיל שלכם (`IMG`):

1. פתחו את פרופיל ה-GitHub שלכם בדפדפן (`https://github.com/<your-username>`).
2. לחצו לחיצה ימנית על תמונת הפרופיל שלכם ובחרו ב-**"העתק כתובת תמונה"** (או **"Copy image address"**).
3. הדביקו את ה-URL שהעתקתם בשדה `"img"`.

> [!TIP]
> טיפ מהיר: תוכלו גם להשתמש בכתובת `https://github.com/<your-username>.png` ככתובת התמונה!

### דוגמה

אם שם המשתמש שלכם הוא `octocat`, תיצרו את הקובץ `assets/cards/octocat.json` עם התוכן הבא:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

שמרו את הקובץ בסיום. לאחר יצירתו, אתם מוכנים לשלב הבא!

## 6. בצעו COMMIT ו-PUSH לשינויים שלכם

לפני יצירת ה-Pull Request, עליכם לשמור את השינויים ולהעלות את הענף שלכם ל-GitHub.

1. פתחו את הטרמינל בתוך תיקיית הפרויקט והכינו את הקובץ החדש:

   ```bash
   git add assets/cards/<your-username>.json
   ```

2. בצעו commit לשינויים עם הודעה קצרה ותיאורית:

   ```bash
   git commit -m "feat: add <your-username> card"
   ```

3. העלו את הענף שלכם ל-fork שלכם ב-GitHub:

   ```bash
   git push origin <branch-name>
   ```

   > [!NOTE]
   > אם תתבקשו, תוכלו גם להריץ `git push -u origin <branch-name>`.

## 7. צרו את ה-PULL REQUEST

כעת, כשהענף שלכם עלה ל-GitHub, הגיע הזמן לשלוח את התרומה שלכם לפרויקט!

1. עברו לעמוד ה-fork שלכם ב-GitHub (או בקרו במאגר המקורי: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. לחצו על כפתור **"Contribute"** ובחרו ב-**"Open pull request"** (או לחצו על כפתור **"Compare & pull request"** בסרגל הצהוב):

   <br/>

   <img src="../src/image5.png" alt="פתיחת Pull Request" width="450" />

   <br/>

3. ודאו כי:
   - **Base repository:** `jaanque/good-first-issue` (ענף `main`)
   - **Head repository:** ה-fork שלכם (הענף שלכם)
4. בכותרת ובתיאור, הסבירו בבירור מה שיניתם:
   - **כותרת:** הוסיפו כותרת תיאורית (למשל `Add <your-username> card`).
   - **תיאור:** כתבו תיאור קצר המסביר מה עשיתם (למשל שהוספתם את כרטיס התורם שלכם ב-`assets/cards/<your-username>.json`).
5. לחצו על הכפתור הירוק **Create pull request**!

### כעת נותר רק להמתין לבדיקת ה-PULL REQUEST שלכם. לאחר הבדיקה והאישור, הכרטיס שלכם יתווסף אוטומטית ללוח התורמים.
