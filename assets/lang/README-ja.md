##

Git と GitHub を使うのは初めてですか？ **ここがぴったりの場所です！**

このリポジトリは、何も壊す心配のない安全な環境で、**オープンソース（Open Source）** の世界への第一歩を踏み出せるように作られています。

一番の学習方法は **「実際にやってみること」** だと考えています。そのため、誰でも簡単に変更して改善できるシンプルなプロジェクトを用意しました。

**あなたのミッションはとてもシンプル：** ステップごとの手順に従って、あなたの名前と写真をプロジェクトに追加するだけです。

**始める準備はできましたか？** それでは **ステップ 1** に進んで、最初の一歩を踏み出しましょう！

## 基本ツール

始める前に、以下の基本的なツールが準備できていることを確認してください：

| ツール                |                                                               Logo                                                               | 説明                                                 | リンク                                             |
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------: | :--------------------------------------------------- | :------------------------------------------------- |
| **GitHub アカウント** | <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/github/github-original.svg" width="30" height="30" alt="GitHub" />  | コードをホストして貢献するためのアカウントを作成     | [サインアップ](https://github.com/signup)          |
| **Git**               |      <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/git/git-original.svg" width="30" height="30" alt="Git" />      | コードの変更を管理するためのバージョン管理ツール     | [ダウンロード](https://git-scm.com/downloads)     |
| **VS Code**           | <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/vscode/vscode-original.svg" width="30" height="30" alt="VS Code" /> | おすすめのコードエディタ _（またはお好みのエディタ）_ | [ダウンロード](https://code.visualstudio.com/download) |

## 1. リポジトリをフォーク（FORK）する

**フォーク（Fork）** とは、このリポジトリをご自身の GitHub アカウント配下に複製することです。元のプロジェクトに影響を与えることなく、安全に変更を加えることができます！

1. このページの右上にある **Fork** ボタンをクリックします：

   <br/>

   <img src="../src/image.png" alt="Fork ボタン" width="400" />

   <br/>

2. **Create a new fork** ページで、リポジトリ名はそのままにして **Create fork** をクリックします。

3. 数秒後、GitHub によって新しく作成されたあなたのコピー先にリダイレクトされます：

   `https://github.com/<あなたのユーザー名>/good-first-issue`

🎉 **素晴らしい！** これであなた専用のプロジェクトコピーができました。

## 2. リポジトリをクローン（CLONE）する

ローカルでファイルを編集できるように、フォークしたリポジトリをお使いのパソコンにダウンロードします。

1. GitHub の **フォークしたリポジトリのページ** で、緑色の「**<> Code**」ボタンをクリックします。
2. ドロップダウンメニューで **HTTPS** タブが選択されていることを確認し、コピーアイコンをクリックしてリポジトリの URL をコピーします：

   <br/>

   <img src="../src/image2.png" alt="リポジトリのクローン" width="360" />

   <br/>

3. ターミナルを開き、`git clone` コマンドに続けてコピーした URL を入力して実行します：

   ```bash
   git clone https://github.com/<あなたのユーザー名>/good-first-issue.git
   ```

   > 💡 _`<あなたのユーザー名>` は、実際の GitHub ユーザー名に置き換えてください！_

4. ダウンロードが完了したら、プロジェクトのディレクトリに移動します：

   ```bash
   cd good-first-issue
   ```

🚀 **よくできました！** プロジェクトのファイルが手元のパソコンに保存され、変更を加える準備が整いました。

## 3. 新しいブランチを作成する

変更を加える前に、新しいブランチを作成するのがベストプラクティスです。別のブランチで作業することで作業内容が整理され、`main` ブランチをクリーンな状態に保つことができます。

1. ターミナルで（`good-first-issue` フォルダ内で）、`git switch -c` コマンドに続けてブランチ名を入力して実行します：

   ```bash
   git switch -c <あなたのブランチ名>
   ```

   _（`add-your-name` や `任意のブランチ名` など、わかりやすい名前を付けましょう）_

2. Git により、新しいブランチが作成されて切り替わったことが表示されます：

   <br/>

   <img src="../src/image3.png" alt="新しいブランチの作成" width="550" />

   <br/>

   > 💡 _ヒント: 古いバージョンの Git をお使いの場合は、`git checkout -b <あなたのブランチ名>` も使用できます。_

🌿 **準備完了です！** 今後行う変更はすべてこの新しいブランチ内に保持されます。

## 4. コードエディタでプロジェクトを開く

プロジェクトがローカルにあり、ブランチも準備できたので、コードエディタで開きましょう。このガイドでは **Visual Studio Code (VS Code)** を使用しますが、お好きなエディタで構いません。

コマンドラインで VS Code が使えるよう設定されている場合は、`good-first-issue` フォルダ内で次のコマンドを実行するだけです：

```bash
code .
```

または、手動で開くこともできます：

1. **Visual Studio Code** を起動します。
2. **File** > **Open Folder...**（Windows は `Ctrl + K, Ctrl + O` / macOS は `Cmd + O`）を選択します。
3. `good-first-issue` フォルダを選択します。

エクスプローラーにプロジェクトファイルが表示されます：

<br/>

<img src="../src/image4.png" alt="VS Code で開いたプロジェクト" width="310" />

<br/>

> 💡 _VS Code をまだインストールしていませんか？ [code.visualstudio.com](https://code.visualstudio.com/) から無料でダウンロードできます。_

💻 **準備完了！** エディタでプロジェクトが開かれ、編集を開始できます。

## 5. コントリビューターカードを追加する

ここからが一番楽しいステップです。プロジェクトにあなた自身のカードを追加しましょう！

`assets/cards/` ディレクトリの中に、あなたの GitHub ユーザー名に `.json` を付けた新しいファイルを作成します：

📄 `assets/cards/<あなたのユーザー名>.json` _（例：`octocat.json`）_

### 構造

ファイルは `jan.json` とまったく同じ構造にする必要があります：

```json
{
  "name": "<あなたのユーザー名>",
  "img": "<あなたのアバターURL>",
  "github": "https://github.com/<あなたのユーザー名>"
}
```

### プロフィール画像の URL（`IMG`）の取得方法：

1. ブラウザで GitHub のプロフィールページを開きます（`https://github.com/<あなたのユーザー名>`）。
2. プロフィール画像を右クリックし、**「画像アドレスをコピー」**（または **"Copy image address"**）を選択します。
3. コピーした URL を `"img"` フィールドに貼り付けます。

> 💡 _プチ裏技：画像 URL として `https://github.com/<あなたのユーザー名>.png` をそのまま使うこともできます！_

### 例

もしユーザー名が `octocat` の場合、以下の内容で `assets/cards/octocat.json` を作成します：

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

終わったらファイルを保存します。ファイルが作成できたら、次のステップに進みましょう！

## 6. 変更をコミットしてプッシュ（PUSH）する

Pull Request を作成する前に、変更を保存してブランチを GitHub にアップロードする必要があります。

1. プロジェクトディレクトリ内でターミナルを開き、新しいファイルをステージングします：

   ```bash
   git add assets/cards/<あなたのユーザー名>.json
   ```

2. 簡潔でわかりやすいメッセージとともに変更をコミットします：

   ```bash
   git commit -m "feat: add <あなたのユーザー名> card"
   ```

3. ブランチを GitHub 上のフォークにプッシュします：

   ```bash
   git push origin <あなたのブランチ名>
   ```

   > 💡 _メッセージが表示された場合は、`git push -u origin <あなたのブランチ名>` を実行しても構いません。_

## 7. PULL REQUEST を作成する

ブランチが GitHub にプッシュされたので、プロジェクトに貢献を提出しましょう！

1. GitHub のフォークページに移動します（または元のリポジトリ [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue) にアクセスします）。
2. **「Contribute」** ボタンをクリックして **「Open pull request」** を選択します（または黄色いバナーの **「Compare & pull request」** ボタンをクリックします）：

   <br/>

   <img src="../src/image5.png" alt="Pull Request を開く" width="450" />

   <br/>

3. 次の内容を確認します：
   - **Base repository:** `jaanque/good-first-issue`（`main` ブランチ）
   - **Head repository:** あなたのフォーク（あなたのブランチ）
4. タイトルと説明文で、変更内容を分かりやすく記載します：
   - **タイトル：** わかりやすいタイトルを入力します（例：`Add <あなたのユーザー名> card`）。
   - **説明：** 変更した内容を簡潔に説明します（例：`assets/cards/<あなたのユーザー名>.json` にコントリビューターカードを追加した旨など）。
5. 緑色の **Create pull request** ボタンをクリックします！

### あとは PULL REQUEST のレビューを待つだけです。レビューで承認されると、あなたのカードがコントリビューター一覧に自動的に追加されます。

これまでのコントリビューターのみなさんの成果はこちらからリアルタイムで確認できます：
👉 **[コントリビューター一覧](https://jaanque.github.io/good-first-issue/)**

##

覚えておいてください。これはほんの始まりに過ぎません！ あなたの貢献を待っているオープンソースプロジェクトは何千と存在し、その手順はどこでも基本的には同じです：リポジトリをフォークし、ブランチを作成し、変更を加えて、Pull Request を送信するだけです。
