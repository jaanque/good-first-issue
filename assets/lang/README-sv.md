##

Är det första gången du använder Git och GitHub? **Då har du kommit helt rätt!**

Detta repository är utformat för att hjälpa dig ta dina första steg i **Open Source**-världen i en trygg miljö, utan rädsla för att ha sönder något.

Jag tror att det bästa sättet att lära sig är genom att **göra**, så jag har skapat ett enkelt projekt som du smidigt kan ändra och förbättra.

**Ditt uppdrag är enkelt:** Följ steg-för-steg-instruktionerna för att lägga till ditt namn och foto i projektet.

**Redo att sätta igång?** Gå till **Steg 1** så skapar vi lite magi!

## 1. FORKA DETTA REPOSITORY

En **fork** är din egen kopia av detta repository på ditt GitHub-konto. Det låter dig göra ändringar säkert utan att påverka originalprojektet!

1. Gå till det övre högra hörnet på denna sida och klicka på knappen **Fork**:

   <br/>

   <img src="../src/image.png" alt="Fork-knapp" width="400" />

   <br/>

2. På sidan **Create a new fork**, lämna namnet på repositoryt som det är och klicka på **Create fork**.

3. Efter några sekunder kommer GitHub att omdirigera dig till din nyskapade kopia på:

   `https://github.com/<ditt-anvandarnamn>/good-first-issue`

🎉 **Grymt!** Nu har du din egen arbetskopia av projektet.

## 2. KLONA DETTA REPOSITORY

Nu behöver du ladda ner ditt forkade repository till din dator så att du kan redigera filerna lokalt.

1. På **sidan för ditt forkade repository** på GitHub klickar du på den gröna knappen "**<> Code**".
2. I rullgardinsmenyn, se till att fliken **HTTPS** är vald och klicka på kopieringsikonen för att kopiera URL:en:

   <br/>

   <img src="../src/image2.png" alt="Klona repository" width="360" />

   <br/>

3. Öppna din terminal och kör kommandot `git clone` följt av den kopierade URL:en:

   ```bash
   git clone https://github.com/<ditt-anvandarnamn>/good-first-issue.git
   ```

   > 💡 _Ersätt `<ditt-anvandarnamn>` med ditt riktiga användarnamn på GitHub!_

4. När nedladdningen är klar går du in i projektmappen:

   ```bash
   cd good-first-issue
   ```

🚀 **Bra jobbat!** Nu har du projektfilerna på din lokala dator och är redo att göra ändringar.

## 3. SKAPA EN NY BRANCH (GREN)

Innan du gör några ändringar är det god praxis att skapa en ny branch. Att arbeta i en separat gren håller ditt arbete organiserat och huvudgrenen `main` ren.

1. I din terminal (i mappen `good-first-issue`), kör kommandot `git switch -c` med namnet på din gren:

   ```bash
   git switch -c <ditt-grennamn>
   ```

   _(Välj ett beskrivande namn, till exempel `add-ditt-namn` eller vad du vill)_

2. Git bekräftar att du har skapat och bytt till din nya gren:

   <br/>

   <img src="../src/image3.png" alt="Skapa ny gren" width="550" />

   <br/>

   > 💡 _Tips: Om du använder en äldre version av Git kan du även köra `git checkout -b <ditt-grennamn>`._

🌿 **Allt klart!** Alla ändringar du gör framöver kommer att hållas inom din nya gren.

## 4. ÖPPNA PROJEKTET I DIN KODREDIGERARE

Nu när du har projektet lokalt och din gren är redo är det dags att öppna det i din kodredigerare. I denna guide använder vi **Visual Studio Code (VS Code)**, men du kan använda vilken editor du vill.

Om du har konfigurerat VS Code i kommandotolken, kör helt enkelt följande kommando inifrån mappen `good-first-issue`:

```bash
code .
```

Alternativt kan du öppna det manuellt:

1. Öppna **Visual Studio Code**.
2. Gå till **Arkiv** > **Öppna mapp...** (eller tryck `Ctrl + K, Ctrl + O` i Windows / `Cmd + O` i macOS).
3. Välj mappen `good-first-issue`.

Du bör nu se projektfilerna i filutforskaren:

<br/>

<img src="../src/image4.png" alt="Projekt öppnat i VS Code" width="310" />

<br/>

> 💡 _Har du inte installerat VS Code än? Du kan ladda ner det gratis från [code.visualstudio.com](https://code.visualstudio.com/)._

💻 **Klart!** Projektet är nu öppet i din editor och du är redo att börja redigera.

## 5. LÄGG TILL DITT BIDRAGSKORT

Nu kommer den roliga biten: att lägga till ditt eget kort i projektet!

I mappen `assets/cards/`, skapa en ny fil med ditt GitHub-användarnamn följt av `.json`:

📄 `assets/cards/<ditt-anvandarnamn>.json` _(t.ex. `octocat.json`)_

### STRUKTUR

Din fil måste följa exakt samma struktur som `jan.json`:

```json
{
  "name": "<ditt-anvandarnamn>",
  "img": "<url-till-ditt-avatar>",
  "github": "https://github.com/<ditt-anvandarnamn>"
}
```

### HUR DU HITTAR URL:EN TILL DIN PROFILBILD (`IMG`):

1. Öppna din GitHub-profil i webbläsaren (`https://github.com/<ditt-anvandarnamn>`).
2. Högerklicka på din profilbild och välj **"Kopiera bildadress"** (eller **"Copy image address"**).
3. Klistra in den kopierade URL:en i fältet `"img"`.

> 💡 _Snabbtips: Du kan också använda `https://github.com/<ditt-anvandarnamn>.png` som bildens URL!_

### EXEMPEL

Om ditt användarnamn är `octocat` skapar du `assets/cards/octocat.json` med följande innehåll:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Spara filen när du är klar. När den är skapad är du redo för nästa steg!

## 6. GÖR COMMIT OCH PUSH PÅ DINA ÄNDRINGAR

Innan du skapar en Pull Request måste du spara dina ändringar och ladda upp din gren till GitHub.

1. Öppna din terminal i projektkatalogen och förbered din nya fil:

   ```bash
   git add assets/cards/<ditt-anvandarnamn>.json
   ```

2. Gör en commit av ändringarna med ett kort och beskrivande meddelande:

   ```bash
   git commit -m "feat: add <ditt-anvandarnamn> card"
   ```

3. Ladda upp din gren till din fork på GitHub:

   ```bash
   git push origin <ditt-grennamn>
   ```

   > 💡 _Om du uppmanas kan du också köra `git push -u origin <ditt-grennamn>`._

## 7. SKAPA EN PULL REQUEST

Nu när din gren är uppladdad till GitHub är det dags att skicka in ditt bidrag till projektet!

1. Gå till sidan för din fork på GitHub (eller besök originalprojektet: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Klicka på knappen **"Contribute"** och välj **"Open pull request"** (eller klicka på knappen **"Compare & pull request"** i den gula bannern):

   <br/>

   <img src="../src/image5.png" alt="Öppna pull request" width="450" />

   <br/>

3. Kontrollera att:
   - **Base repository:** `jaanque/good-first-issue` (gren `main`)
   - **Head repository:** din fork (din gren)
4. I titel och beskrivning, förklara tydligt vad du har ändrat:
   - **Titel:** Lägg till en beskrivande titel (t.ex. `Add <ditt-anvandarnamn> card`).
   - **Beskrivning:** Skriv en kort förklaring om vad du ändrade (t.ex. att du lade till ditt bidragskort i `assets/cards/<ditt-anvandarnamn>.json`).
5. Klicka på den gröna knappen **Create pull request**!

### NU BEHÖVER DU BARA VÄNTA PÅ GRANSKNINGEN AV DIN PULL REQUEST. EFTER GODKÄNNANDE LÄGGS DITT KORT AUTOMATISKT TILL I GALLERIET FÖR BIDRAGSGIVARE.

Du kan se live-resultatet av alla bidrag här:
👉 **[Våra bidragsgivare](https://jaanque.github.io/good-first-issue/)**

Du har precis skickat in ditt allra första bidrag till Open Source-världen! När det har slagits samman kommer ditt kort automatiskt att synas i galleriet.
