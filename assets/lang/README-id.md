##

Apakah ini pertama kalinya Anda menggunakan Git dan GitHub? **Anda berada di tempat yang tepat!**

Repositori ini dirancang untuk membantu Anda mengambil langkah pertama di dunia **Open Source** dalam lingkungan yang aman, tanpa rasa takut merusak apa pun.

Saya percaya bahwa cara terbaik untuk belajar adalah **dengan praktik langsung**, jadi saya telah membuat proyek sederhana yang dapat Anda ubah dan tingkatkan dengan mudah.

**Misi Anda sederhana:** Ikuti panduan langkah demi langkah untuk menambahkan nama dan foto Anda ke dalam proyek ini.

**Siap untuk memulai?** Buka **Langkah 1** dan mari kita mulai!

## 1. FORK REPOSITORI INI

**Fork** adalah salinan repositori ini di bawah akun GitHub Anda sendiri. Ini memungkinkan Anda melakukan perubahan dengan aman tanpa memengaruhi proyek asli!

1. Buka sudut kanan atas halaman ini dan klik tombol **Fork**:

   <br/>

   <img src="../src/image.png" alt="Tombol Fork" width="400" />

   <br/>

2. Pada halaman **Create a new fork**, biarkan nama repositori apa adanya dan klik **Create fork**.

3. Setelah beberapa detik, GitHub akan mengarahkan Anda ke salinan yang baru dibuat di:

   `https://github.com/<username-anda>/good-first-issue`

🎉 **Luar biasa!** Sekarang Anda memiliki salinan kerja proyek Anda sendiri.

## 2. CLONE REPOSITORI

Sekarang Anda perlu mengunduh repositori yang telah di-fork ke komputer Anda agar dapat mengedit file secara lokal.

1. Di **halaman repositori fork Anda** di GitHub, klik tombol hijau "**<> Code**".
2. Di menu dropdown, pastikan tab **HTTPS** dipilih, lalu klik ikon salin untuk menyalin URL repositori Anda:

   <br/>

   <img src="../src/image2.png" alt="Clone repositori" width="360" />

   <br/>

3. Buka terminal Anda dan jalankan perintah `git clone` diikuti URL yang telah Anda salin:

   ```bash
   git clone https://github.com/<username-anda>/good-first-issue.git
   ```

   > 💡 _Ganti `<username-anda>` dengan nama pengguna GitHub asli Anda!_

4. Setelah unduhan selesai, masuk ke direktori proyek:

   ```bash
   cd good-first-issue
   ```

🚀 **Kerja bagus!** Sekarang Anda memiliki file proyek di mesin lokal Anda dan siap untuk membuat perubahan.

## 3. BUAT BRANCH BARU

Sebelum melakukan perubahan apa pun, praktik terbaiknya adalah membuat branch baru. Bekerja di branch terpisah menjaga pekerjaan Anda tetap rapi dan membiarkan branch `main` tetap bersih.

1. Di terminal Anda (di dalam folder `good-first-issue`), jalankan perintah `git switch -c` diikuti dengan nama branch Anda:

   ```bash
   git switch -c <nama-branch-anda>
   ```

   _(Beri nama yang deskriptif, seperti `add-nama-anda` atau `nama-branch-yang-diinginkan`)_

2. Git akan mengonfirmasi bahwa Anda telah membuat dan beralih ke branch baru Anda:

   <br/>

   <img src="../src/image3.png" alt="Buat branch baru" width="550" />

   <br/>

   > 💡 _Tips: Jika Anda menggunakan versi Git yang lebih lama, Anda juga dapat menggunakan `git checkout -b <nama-branch-anda>`._

🌿 **Semua siap!** Setiap perubahan yang Anda buat mulai sekarang akan tersimpan di branch baru Anda.

## 4. BUKA PROYEK DI EDITOR KODE ANDA

Sekarang setelah proyek ada di komputer Anda dan branch sudah siap, saatnya membukanya di editor kode Anda. Dalam panduan ini kita menggunakan **Visual Studio Code (VS Code)**, tetapi Anda dapat menggunakan editor apa pun yang Anda sukai.

Jika Anda telah mengonfigurasi VS Code di command line, cukup jalankan perintah berikut dari dalam folder `good-first-issue`:

```bash
code .
```

Atau, Anda dapat membukanya secara manual:

1. Buka **Visual Studio Code**.
2. Masuk ke **File** > **Open Folder...** (atau tekan `Ctrl + K, Ctrl + O` di Windows / `Cmd + O` di macOS).
3. Pilih folder `good-first-issue`.

Anda akan melihat file proyek di file explorer:

<br/>

<img src="../src/image4.png" alt="Proyek dibuka di VS Code" width="310" />

<br/>

> 💡 _Belum menginstal VS Code? Anda dapat mengunduhnya secara gratis di [code.visualstudio.com](https://code.visualstudio.com/)._

💻 **Selesai!** Proyek sekarang terbuka di editor Anda dan Anda siap untuk mulai mengedit.

## 5. TAMBAHKAN KARTU KONTRIBUTOR ANDA

Sekarang saatnya bagian yang menyenangkan: menambahkan kartu Anda sendiri ke dalam proyek!

Di dalam direktori `assets/cards/`, buat file baru dengan nama pengguna GitHub Anda diikuti dengan `.json`:

📄 `assets/cards/<username-anda>.json` _(mis. `octocat.json`)_

### STRUKTUR

File Anda harus mengikuti struktur yang persis sama dengan `jan.json`:

```json
{
  "name": "<username-anda>",
  "img": "<url-avatar-anda>",
  "github": "https://github.com/<username-anda>"
}
```

### CARA MENDAPATKAN URL FOTO PROFIL ANDA (`IMG`):

1. Buka halaman profil GitHub Anda di browser (`https://github.com/<username-anda>`).
2. Klik kanan pada foto profil Anda dan pilih **"Salin alamat gambar"** (atau **"Copy image address"**).
3. Tempel URL yang disalin tersebut ke kolom `"img"`.

> 💡 _Trik cepat: Anda juga dapat menggunakan `https://github.com/<username-anda>.png` langsung sebagai URL gambar Anda!_

### CONTOH

Jika nama pengguna Anda adalah `octocat`, Anda akan membuat `assets/cards/octocat.json` dengan konten berikut:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Simpan file setelah selesai. Setelah dibuat, Anda siap untuk langkah selanjutnya!

## 6. COMMIT DAN PUSH PERUBAHAN ANDA

Sebelum membuat Pull Request, Anda perlu menyimpan perubahan dan mengunggah branch Anda ke GitHub.

1. Buka terminal di dalam direktori proyek dan siapkan file baru Anda:

   ```bash
   git add assets/cards/<username-anda>.json
   ```

2. Lakukan commit pada perubahan dengan pesan singkat dan deskriptif:

   ```bash
   git commit -m "feat: add <username-anda> card"
   ```

3. Unggah (push) branch Anda ke fork GitHub Anda:

   ```bash
   git push origin <nama-branch-anda>
   ```

   > 💡 _Jika diminta, Anda juga dapat menjalankan `git push -u origin <nama-branch-anda>`._

## 7. BUAT PULL REQUEST

Sekarang branch Anda telah diunggah ke GitHub, saatnya mengirimkan kontribusi Anda ke proyek!

1. Buka halaman fork Anda di GitHub (atau kunjungi repositori asli: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Klik tombol **"Contribute"** dan pilih **"Open pull request"** (atau klik tombol **"Compare & pull request"** pada banner kuning):

   <br/>

   <img src="../src/image5.png" alt="Buka pull request" width="450" />

   <br/>

3. Pastikan bahwa:
   - **Base repository:** `jaanque/good-first-issue` (branch `main`)
   - **Head repository:** fork Anda (branch Anda)
4. Pada judul dan deskripsi, jelaskan secara jelas apa yang telah Anda modifikasi:
   - **Judul:** Tambahkan judul deskriptif (mis. `Add <username-anda> card`).
   - **Deskripsi:** Tulis penjelasan singkat tentang apa yang Anda ubah (mis. bahwa Anda menambahkan kartu kontributor di `assets/cards/<username-anda>.json`).
5. Klik tombol hijau **Create pull request**!
