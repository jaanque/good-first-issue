##

Ви вперше користуєтеся Git та GitHub? **Ви в правильному місці!**

Цей репозиторій створений, щоб допомогти вам зробити перші кроки у світі **Open Source** у безпечному середовищі, без остраху щось зламати.

Я вірю, що найкращий спосіб навчитися — це **практика**, тому я створив простий проєкт, який ви можете легко змінити та покращити.

**Ваша місія проста:** Дотримуйтесь покрокових інструкцій, щоб додати своє ім'я та фото до проєкту.

**Готові розпочати?** Переходьте до **Кроку 1** і творімо магію разом!

## 1. Зробіть форк (Fork) репозиторію

**Форк (Fork)** — це ваша власна копія цього репозиторію у вашому акаунті GitHub. Він дозволяє безпечно вносити зміни, не впливаючи на оригінальний проєкт!

1. Перейдіть у правий верхній кут цієї сторінки та натисніть кнопку **Fork**:

   <br/>

   <img src="../src/image.png" alt="Кнопка Fork" width="400" />

   <br/>

2. На сторінці **Create a new fork** залиште назву репозиторію без змін і натисніть **Create fork**.

3. За кілька секунд GitHub перенаправить вас на щойно створену копію за адресою:

   `https://github.com/<ваше-ім-я-користувача>/good-first-issue`

🎉 **Чудово!** Тепер у вас є власна робоча копія проєкту.

## 2. Клонуйте репозиторій

Тепер потрібно завантажити форкнутий репозиторій на ваш комп'ютер, щоб редагувати файли локально.

1. На **сторінці вашого форка** на GitHub натисніть зелену кнопку "**<> Code**".
2. У спадному меню переконайтеся, що обрано вкладку **HTTPS**, і натисніть значок копіювання, щоб скопіювати URL репозиторію:

   <br/>

   <img src="../src/image2.png" alt="Клонувати репозиторій" width="360" />

   <br/>

3. Відкрийте термінал і виконайте команду `git clone`, додавши скопійовану адресу:

   ```bash
   git clone https://github.com/<ваше-ім-я-користувача>/good-first-issue.git
   ```

   > 💡 _Замініть `<ваше-ім-я-користувача>` на ваше реальне ім'я користувача GitHub!_

4. Після завершення завантаження перейдіть до каталогу проєкту:

   ```bash
   cd good-first-issue
   ```

🚀 **Чудова робота!** Файли проєкту тепер знаходяться на вашому комп'ютері, і ви готові вносити зміни.

## 3. Створіть нову гілку (branch)

Перед внесенням будь-яких змін гарною практикою є створення нової гілки. Робота в окремій гілці підтримує порядок і залишає гілку `main` чистою.

1. У терміналі (всередині папки `good-first-issue`) виконайте команду `git switch -c`, вказавши назву вашої гілки:

   ```bash
   git switch -c <назва-вашої-гілки>
   ```

   _(Дайте їй зрозумілу назву, наприклад `add-ваше-ім-я` або `будь-яка-назва-гілки`)_

2. Git підтвердить створення нової гілки та перемикання на неї:

   <br/>

   <img src="../src/image3.png" alt="Створити нову гілку" width="550" />

   <br/>

   > 💡 _Порада: якщо ви використовуєте старішу версію Git, ви також можете виконати команду `git checkout -b <назва-вашої-гілки>`._

🌿 **Все готово!** Усі зміни, які ви зробите відтепер, залишаться у вашій новій гілці.

## 4. Відкрийте проєкт у редакторі коду

Тепер, коли проєкт завантажено локально, а гілка готова, час відкрити його в редакторі коду. У цьому посібнику ми використовуємо **Visual Studio Code (VS Code)**, але ви можете використовувати будь-який редактор на ваш смак.

Якщо ви налаштували запуск VS Code з командного рядка, просто виконайте таку команду з папки `good-first-issue`:

```bash
code .
```

Також ви можете відкрити його вручну:

1. Запустіть **Visual Studio Code**.
2. Перейдіть до **File** > **Open Folder...** (або натисніть `Ctrl + K, Ctrl + O` у Windows / `Cmd + O` у macOS).
3. Оберіть папку `good-first-issue`.

Ви побачите файли проєкту в провіднику:

<br/>

<img src="../src/image4.png" alt="Проєкт відкритий у VS Code" width="310" />

<br/>

> 💡 _Ще не встановили VS Code? Його можна завантажити безкоштовно з [code.visualstudio.com](https://code.visualstudio.com/)._

💻 **Готово!** Проєкт відкрито у вашому редакторі, і ви готові розпочати редагування.

## 5. Додайте свою картку учасника

Тепер найцікавіше: додавання власної картки до проєкту!

У каталозі `assets/cards/` створіть новий файл із вашим іменем користувача GitHub та розширенням `.json`:

📄 `assets/cards/<ваше-ім-я-користувача>.json` _(наприклад, `octocat.json`)_

### Структура

Файл повинен мати точно таку саму структуру, як і `jan.json`:

```json
{
  "name": "<ваше-ім-я-користувача>",
  "img": "<url-вашого-аватара>",
  "github": "https://github.com/<ваше-ім-я-користувача>"
}
```

### Як отримати URL-адресу фотографії профілю (`img`):

1. Відкрийте сторінку свого профілю GitHub у браузері (`https://github.com/<ваше-ім-я-користувача>`).
2. Клацніть правою кнопкою миші на фотографію профілю та виберіть **"Копіювати адресу зображення"** (або **"Copy image address"**).
3. Вставте скопійовану адресу в поле `"img"`.

> 💡 _Корисна підказка: Ви також можете використати `https://github.com/<ваше-ім-я-користувача>.png` як пряму адресу фотографії!_

### Приклад

Якщо ваше ім'я користувача — `octocat`, ви створите файл `assets/cards/octocat.json` з таким вмістом:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Збережіть файл. Після його створення ви готові до наступного кроку!

## 6. Зробіть commit та push ваших змін

Перед створенням Pull Request необхідно зберегти зміни та надіслати вашу гілку на GitHub.

1. Відкрийте термінал у папці проєкту та додайте новий файл:

   ```bash
   git add assets/cards/<ваше-ім-я-користувача>.json
   ```

2. Зафіксуйте зміни з коротким зрозумілим повідомленням:

   ```bash
   git commit -m "feat: add <ваше-ім-я-користувача> card"
   ```

3. Надішліть вашу гілку у ваш форк на GitHub:

   ```bash
   git push origin <назва-вашої-гілки>
   ```

   > 💡 _Якщо з'явиться запит, ви також можете виконати команду `git push -u origin <назва-вашої-гілки>`._

## 7. Створіть Pull Request

Тепер, коли ваша гілка завантажена на GitHub, настав час надіслати ваш внесок до проєкту!

1. Перейдіть на сторінку вашого форка на GitHub (або відвідайте оригінальний репозиторій: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Натисніть кнопку **"Contribute"** та виберіть **"Open pull request"** (або натисніть кнопку **"Compare & pull request"** на жовтій плашці):

   <br/>

   <img src="../src/image5.png" alt="Відкрити pull request" width="450" />

   <br/>

3. Перевірте, що:
   - **Base repository:** `jaanque/good-first-issue` (гілка `main`)
   - **Head repository:** ваш форк (ваша гілка)
4. У заголовку та описі чітко вкажіть, що саме ви змінили:
   - **Заголовок:** Додайте описову назву (наприклад, `Add <ваше-ім-я-користувача> card`).
   - **Опис:** Напишіть короткий опис внесених змін (наприклад, що ви додали свою картку в `assets/cards/<ваше-ім-я-користувача>.json`).
5. Натисніть зелену кнопку **Create pull request**!

### Тепер просто зачекайте на перевірку вашого pull request. Після схвалення ваша картка автоматично з'явиться на вітрині учасників.

Ви можете побачити внески всіх учасників у реальному часі тут:
👉 **[Наші Учасники](https://jaanque.github.io/good-first-issue/)**
