## 1. 저장소 포크(FORK)하기

**포크(Fork)** 는 이 저장소를 본인의 GitHub 계정으로 복사해 오는 것입니다. 원본 프로젝트에 영향을 주지 않고 안전하게 변경할 수 있습니다!

1. 이 페이지의 오른쪽 상단으로 이동하여 **Fork** 버튼을 클릭합니다:

   <br/>

   <img src="../src/image.png" alt="Fork 버튼" width="400" />

   <br/>

2. **Create a new fork** 페이지에서 저장소 이름을 그대로 두고 **Create fork**를 클릭합니다.

3. 몇 초 후, GitHub이 새로 생성된 복사본으로 이동시켜 줍니다:

   `https://github.com/<본인-사용자명>/good-first-issue`

🎉 **멋집니다!** 이제 여러분만의 프로젝트 작업 복사본이 생겼습니다.

## 2. 저장소 복제(CLONE)하기

이제 로컬 컴퓨터에서 파일을 편집할 수 있도록 포크한 저장소를 다운로드해야 합니다.

1. GitHub의 **포크한 저장소 페이지**에서 녹색 "**<> Code**" 버튼을 클릭합니다.
2. 드롭다운 메뉴에서 **HTTPS** 탭이 선택되어 있는지 확인하고, 복사 아이콘을 클릭하여 저장소 URL을 복사합니다:

   <br/>

   <img src="../src/image2.png" alt="저장소 복제" width="360" />

   <br/>

3. 터미널을 열고 `git clone` 명령어 뒤에 복사한 URL을 붙여넣어 실행합니다:

   ```bash
   git clone https://github.com/<본인-사용자명>/good-first-issue.git
   ```

> [!NOTE]
> `<본인-사용자명>`을 실제 GitHub 사용자명으로 변경하세요!

4. 다운로드가 완료되면 프로젝트 디렉토리로 이동합니다:

   ```bash
   cd good-first-issue
   ```

🚀 **잘하셨습니다!** 이제 로컬 컴퓨터에 프로젝트 파일이 준비되었으며 변경할 준비가 끝났습니다.

## 3. 새 브랜치(BRANCH) 생성하기

변경 사항을 만들기 전에 새 브랜치를 생성하는 것이 모범적인 방식입니다. 별도의 브랜치에서 작업하면 작업이 깔끔하게 정리되고 `main` 브랜치를 깨끗하게 유지할 수 있습니다.

1. 터미널에서(`good-first-issue` 폴더 안에서) `git switch -c` 명령어 뒤에 브랜치 이름을 입력하여 실행합니다:

   ```bash
   git switch -c <브랜치명>
   ```

   _(예: `add-본인이름` 또는 `원하는-브랜치명`과 같이 알기 쉬운 이름을 붙이세요)_

2. Git이 새 브랜치를 생성하고 전환했음을 확인해 줍니다:

   <br/>

   <img src="../src/image3.png" alt="새 브랜치 생성" width="550" />

   <br/>

> [!NOTE]
> 팁: 이전 버전의 Git을 사용하는 경우 `git checkout -b <브랜치명>` 명령어를 사용할 수도 있습니다.

🌿 **준비 완료!** 지금부터 수행하는 모든 변경 사항은 새 브랜치에 유지됩니다.

## 4. 코드 에디터에서 프로젝트 열기

프로젝트를 로컬에 내려받고 브랜치 준비도 끝났으니, 코드 에디터에서 열 차례입니다. 이 가이드에서는 **Visual Studio Code (VS Code)** 를 사용하지만 선호하는 다른 에디터를 사용해도 좋습니다.

명령줄에서 VS Code를 사용할 수 있도록 설정되어 있다면 `good-first-issue` 폴더 안에서 다음 명령어를 실행하기만 하면 됩니다:

```bash
code .
```

또는 직접 수동으로 열 수도 있습니다:

1. **Visual Studio Code**를 실행합니다.
2. **File** > **Open Folder...** (Windows에서는 `Ctrl + K, Ctrl + O` / macOS에서는 `Cmd + O`)를 선택합니다.
3. `good-first-issue` 폴더를 선택합니다.

탐색기에 프로젝트 파일들이 보일 것입니다:

<br/>

<img src="../src/image4.png" alt="VS Code에서 열린 프로젝트" width="310" />

<br/>

> [!NOTE]
> 아직 VS Code가 설치되어 있지 않나요? [code.visualstudio.com](https://code.visualstudio.com/)에서 무료로 다운로드할 수 있습니다.

💻 **준비 완료!** 이제 에디터에 프로젝트가 열렸으며 수정을 시작할 수 있습니다.

## 5. 기여자 카드 추가하기

이제 가장 재미있는 단계입니다: 프로젝트에 여러분만의 카드를 추가해보세요!

`assets/cards/` 디렉토리 안에 본인의 GitHub 사용자명에 `.json`을 붙인 새 파일을 만듭니다:

📄 `assets/cards/<본인-사용자명>.json` _(예: `octocat.json`)_

### 구조

파일은 `jan.json`과 정확히 동일한 구조를 따라야 합니다:

```json
{
  "name": "<본인-사용자명>",
  "img": "<프로필-이미지-URL>",
  "github": "https://github.com/<본인-사용자명>"
}
```

### 프로필 이미지 URL(`IMG`) 가져오는 방법:

1. 브라우저에서 GitHub 프로필 페이지를 엽니다(`https://github.com/<본인-사용자명>`).
2. 프로필 사진을 우클릭하고 **"이미지 주소 복사"** (또는 **"Copy image address"**)를 선택합니다.
3. 복사한 URL을 `"img"` 필드에 붙여넣습니다.

> [!NOTE]
> 꿀팁: 이미지 URL로 `https://github.com/<본인-사용자명>.png`를 바로 사용할 수도 있습니다!

### 예시

사용자명이 `octocat`인 경우 다음 내용으로 `assets/cards/octocat.json` 파일을 작성합니다:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

작성이 끝나면 파일을 저장합니다. 파일이 생성되면 다음 단계로 넘어갈 준비가 되었습니다!

## 6. 변경 사항 커밋(COMMIT) 및 푸시(PUSH)하기

Pull Request를 생성하기 전에 변경 사항을 저장하고 브랜치를 GitHub에 업로드해야 합니다.

1. 프로젝트 디렉토리 내부에서 터미널을 열고 새 파일을 스테이징합니다:

   ```bash
   git add assets/cards/<본인-사용자명>.json
   ```

2. 변경 사항을 짧고 명확한 메시지와 함께 커밋합니다:

   ```bash
   git commit -m "feat: add <본인-사용자명> card"
   ```

3. 여러분의 GitHub 포크로 브랜치를 푸시합니다:

   ```bash
   git push origin <브랜치명>
   ```

> [!NOTE]
> 안내 메시지가 나타나면 `git push -u origin <브랜치명>`을 실행해도 됩니다.

## 7. PULL REQUEST 생성하기

이제 브랜치가 GitHub에 업로드되었으므로 프로젝트에 기여를 제출할 시간입니다!

1. GitHub의 포크 페이지로 이동합니다 (또는 원본 저장소인 [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)를 방문합니다).
2. **"Contribute"** 버튼을 클릭하고 **"Open pull request"**를 선택합니다 (또는 노란색 배너의 **"Compare & pull request"** 버튼을 클릭합니다):

   <br/>

   <img src="../src/image5.png" alt="Pull request 열기" width="450" />

   <br/>

3. 다음 사항을 확인합니다:
   - **Base repository:** `jaanque/good-first-issue` (`main` 브랜치)
   - **Head repository:** 여러분의 포크 (여러분의 브랜치)
4. 제목과 설명에 수정한 내용을 명확하게 작성합니다:
   - **제목:** 알기 쉬운 제목을 입력합니다 (예: `Add <본인-사용자명> card`).
   - **설명:** 수정한 내용을 간단히 설명합니다 (예: `assets/cards/<본인-사용자명>.json`에 기여자 카드를 추가했다는 내용 등).
5. 녹색 **Create pull request** 버튼을 클릭합니다!
