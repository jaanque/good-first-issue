##

¿Es tu primera vez usando Git y GitHub? **¡Estás en el lugar correcto!**

Este repositorio está diseñado para ayudarte a dar tus primeros pasos en el mundo del **Open Source** en un entorno seguro, sin miedo a romper nada.

Creo que la mejor manera de aprender es **haciendo**, así que he creado un proyecto sencillo que puedes modificar y mejorar fácilmente.

**Tu misión es simple:** Sigue las instrucciones paso a paso para añadir tu nombre y foto al proyecto.

**¿Listo para empezar?** ¡Ve al **Paso 1** y hagamos algo de magia!

## 1. Haz un fork del repositorio

Un **fork** es tu propia copia de este repositorio en tu cuenta de GitHub. ¡Te permite hacer cambios de forma segura sin afectar el proyecto original!

1. Ve a la esquina superior derecha de esta página y haz clic en el botón **Fork**:

   <br/>

   <img src="../src/image.png" alt="Botón Fork" width="400" />

   <br/>

2. En la página **Create a new fork**, deja el nombre del repositorio tal como está y haz clic en **Create fork**.

3. Después de unos segundos, GitHub te redirigirá a tu copia recién creada en:

   `https://github.com/<tu-usuario>/good-first-issue`

🎉 **¡Genial!** Ahora tienes tu propia copia de trabajo del proyecto.

## 2. Clona el repositorio

Ahora necesitas descargar tu repositorio forkeado a tu computadora para poder editar los archivos localmente.

1. En **la página de tu repositorio forkeado** en GitHub, haz clic en el botón verde "**<> Code**".
2. En el menú desplegable, asegúrate de que la pestaña **HTTPS** esté seleccionada y haz clic en el icono de copiar para copiar la URL de tu repositorio:

   <br/>

   <img src="../src/image2.png" alt="Clonar repositorio" width="360" />

   <br/>

3. Abre tu terminal y ejecuta el comando `git clone` seguido de la URL que copiaste:

   ```bash
   git clone https://github.com/<tu-usuario>/good-first-issue.git
   ```

   > 💡 _¡Reemplaza `<tu-usuario>` por tu nombre de usuario real de GitHub!_

4. Una vez completada la descarga, entra en el directorio del proyecto:

   ```bash
   cd good-first-issue
   ```

🚀 **¡Buen trabajo!** Ya tienes los archivos del proyecto en tu máquina local y estás listo para hacer tus cambios.

## 3. Crea una nueva rama (branch)

Antes de hacer cualquier cambio, es una buena práctica crear una nueva rama. Trabajar en una rama separada mantiene tu trabajo organizado y deja la rama `main` limpia.

1. En tu terminal (dentro de la carpeta `good-first-issue`), ejecuta el comando `git switch -c` seguido del nombre de tu rama:

   ```bash
   git switch -c <nombre-de-tu-rama>
   ```

   _(Dale un nombre descriptivo, como `add-tu-nombre` o `el-nombre-de-rama-que-quieras`)_

2. Git confirmará que has creado y cambiado a tu nueva rama:

   <br/>

   <img src="../src/image3.png" alt="Crear nueva rama" width="550" />

   <br/>

   > 💡 _Consejo: Si estás usando una versión más antigua de Git, también puedes usar `git checkout -b <nombre-de-tu-rama>`._

🌿 **¡Todo listo!** Cualquier cambio que hagas a partir de ahora se mantendrá en tu nueva rama.

## 4. Abre el proyecto en tu editor de código

Ahora que tienes el proyecto localmente y tu rama está lista, es hora de abrirlo en tu editor de código. En esta guía usaremos **Visual Studio Code (VS Code)**, pero puedes usar el editor que prefieras.

Si tienes VS Code configurado en tu línea de comandos, simplemente ejecuta el siguiente comando desde dentro de la carpeta `good-first-issue`:

```bash
code .
```

Como alternativa, puedes abrirlo manualmente:

1. Abre **Visual Studio Code**.
2. Ve a **Archivo** > **Abrir carpeta...** (o presiona `Ctrl + K, Ctrl + O` en Windows / `Cmd + O` en macOS).
3. Selecciona la carpeta `good-first-issue`.

Deberías ver los archivos del proyecto en el explorador:

<br/>

<img src="../src/image4.png" alt="Proyecto abierto en VS Code" width="310" />

<br/>

> 💡 _¿Aún no tienes instalado VS Code? Puedes descargarlo gratis desde [code.visualstudio.com](https://code.visualstudio.com/)._

💻 **¡Listo!** Ya tienes el proyecto abierto en tu editor y estás preparado para empezar a editar.

## 5. Añade tu tarjeta de colaborador

¡Ahora viene la parte divertida: añadir tu propia tarjeta al proyecto!

Dentro del directorio `assets/cards/`, crea un nuevo archivo con tu nombre de usuario de GitHub seguido de `.json`:

📄 `assets/cards/<tu-usuario>.json` _(ej. `octocat.json`)_

### Estructura

Tu archivo debe seguir exactamente la misma estructura que `jan.json`:

```json
{
  "name": "<tu-usuario>",
  "img": "<url-de-tu-avatar>",
  "github": "https://github.com/<tu-usuario>"
}
```

### Cómo obtener la URL de tu foto de perfil (`img`):

1. Abre tu perfil de GitHub en tu navegador (`https://github.com/<tu-usuario>`).
2. Haz clic derecho en tu foto de perfil y selecciona **"Copiar dirección de imagen"** (o **"Copy image address"**).
3. Pega esa URL copiada en el campo `"img"`.

> 💡 _Truco rápido: ¡También puedes usar `https://github.com/<tu-usuario>.png` como la URL de tu imagen!_

### Ejemplo

Si tu nombre de usuario es `octocat`, crearías `assets/cards/octocat.json` con el siguiente contenido:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Guarda el archivo cuando termines. ¡Una vez creado, estás listo para el siguiente paso!

## 6. Haz commit y push de tus cambios

Antes de crear el Pull Request, necesitas guardar tus cambios y subir tu rama a GitHub.

1. Abre tu terminal dentro del directorio del proyecto y prepara tu nuevo archivo:

   ```bash
   git add assets/cards/<tu-usuario>.json
   ```

2. Haz commit de los cambios con un mensaje corto y descriptivo:

   ```bash
   git commit -m "feat: add <tu-usuario> card"
   ```

3. Sube tu rama a tu fork de GitHub:

   ```bash
   git push origin <nombre-de-tu-rama>
   ```

   > 💡 _Si te lo solicita, también puedes ejecutar `git push -u origin <nombre-de-tu-rama>`._

## 7. Crea el Pull Request

Ahora que tu rama está subida a GitHub, ¡es hora de enviar tu contribución al proyecto!

1. Ve a la página de tu fork en GitHub (o visita el repositorio original: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Haz clic en el botón **"Contribute"** y selecciona **"Open pull request"** (o haz clic en el botón **"Compare & pull request"** en el banner amarillo):

   <br/>

   <img src="../src/image5.png" alt="Abrir pull request" width="450" />

   <br/>

3. Verifica que:
   - **Base repository:** `jaanque/good-first-issue` (rama `main`)
   - **Head repository:** tu fork (tu rama)
4. En el título y la descripción, describe claramente lo que has modificado:
   - **Título:** Añade un título descriptivo (ej. `Add <tu-usuario> card`).
   - **Descripción:** Escribe una breve descripción explicando lo que modificaste (ej. que añadiste tu tarjeta de colaborador en `assets/cards/<tu-usuario>.json`).
5. ¡Haz clic en el botón verde **Create pull request**!

### Ahora solo espera la revisión de tu pull request. Tras la revisión, si es aceptado, tu tarjeta se añadirá automáticamente a la vitrina de colaboradores.

Puedes ver el resultado en vivo de las contribuciones de todos aquí:
👉 **[Nuestros Colaboradores](https://jaanque.github.io/good-first-issue/)**
