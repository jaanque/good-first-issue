## 1. DEPOYU FORK'LAYIN

**Fork**, bu deponun kendi GitHub hesabınız altındaki kopyasıdır. Orijinal projeyi etkilemeden güvenle değişiklik yapmanızı sağlar!

1. Bu sayfanın sağ üst köşesine gidin ve **Fork** butonuna tıklayın:

   <br/>

   <img src="../src/image.png" alt="Fork butonu" width="400" />

   <br/>

2. **Create a new fork** sayfasında, depo adını olduğu gibi bırakın ve **Create fork** butonuna tıklayın.

3. Birkaç saniye sonra GitHub sizi yeni oluşturulan kopyanıza yönlendirecektir:

   `https://github.com/<kullanici-adiniz>/good-first-issue`

🎉 **Harika!** Artık projenin üzerinde çalışabileceğiniz kendi kopyanıza sahipsiniz.

## 2. DEPOYU KLONLAYIN

Şimdi, dosyaları yerel olarak düzenleyebilmek için fork'ladığınız depoyu bilgisayarınıza indirmeniz gerekiyor.

1. GitHub'da **fork'ladığınız deponun sayfasında**, yeşil renkli "**<> Code**" butonuna tıklayın.
2. Açılan menüde **HTTPS** sekmesinin seçili olduğundan emin olun ve kopyalama simgesine tıklayarak depo URL'sini kopyalayın:

   <br/>

   <img src="../src/image2.png" alt="Depoyu klonlama" width="360" />

   <br/>

3. Terminalinizi açın ve `git clone` komutunu, ardından kopyaladığınız URL'yi yazarak çalıştırın:

   ```bash
   git clone https://github.com/<kullanici-adiniz>/good-first-issue.git
   ```

> [!NOTE]
> `<kullanici-adiniz>` kısmını gerçek GitHub kullanıcı adınızla değiştirin!

4. İndirme tamamlandığında, proje dizinine geçin:

   ```bash
   cd good-first-issue
   ```

🚀 **Tebrikler!** Proje dosyaları artık yerel bilgisayarınızda ve değişiklik yapmaya hazırsınız.

## 3. YENI BIR DAL (BRANCH) OLUŞTURUN

Herhangi bir değişiklik yapmadan önce yeni bir dal oluşturmak en iyi uygulamadır. Ayrı bir dalda çalışmak çalışmalarınızı düzenli tutar ve `main` dalını temiz bırakır.

1. Terminalinizde (`good-first-issue` klasörünün içinde), `git switch -c` komutunu ve ardından dalınızın adını yazarak çalıştırın:

   ```bash
   git switch -c <dal-adiniz>
   ```

   _(Örn: `add-adiniz` veya `istediginiz-dal-adi` gibi açıklayıcı bir isim verin)_

2. Git, yeni dalı oluşturduğunuzu ve ona geçtiğinizi onaylayacaktır:

   <br/>

   <img src="../src/image3.png" alt="Yeni dal oluşturma" width="550" />

   <br/>

> [!NOTE]
> İpucu: Git'in daha eski bir sürümünü kullanıyorsanız `git checkout -b <dal-adiniz>` komutunu da kullanabilirsiniz.

🌿 **Her şey hazır!** Bundan sonra yapacağınız tüm değişiklikler bu yeni dalda kalacaktır.

## 4. PROJEYI KOD DÜZENLEYICINIZDE AÇIN

Artık proje yerel bilgisayarınızda ve dalınız hazır olduğuna göre, projeyi kod düzenleyicinizde açma zamanı geldi. Bu kılavuzda **Visual Studio Code (VS Code)** kullanacağız, ancak tercih ettiğiniz herhangi bir düzenleyiciyi de kullanabilirsiniz.

Eğer komut satırında VS Code yapılandırmanız varsa, `good-first-issue` klasörü içindeyken aşağıdaki komutu çalıştırmanız yeterlidir:

```bash

```

Alternatif olarak elle de açabilirsiniz:

1. **Visual Studio Code** uygulamasını başlatın.
2. **File** > **Open Folder...** seçeneğine gidin (veya Windows'ta `Ctrl + K, Ctrl + O` / macOS'ta `Cmd + O`).
3. `good-first-issue` klasörünü seçin.

Proje dosyalarını dosya gezgininde göreceksiniz:

<br/>

<img src="../src/image4.png" alt="VS Code'da açılmış proje" width="310" />

<br/>

> [!NOTE]
> Henüz VS Code yüklü değil mi? [code.visualstudio.com](https://code.visualstudio.com/) adresinden ücretsiz indirebilirsiniz.

💻 **Hazır!** Proje düzenleyicinizde açıldı ve düzenlemeye başlayabilirsiniz.

## 5. KATKIDA BULUNAN KARTINIZI EKLEYIN

Şimdi en eğlenceli kısma geldik: projeye kendi kartınızı eklemek!

`assets/cards/` dizini içinde, GitHub kullanıcı adınızın sonuna `.json` ekleyerek yeni bir dosya oluşturun:

📄 `assets/cards/<kullanici-adiniz>.json` _(örn. `octocat.json`)_

### YAPI

Dosyanız `jan.json` ile birebir aynı yapıyı izlemelidir:

```json
{
  "name": "<kullanici-adiniz>",
  "img": "<avatar-resim-url-adresiniz>",
  "github": "https://github.com/<kullanici-adiniz>"
}
```

### PROFIL RESMI URL ADRESINIZI (`IMG`) NASIL ALIRSINIZ:

1. Tarayıcınızda GitHub profil sayfanızı açın (`https://github.com/<kullanici-adiniz>`).
2. Profil resminize sağ tıklayın ve **"Resim adresini kopyala"** (veya **"Copy image address"**) seçeneğini seçin.
3. Kopyalanan bu adresi `"img"` alanına yapıştırın.

> [!NOTE]
> Küçük bir ipucu: Resim URL'si olarak doğrudan `https://github.com/<kullanici-adiniz>.png` adresini de kullanabilirsiniz!

### ÖRNEK

Kullanıcı adınız `octocat` ise, aşağıdaki içerikle `assets/cards/octocat.json` dosyasını oluşturursunuz:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

İşiniz bittiğinde dosyayı kaydedin. Dosya oluşturulduktan sonra bir sonraki adıma hazırsınız!

## 6. DEĞIŞIKLIKLERINIZI COMMIT'LEYIN VE PUSH'LAYIN

Pull Request oluşturmadan önce değişikliklerinizi kaydetmeniz ve dalınızı GitHub'a yüklemeniz gerekir.

1. Proje dizini içinde terminalinizi açın ve yeni dosyanızı ekleyin:

   ```bash
   git add assets/cards/<kullanici-adiniz>.json
   ```

2. Kısa ve açıklayıcı bir mesajla değişiklikleri commit'leyin:

   ```bash
   git commit -m "feat: add <kullanici-adiniz> card"
   ```

3. Dalınızı GitHub fork'unuza push'layın:

   ```bash
   git push origin <dal-adiniz>
   ```

> [!NOTE]
> İstenirse `git push -u origin <dal-adiniz>` komutunu da çalıştırabilirsiniz.

## 7. PULL REQUEST OLUŞTURUN

Dalınız GitHub'a yüklendiğine göre, artık projeye katkınızı sunma zamanı!

1. GitHub'daki fork sayfanıza gidin (veya orijinal depoyu ziyaret edin: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. **"Contribute"** butonuna tıklayın ve **"Open pull request"** seçeneğini seçin (veya sarı başlıktaki **"Compare & pull request"** butonuna tıklayın):

   <br/>

   <img src="../src/image5.png" alt="Pull request açma" width="450" />

   <br/>

3. Şunları doğrulayın:
   - **Base repository:** `jaanque/good-first-issue` (`main` dalı)
   - **Head repository:** sizin fork'unuz (sizin dalınız)
4. Başlık ve açıklamada neyi değiştirdiğinizi açıkça belirtin:
   - **Başlık:** Açıklayıcı bir başlık ekleyin (örn. `Add <kullanici-adiniz> card`).
   - **Açıklama:** Ne yaptığınızı açıklayan kısa bir metin yazın (örn. `assets/cards/<kullanici-adiniz>.json` dosyasına katkıda bulunan kartınızı eklediğinizi belirtin).
5. Yeşil renkli **Create pull request** butonuna tıklayın!
