##

Вы впервые используете Git и GitHub? **Вы попали по адресу!**

Этот репозиторий создан для того, чтобы помочь вам сделать первые шаги в мире **Open Source** в безопасной среде, не опасаясь ничего сломать.

Я считаю, что лучший способ научиться — это **практика**, поэтому я создал простой проект, который вы легко сможете изменить и улучшить.

**Ваша задача проста:** следуйте пошаговым инструкциям, чтобы добавить своё имя и фотографию в проект.

**Готовы начать?** Переходите к **Шагу 1** — и вперед к магии!

## 1. СДЕЛАЙТЕ ФОРК (FORK) РЕПОЗИТОРИЯ

**Форк** — это ваша личная копия данного репозитория в вашем аккаунте GitHub. Он позволяет безопасно вносить изменения, не затрагивая исходный проект!

1. Перейдите в правый верхний угол этой страницы и нажмите кнопку **Fork**:

   <br/>

   <img src="../src/image.png" alt="Кнопка Fork" width="400" />

   <br/>

2. На странице **Create a new fork** оставьте название репозитория без изменений и нажмите **Create fork**.

3. Через несколько секунд GitHub перенаправит вас на только что созданную копию по адресу:

   `https://github.com/<ваше-имя-пользователя>/good-first-issue`

🎉 **Отлично!** Теперь у вас есть собственная рабочая копия проекта.

## 2. КЛОНИРУЙТЕ РЕПОЗИТОРИЙ

Теперь нужно скачать форкнутый репозиторий на ваш компьютер, чтобы редактировать файлы локально.

1. На **странице вашего форка** на GitHub нажмите зеленую кнопку "**<> Code**".
2. В выпадающем меню убедитесь, что выбрана вкладка **HTTPS**, и нажмите значок копирования, чтобы скопировать URL репозитория:

   <br/>

   <img src="../src/image2.png" alt="Клонировать репозиторий" width="360" />

   <br/>

3. Откройте терминал и выполните команду `git clone`, за которой следует скопированный URL:

   ```bash
   git clone https://github.com/<ваше-имя-пользователя>/good-first-issue.git
   ```

   > [!IMPORTANT]
   > Замените `<ваше-имя-пользователя>` на ваше реальное имя пользователя GitHub!

4. Как только скачивание завершится, перейдите в папку проекта:

   ```bash
   cd good-first-issue
   ```

🚀 **Прекрасная работа!** Теперь файлы проекта находятся на вашем локальном компьютере, и вы готовы вносить изменения.

## 3. СОЗДАЙТЕ НОВУЮ ВЕТКУ

Перед внесением любых изменений рекомендуется создать новую ветку. Работа в отдельной ветке помогает поддерживать порядок и сохраняет основную ветку `main` чистой.

1. В терминале (внутри папки `good-first-issue`) выполните команду `git switch -c`, указав имя вашей ветки:

   ```bash
   git switch -c <имя-вашей-ветки>
   ```

   _(Дайте ей понятное название, например `add-ваше-имя` или `любое-желаемое-имя-ветки`)_

2. Git подтвердит создание и переключение на новую ветку:

   <br/>

   <img src="../src/image3.png" alt="Создание новой ветки" width="550" />

   <br/>

   > [!TIP]
   > Совет: если вы используете более старую версию Git, вы также можете использовать команду `git checkout -b <имя-вашей-ветки>`.

🌿 **Все готово!** Все изменения, которые вы сделаете отныне, останутся в вашей новой ветке.

## 4. ОТКРОЙТЕ ПРОЕКТ В РЕДАКТОРЕ КОДА

Теперь, когда проект сохранен локально, а ветка готова, пришло время открыть его в редакторе кода. В этом руководстве мы используем **Visual Studio Code (VS Code)**, но вы можете использовать любой удобный редактор.

Если у вас настроен запуск VS Code из командной строки, просто выполните следующую команду из папки `good-first-issue`:

```bash
code .
```

Либо откройте проект вручную:

1. Запустите **Visual Studio Code**.
2. Выберите **File** > **Open Folder...** (или нажмите `Ctrl + K, Ctrl + O` в Windows / `Cmd + O` в macOS).
3. Выберите папку `good-first-issue`.

Вы увидите файлы проекта в проводнике:

<br/>

<img src="../src/image4.png" alt="Проект открыт в VS Code" width="310" />

<br/>

> [!NOTE]
> Еще не установили VS Code? Его можно бесплатно скачать на сайте [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Готово!** Проект открыт в редакторе, и вы можете приступать к изменениям.

## 5. ДОБАВЬТЕ КАРТОЧКУ УЧАСТНИКА

Теперь самое интересное: добавление собственной карточки в проект!

В папке `assets/cards/` создайте новый файл с вашим именем пользователя GitHub и расширением `.json`:

📄 `assets/cards/<ваше-имя-пользователя>.json` _(например, `octocat.json`)_

### СТРУКТУРА

Файл должен иметь точно такую же структуру, как и `jan.json`:

```json
{
  "name": "<ваше-имя-пользователя>",
  "img": "<url-вашего-аватара>",
  "github": "https://github.com/<ваше-имя-пользователя>"
}
```

### КАК ПОЛУЧИТЬ URL ФОТОГРАФИИ ВАШЕГО ПРОФИЛЯ (`IMG`):

1. Откройте страницу своего профиля на GitHub в браузере (`https://github.com/<ваше-имя-пользователя>`).
2. Нажмите правой кнопкой мыши по своей фотографии профиля и выберите **«Копировать адрес изображения»** (или **"Copy image address"**).
3. Вставьте скопированный URL в поле `"img"`.

> [!TIP]
> Маленькая хитрость: вы также можете использовать `https://github.com/<ваше-имя-пользователя>.png` в качестве URL вашего изображения!

### ПРИМЕР

Если ваше имя пользователя — `octocat`, вы создадите файл `assets/cards/octocat.json` со следующим содержимым:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Сохраните файл. После этого вы готовы к следующему шагу!

## 6. ЗАКОММИТЬТЕ И ОТПРАВЬТЕ ИЗМЕНЕНИЯ (PUSH)

Перед созданием Pull Request необходимо сохранить изменения и отправить вашу ветку на GitHub.

1. Откройте терминал в папке проекта и добавьте новый файл для фиксации:

   ```bash
   git add assets/cards/<ваше-имя-пользователя>.json
   ```

2. Закоммитьте изменения с коротким понятным сообщением:

   ```bash
   git commit -m "feat: add <ваше-имя-пользователя> card"
   ```

3. Отправьте вашу ветку в ваш форк на GitHub:

   ```bash
   git push origin <имя-вашей-ветки>
   ```

   > [!NOTE]
   > Если появится запрос, вы также можете выполнить `git push -u origin <имя-вашей-ветки>`.

## 7. СОЗДАЙТЕ PULL REQUEST

Теперь, когда ваша ветка отправлена на GitHub, пришло время отправить ваш вклад в проект!

1. Перейдите на страницу вашего форка на GitHub (или посетите оригинальный репозиторий: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Нажмите кнопку **"Contribute"** и выберите **"Open pull request"** (или нажмите кнопку **"Compare & pull request"** на желтой плашке):

   <br/>

   <img src="../src/image5.png" alt="Открыть pull request" width="450" />

   <br/>

3. Убедитесь, что:
   - **Base repository:** `jaanque/good-first-issue` (ветка `main`)
   - **Head repository:** ваш форк (ваша ветка)
4. В заголовке и описании четко укажите, что именно вы изменили:
   - **Title (Заголовок):** добавьте понятное название (например, `Add <ваше-имя-пользователя> card`).
   - **Description (Описание):** кратко опишите внесенные изменения (например, что вы добавили карточку участника в `assets/cards/<ваше-имя-пользователя>.json`).
5. Нажмите зеленую кнопку **Create pull request**!

### ТЕПЕРЬ ПРОСТО ДОЖДИТЕСЬ ПРОВЕРКИ ВАШЕГО PULL REQUEST. ПОСЛЕ ПРОВЕРКИ, ЕСЛИ ОН БУДЕТ ПРИНЯТ, ВАША КАРТОЧКА АВТОМАТИЧЕСКИ ПОЯВИТСЯ НА ВИТРИНЕ УЧАСТНИКОВ.
