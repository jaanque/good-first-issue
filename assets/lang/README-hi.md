क्या आप पहली बार Git और GitHub का उपयोग कर रहे हैं? **आप बिल्कुल सही जगह पर हैं!**

यह रिपॉजिटरी बिना किसी डर के, एक सुरक्षित वातावरण में **ओपन सोर्स (Open Source)** की दुनिया में आपके पहले कदम रखने में मदद करने के लिए बनाई गई है।

मेरा मानना है कि सीखने का सबसे अच्छा तरीका **करके सीखना** है, इसलिए मैंने एक सरल प्रोजेक्ट बनाया है जिसे आप आसानी से संशोधित और बेहतर बना सकते हैं।

**आपका मिशन सरल है:** प्रोजेक्ट में अपना नाम और फ़ोटो जोड़ने के लिए चरण-दर-चरण निर्देशों का पालन करें।

**शुरू करने के लिए तैयार हैं?** **चरण 1** पर जाएं और शुरुआत करें!

## 1. रिपॉजिटरी को Fork करें

**Fork** आपके GitHub अकाउंट के तहत इस रिपॉजिटरी की अपनी एक प्रति है। यह आपको मूल प्रोजेक्ट को प्रभावित किए बिना सुरक्षित रूप से बदलाव करने की सुविधा देता है!

1. इस पृष्ठ के शीर्ष-दाएं कोने पर जाएं और **Fork** बटन पर क्लिक करें:

   <br/>

   <img src="../src/image.png" alt="Fork बटन" width="400" />

   <br/>

2. **Create a new fork** पेज पर, रिपॉजिटरी का नाम वैसा ही रहने दें और **Create fork** पर क्लिक करें।

3. कुछ ही सेकंड बाद GitHub आपको आपकी नई बनाई गई प्रति पर पुनर्निर्देशित कर देगा:

   `https://github.com/<आपका-यूज़रनेम>/good-first-issue`

🎉 **बहुत बढ़िया!** अब आपके पास प्रोजेक्ट की अपनी कार्यशील प्रति है।

## 2. रिपॉजिटरी को Clone करें

अब आपको फ़ाइलों को स्थानीय रूप से संपादित करने के लिए अपनी फ़ोर्क की गई रिपॉजिटरी को अपने कंप्यूटर पर डाउनलोड करना होगा।

1. GitHub पर **अपनी फ़ोर्क की गई रिपॉजिटरी के पेज** पर हरे रंग के "**<> Code**" बटन पर क्लिक करें।
2. ड्रॉपडाउन मेनू में सुनिश्चित करें कि **HTTPS** टैब चुना गया है, और अपने रिपॉजिटरी URL को कॉपी करने के लिए कॉपी आइकन पर क्लिक करें:

   <br/>

   <img src="../src/image2.png" alt="रिपॉजिटरी क्लोन करें" width="360" />

   <br/>

3. अपना टर्मिनल खोलें और `git clone` कमांड के बाद कॉपी किया गया URL पेस्ट करके चलाएं:

   ```bash
   git clone https://github.com/<आपका-यूज़रनेम>/good-first-issue.git
   ```

   > 💡 _`<आपका-यूज़रनेम>` को अपने वास्तविक GitHub यूज़रनेम से बदलें!_

4. डाउनलोड पूरा होने के बाद, प्रोजेक्ट डायरेक्टरी में जाएं:

   ```bash
   cd good-first-issue
   ```

🚀 **शानदार काम!** प्रोजेक्ट की फ़ाइलें अब आपकी स्थानीय मशीन पर हैं और आप बदलाव करने के लिए तैयार हैं।

## 3. एक नई ब्रांच (Branch) बनाएं

कोई भी बदलाव करने से पहले एक नई ब्रांच बनाना सबसे अच्छा अभ्यास माना जाता है। एक अलग ब्रांच पर काम करने से आपका काम व्यवस्थित रहता है और `main` ब्रांच साफ रहती है।

1. अपने टर्मिनल में (`good-first-issue` फ़ोल्डर के अंदर), `git switch -c` कमांड और अपनी ब्रांच का नाम लिखकर चलाएं:

   ```bash
   git switch -c <आपकी-ब्रांच-का-नाम>
   ```

   _(इसे कोई वर्णनात्मक नाम दें, जैसे `add-आपका-नाम` या `अपनी-पसंद-का-ब्रांच-नाम`)_

2. Git पुष्टि करेगा कि आपने नई ब्रांच बना ली है और उस पर स्विच कर लिया है:

   <br/>

   <img src="../src/image3.png" alt="नई ब्रांच बनाएं" width="550" />

   <br/>

   > 💡 _सुझाव: यदि आप Git के पुराने वर्शन का उपयोग कर रहे हैं, तो आप `git checkout -b <आपकी-ब्रांच-का-नाम>` का भी उपयोग कर सकते हैं।_

🌿 **सब तैयार है!** अब से आप जो भी बदलाव करेंगे, वे आपकी नई ब्रांच में सुरक्षित रहेंगे।

## 4. प्रोजेक्ट को अपने कोड एडिटर में खोलें

अब जब आपके पास प्रोजेक्ट स्थानीय रूप से मौजूद है और आपकी ब्रांच तैयार है, तो इसे अपने कोड एडिटर में खोलने का समय आ गया है। इस गाइड में हम **Visual Studio Code (VS Code)** का उपयोग करेंगे, लेकिन आप अपनी पसंद का कोई भी एडिटर इस्तेमाल कर सकते हैं।

यदि आपने कमांड लाइन में VS Code कॉन्फ़िगर किया है, तो `good-first-issue` फ़ोल्डर के अंदर से बस निम्नलिखित कमांड चलाएं:

```bash
code .
```

वैकल्पिक रूप से, आप इसे मैन्युअली भी खोल सकते हैं:

1. **Visual Studio Code** खोलें।
2. **File** > **Open Folder...** पर जाएं (या Windows पर `Ctrl + K, Ctrl + O` / macOS पर `Cmd + O` दबाएं)।
3. `good-first-issue` फ़ोल्डर चुनें।

आपको एक्सप्लोरर में प्रोजेक्ट की फ़ाइलें दिखाई देंगी:

<br/>

<img src="../src/image4.png" alt="VS Code में खुला प्रोजेक्ट" width="310" />

<br/>

> 💡 _क्या आपके पास अभी तक VS Code इंस्टॉल नहीं है? आप इसे [code.visualstudio.com](https://code.visualstudio.com/) से मुफ्त में डाउनलोड कर सकते हैं।_

💻 **सब तैयार!** अब प्रोजेक्ट आपके एडिटर में खुला है और आप एडिटिंग शुरू करने के लिए तैयार हैं।

## 5. अपना कंट्रीब्यूटर कार्ड जोड़ें

अब सबसे मज़ेदार हिस्सा आता है: प्रोजेक्ट में अपना खुद का कार्ड जोड़ना!

`assets/cards/` डायरेक्टरी के अंदर, अपने GitHub यूज़रनेम के बाद `.json` लगाकर एक नई फ़ाइल बनाएं:

📄 `assets/cards/<आपका-यूज़रनेम>.json` _(उदा. `octocat.json`)_

### संरचना

आपकी फ़ाइल का ढाँचा बिल्कुल `jan.json` जैसा होना चाहिए:

```json
{
  "name": "<आपका-यूज़रनेम>",
  "img": "<आपकी-अवतार-तस्वीर-का-url>",
  "github": "https://github.com/<आपका-यूज़रनेम>"
}
```

### अपनी प्रोफ़ाइल तस्वीर का URL (`img`) कैसे प्राप्त करें:

1. अपने ब्राउज़र में अपना GitHub प्रोफ़ाइल पेज खोलें (`https://github.com/<आपका-यूज़रनेम>`)।
2. अपनी प्रोफ़ाइल तस्वीर पर राइट-क्लिक करें और **"Copy image address"** (छवि का पता कॉपी करें) चुनें।
3. उस कॉपी किए गए URL को `"img"` फ़ील्ड में पेस्ट करें।

> 💡 _त्वरित ट्रिक: आप अपनी छवि URL के रूप में सीधे `https://github.com/<आपका-यूज़रनेम>.png` का भी उपयोग कर सकते हैं!_

### उदाहरण

यदि आपका यूज़रनेम `octocat` है, तो आप निम्नलिखित सामग्री के साथ `assets/cards/octocat.json` फ़ाइल बनाएंगे:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

काम पूरा होने पर फ़ाइल सेव करें। फ़ाइल बनने के बाद, आप अगले कदम के लिए तैयार हैं!

## 6. अपने बदलावों को Commit और Push करें

Pull Request बनाने से पहले, आपको अपने बदलावों को सहेजना होगा और अपनी ब्रांच को GitHub पर अपलोड करना होगा।

1. प्रोजेक्ट डायरेक्टरी के अंदर अपना टर्मिनल खोलें और अपनी नई फ़ाइल जोड़ें:

   ```bash
   git add assets/cards/<आपका-यूज़रनेम>.json
   ```

2. एक संक्षिप्त और स्पष्ट संदेश के साथ बदलावों को कमिट करें:

   ```bash
   git commit -m "feat: add <आपका-यूज़रनेम> card"
   ```

3. अपनी ब्रांच को अपने GitHub फ़ोर्क पर पुश करें:

   ```bash
   git push origin <आपकी-ब्रांच-का-नाम>
   ```

   > 💡 _पूछे जाने पर, आप `git push -u origin <आपकी-ब्रांच-का-नाम>` भी चला सकते हैं।_

## 7. Pull Request बनाएं

अब जब आपकी ब्रांच GitHub पर अपलोड हो गई है, तो प्रोजेक्ट में अपना योगदान सबमिट करने का समय आ गया है!

1. GitHub पर अपने फ़ोर्क पेज पर जाएं (या मूल रिपॉजिटरी पर जाएं: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue))।
2. **"Contribute"** बटन पर क्लिक करें और **"Open pull request"** चुनें (या पीले बैनर में **"Compare & pull request"** बटन पर क्लिक करें):

   <br/>

   <img src="../src/image5.png" alt="Pull request खोलें" width="450" />

   <br/>

3. पुष्टि करें कि:
   - **Base repository:** `jaanque/good-first-issue` (`main` ब्रांच)
   - **Head repository:** आपका फ़ोर्क (आपकी ब्रांच)
4. शीर्षक और विवरण में स्पष्ट रूप से बताएं कि आपने क्या बदलाव किए हैं:
   - **शीर्षक:** एक वर्णनात्मक शीर्षक जोड़ें (उदा. `Add <आपका-यूज़रनेम> card`)।
   - **विवरण:** आपने क्या बदलाव किए हैं, यह समझाते हुए एक संक्षिप्त विवरण लिखें (उदा. आपने `assets/cards/<आपका-यूज़रनेम>.json` में अपना कंट्रीब्यूटर कार्ड जोड़ा है)।
5. हरे रंग के **Create pull request** बटन पर क्लिक करें!
