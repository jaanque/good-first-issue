## 1. ΚΆΝΤΕ FORK ΤΟ ΑΠΟΘΕΤΉΡΙΟ

Το **Fork** είναι το δικό σας αντίγραφο αυτού του αποθετηρίου στον λογαριασμό σας στο GitHub. Σας επιτρέπει να κάνετε αλλαγές με ασφάλεια, χωρίς να επηρεάζετε το αρχικό έργο!

1. Μεταβείτε στην επάνω δεξιά γωνία αυτής της σελίδας και κάντε κλικ στο κουμπί **Fork**:

   <br/>

   <img src="../src/image.png" alt="Κουμπί Fork" width="400" />

   <br/>

2. Στη σελίδα **Create a new fork**, αφήστε το όνομα του αποθετηρίου ως έχει και κάντε κλικ στο **Create fork**.

3. Μετά από λίγα δευτερόλεπτα, το GitHub θα σας ανακατευθύνει στο νέο σας αντίγραφο στη διεύθυνση:

   `https://github.com/<το-όνομα-χρήστη-σας>/good-first-issue`

🎉 **Εξαιρετικά!** Τώρα έχετε το δικό σας αντίγραφο εργασίας του έργου.

## 2. ΚΆΝΤΕ CLONE ΤΟ ΑΠΟΘΕΤΉΡΙΟ

Τώρα πρέπει να κατεβάσετε το αποθετήριο στον υπολογιστή σας για να μπορείτε να επεξεργαστείτε τα αρχεία τοπικά.

1. Στη **σελίδα του fork σας** στο GitHub, κάντε κλικ στο πράσινο κουμπί "**<> Code**".
2. Στο αναπτυσσόμενο μενού, βεβαιωθείτε ότι είναι επιλεγμένη η καρτέλα **HTTPS** και κάντε κλικ στο εικονίδιο αντιγραφής για να αντιγράψετε το URL:

   <br/>

   <img src="../src/image2.png" alt="Clone αποθετηρίου" width="360" />

   <br/>

3. Ανοίξτε το τερματικό σας και εκτελέστε την εντολή `git clone` ακολουθούμενη από το URL που αντιγράψατε:

   ```bash
   git clone https://github.com/<το-όνομα-χρήστη-σας>/good-first-issue.git
   ```

   > [!IMPORTANT]
   > Αντικαταστήστε το `<το-όνομα-χρήστη-σας>` με το πραγματικό σας όνομα χρήστη στο GitHub!

4. Μόλις ολοκληρωθεί η λήψη, μεταβείτε στον φάκελο του έργου:

   ```bash
   cd good-first-issue
   ```

🚀 **Μπράβο!** Τα αρχεία του έργου βρίσκονται πλέον στον υπολογιστή σας και είστε έτοιμοι να κάνετε αλλαγές.

## 3. ΔΗΜΙΟΥΡΓΉΣΤΕ ΈΝΑ ΝΈΟ BRANCH

Πριν κάνετε οποιαδήποτε αλλαγή, η καλύτερη πρακτική είναι να δημιουργήσετε ένα νέο branch. Η εργασία σε ξεχωριστό branch κρατά τη δουλειά σας οργανωμένη και το `main` καθαρό.

1. Στο τερματικό σας (μέσα στον φάκελο `good-first-issue`), εκτελέστε την εντολή `git switch -c` ακολουθούμενη από το όνομα του branch σας:

   ```bash
   git switch -c <όνομα-του-branch-σας>
   ```

   _(Δώστε ένα περιγραφικό όνομα, όπως `add-το-όνομά-σας` ή `το-όνομα-branch-που-θέλετε`)_

2. Το Git θα επιβεβαιώσει ότι δημιουργήσατε και μεταβήκατε στο νέο σας branch:

   <br/>

   <img src="../src/image3.png" alt="Δημιουργία νέου branch" width="550" />

   <br/>

   > [!TIP]
   > Συμβουλή: Εάν χρησιμοποιείτε παλαιότερη έκδοση του Git, μπορείτε επίσης να χρησιμοποιήσετε `git checkout -b <όνομα-του-branch-σας>`.

🌿 **Όλα έτοιμα!** Οποιεσδήποτε τροποποιήσεις κάνετε από εδώ και πέρα θα παραμείνουν στο νέο σας branch.

## 4. ΑΝΟΊΞΤΕ ΤΟ ΈΡΓΟ ΣΤΟΝ ΕΠΕΞΕΡΓΑΣΤΉ ΚΏΔΙΚΑ

Τώρα που έχετε το έργο τοπικά και το branch είναι έτοιμο, ήρθε η ώρα να το ανοίξετε στον επεξεργαστή κώδικα. Σε αυτόν τον οδηγό χρησιμοποιούμε το **Visual Studio Code (VS Code)**, αλλά μπορείτε να χρησιμοποιήσετε όποιον επεξεργαστή προτιμάτε.

Εάν έχετε ρυθμίσει το VS Code στη γραμμή εντολών σας, εκτελέστε απλά την ακόλουθη εντολή μέσα από τον φάκελο `good-first-issue`:

```bash
code .
```

Εναλλακτικά, μπορείτε να το ανοίξετε χειροκίνητα:

1. Εκκινήστε το **Visual Studio Code**.
2. Μεταβείτε στο **File** > **Open Folder...** (ή πατήστε `Ctrl + K, Ctrl + O` στα Windows / `Cmd + O` στο macOS).
3. Επιλέξτε τον φάκελο `good-first-issue`.

Θα δείτε τα αρχεία του έργου στην εξερεύνηση αρχείων:

<br/>

<img src="../src/image4.png" alt="Έργο ανοιχτό στο VS Code" width="310" />

<br/>

> [!NOTE]
> Δεν έχετε εγκαταστήσει ακόμα το VS Code; Μπορείτε να το κατεβάσετε δωρεάν από το [code.visualstudio.com](https://code.visualstudio.com/).

💻 **Έτοιμοι!** Το έργο είναι ανοιχτό στον επεξεργαστή σας και μπορείτε να ξεκινήσετε την επεξεργασία.

## 5. ΠΡΟΣΘΈΣΤΕ ΤΗΝ ΚΆΡΤΑ ΣΥΝΕΙΣΦΈΡΟΝΤΟΣ

Τώρα έρχεται το πιο διασκεδαστικό μέρος: να προσθέσετε τη δική σας κάρτα στο έργο!

Μέσα στον κατάλογο `assets/cards/`, δημιουργήστε ένα νέο αρχείο με το όνομα χρήστη σας στο GitHub ακολουθούμενο από `.json`:

📄 `assets/cards/<το-όνομα-χρήστη-σας>.json` _(π.χ. `octocat.json`)_

### ΔΟΜΉ

Το αρχείο σας πρέπει να ακολουθεί ακριβώς την ίδια δομή με το `jan.json`:

```json
{
  "name": "<το-όνομα-χρήστη-σας>",
  "img": "<url-της-φωτογραφίας-σας>",
  "github": "https://github.com/<το-όνομα-χρήστη-σας>"
}
```

### ΠΏΣ ΝΑ ΛΆΒΕΤΕ ΤΟ URL ΤΗΣ ΦΩΤΟΓΡΑΦΊΑΣ ΠΡΟΦΊΛ ΣΑΣ (`IMG`):

1. Ανοίξτε τη σελίδα του προφίλ σας στο GitHub στο πρόγραμμα περιήγησης (`https://github.com/<το-όνομα-χρήστη-σας>`).
2. Κάντε δεξί κλικ στη φωτογραφία προφίλ σας και επιλέξτε **"Copy image address"** (Αντιγραφή διεύθυνσης εικόνας).
3. Επικολλήστε αυτό το URL στο πεδίο `"img"`.

> [!TIP]
> Γρήγορο κόλπο: Μπορείτε επίσης να χρησιμοποιήσετε το `https://github.com/<το-όνομα-χρήστη-σας>.png` απευθείας ως URL εικόνας!

### ΠΑΡΆΔΕΙΓΜΑ

Εάν το όνομα χρήστη σας είναι `octocat`, θα δημιουργούσατε το αρχείο `assets/cards/octocat.json` με το ακόλουθο περιεχόμενο:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

Αποθηκεύστε το αρχείο όταν τελειώσετε. Μόλις δημιουργηθεί, είστε έτοιμοι για το επόμενο βήμα!

## 6. ΚΆΝΤΕ COMMIT ΚΑΙ PUSH ΤΙΣ ΑΛΛΑΓΈΣ ΣΑΣ

Πριν δημιουργήσετε το Pull Request, πρέπει να αποθηκεύσετε τις αλλαγές σας και να ανεβάσετε το branch σας στο GitHub.

1. Ανοίξτε το τερματικό σας στον κατάλογο του έργου και προετοιμάστε το νέο σας αρχείο:

   ```bash
   git add assets/cards/<το-όνομα-χρήστη-σας>.json
   ```

2. Κάντε commit τις αλλαγές με ένα σύντομο και περιγραφικό μήνυμα:

   ```bash
   git commit -m "feat: add <το-όνομα-χρήστη-σας> card"
   ```

3. Κάντε push το branch σας στο δικό σας fork στο GitHub:

   ```bash
   git push origin <όνομα-του-branch-σας>
   ```

   > [!NOTE]
   > Εάν σας ζητηθεί, μπορείτε επίσης να εκτελέσετε `git push -u origin <όνομα-του-branch-σας>`.

## 7. ΔΗΜΙΟΥΡΓΉΣΤΕ ΤΟ PULL REQUEST

Τώρα που το branch σας έχει ανέβει στο GitHub, ήρθε η ώρα να υποβάλετε τη συνεισφορά σας στο έργο!

1. Μεταβείτε στη σελίδα του fork σας στο GitHub (ή επισκεφθείτε το αρχικό αποθετήριο: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue)).
2. Κάντε κλικ στο κουμπί **"Contribute"** και επιλέξτε **"Open pull request"** (ή κάντε κλικ στο κουμπί **"Compare & pull request"** στο κίτρινο πλαίσιο):

   <br/>

   <img src="../src/image5.png" alt="Άνοιγμα pull request" width="450" />

   <br/>

3. Βεβαιωθείτε ότι:
   - **Base repository:** `jaanque/good-first-issue` (branch `main`)
   - **Head repository:** το δικό σας fork (το δικό σας branch)
4. Στον τίτλο και την περιγραφή, περιγράψτε καθαρά τι τροποποιήσατε:
   - **Τίτλος:** Προσθέστε έναν περιγραφικό τίτλο (π.χ. `Add <το-όνομα-χρήστη-σας> card`).
   - **Περιγραφή:** Γράψτε μια σύντομη περιγραφή εξηγώντας τι αλλάξατε (π.χ. ότι προσθέσατε την κάρτα σας στο `assets/cards/<το-όνομα-χρήστη-σας>.json`).
5. Κάντε κλικ στο πράσινο κουμπί **Create pull request**!
