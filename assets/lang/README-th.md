##

นี่เป็นครั้งแรกของคุณที่ใช้ Git และ GitHub ใช่ไหม? **คุณมาถูกที่แล้ว!**

คลังเก็บข้อมูล (Repository) นี้ออกแบบมาเพื่อช่วยให้คุณก้าวเข้าสู่โลกของ **โอเพนซอร์ส (Open Source)** ได้อย่างมั่นใจในสภาพแวดล้อมที่ปลอดภัย โดยไม่ต้องกลัวว่าจะทำอะไรเสียหาย

เราเชื่อว่าวิธีเรียนรู้ที่ดีที่สุดคือ **การลงมือทำ** เราจึงได้สร้างโปรเจกต์ง่ายๆ ที่คุณสามารถแก้ไขและปรับปรุงได้ทันที

**เป้าหมายของคุณนั้นง่ายมาก:** ทำตามขั้นตอนทีละขั้นเพื่อเพิ่มชื่อและรูปภาพของคุณลงในโปรเจกต์นี้

**พร้อมที่จะเริ่มต้นหรือยัง?** ไปที่ **ขั้นตอนที่ 1** แล้วมาร่วมสร้างสิ่งดีๆ กันเลย!

## 1. ฟอร์ก (Fork) คลังเก็บข้อมูล

**Fork** คือสำเนาส่วนตัวของคุณจากคลังเก็บข้อมูลนี้ภายใต้บัญชี GitHub ของคุณ ช่วยให้คุณทำการเปลี่ยนแปลงได้อย่างปลอดภัยโดยไม่กระทบต่อโปรเจกต์ต้นฉบับ!

1. ไปที่มุมบนขวาของหน้านี้ แล้วคลิกที่ปุ่ม **Fork**:

   <br/>

   <img src="../src/image.png" alt="ปุ่ม Fork" width="400" />

   <br/>

2. ในหน้า **Create a new fork** ให้คงชื่อคลังเก็บข้อมูลไว้ตามเดิม แล้วคลิก **Create fork**

3. หลังจากนั้นไม่กี่วินาที GitHub จะนำคุณไปยังสำเนาที่สร้างขึ้นใหม่ของคุณที่:

   `https://github.com/<ชื่อผู้ใช้ของคุณ>/good-first-issue`

🎉 **ยอดเยี่ยม!** ตอนนี้คุณมีสำเนาโปรเจกต์สำหรับทำงานแล้ว

## 2. โคลน (Clone) คลังเก็บข้อมูล

ตอนนี้คุณต้องดาวน์โหลดคลังเก็บข้อมูลที่คุณฟอร์กไว้ลงมาที่เครื่องคอมพิวเตอร์ของคุณเพื่อแก้ไขไฟล์ในเครื่อง

1. ใน **หน้าคลังเก็บข้อมูลที่คุณฟอร์กไว้** บน GitHub ให้คลิกที่ปุ่มสีเขียว "**<> Code**"
2. ในเมนูดรอปดาวน์ ตรวจสอบให้แน่ใจว่าเลือกแท็บ **HTTPS** แล้วคลิกไอคอนคัดลอกเพื่อคัดลอก URL ของคุณ:

   <br/>

   <img src="../src/image2.png" alt="โคลนคลังเก็บข้อมูล" width="360" />

   <br/>

3. เปิดเทอร์มินัลของคุณแล้วรันคำสั่ง `git clone` ตามด้วย URL ที่คุณคัดลอกมา:

   ```bash
   git clone https://github.com/<ชื่อผู้ใช้ของคุณ>/good-first-issue.git
   ```

   > 💡 _อย่าลืมแทนที่ `<ชื่อผู้ใช้ของคุณ>` ด้วยชื่อผู้ใช้ GitHub จริงของคุณ!_

4. เมื่อการดาวน์โหลดเสร็จสิ้น ให้เข้าไปยังไดเรกทอรีของโปรเจกต์:

   ```bash
   cd good-first-issue
   ```

🚀 **ทำได้ดีมาก!** ตอนนี้ไฟล์โปรเจกต์อยู่ในเครื่องของคุณแล้ว และพร้อมสำหรับการเปลี่ยนแปลง

## 3. สร้างกิ่ง (Branch) ใหม่

ก่อนทำการเปลี่ยนแปลงใดๆ การสร้างกิ่งใหม่ถือเป็นแนวปฏิบัติที่ดีที่สุด การทำงานบนกิ่งแยกช่วยให้งานเป็นระเบียบและทำให้กิ่ง `main` สะอาดอยู่เสมอ

1. ในเทอร์มินัลของคุณ (ภายในโฟลเดอร์ `good-first-issue`) ให้รันคำสั่ง `git switch -c` ตามด้วยชื่อกิ่งของคุณ:

   ```bash
   git switch -c <ชื่อกิ่งของคุณ>
   ```

   _(ตั้งชื่อที่สื่อความหมาย เช่น `add-ชื่อของคุณ` หรือ `ชื่อกิ่งที่คุณต้องการ`)_

2. Git จะยืนยันว่าคุณได้สร้างและสลับไปยังกิ่งใหม่แล้ว:

   <br/>

   <img src="../src/image3.png" alt="สร้างกิ่งใหม่" width="550" />

   <br/>

   > 💡 _คำแนะนำ: หากคุณใช้ Git เวอร์ชันเก่า คุณสามารถใช้ `git checkout -b <ชื่อกิ่งของคุณ>` ได้เช่นกัน_

🌿 **พร้อมแล้ว!** การแก้ไขทั้งหมดหลังจากนี้จะอยู่บนกิ่งใหม่ของคุณ

## 4. เปิดโปรเจกต์ในโปรแกรมแก้ไขโค้ด

ตอนนี้โปรเจกต์อยู่ในเครื่องของคุณและกิ่งก็พร้อมแล้ว ถึงเวลาเปิดในโปรแกรมแก้ไขโค้ด ในคู่มือนี้เราใช้ **Visual Studio Code (VS Code)** แต่คุณสามารถใช้โปรแกรมใดก็ได้ที่คุณสะดวก

หากคุณกำหนดค่า VS Code ในบรรทัดคำสั่งไว้แล้ว เพียงรันคำสั่งต่อไปนี้จากภายในโฟลเดอร์ `good-first-issue`:

```bash
code .
```

หรือคุณสามารถเปิดด้วยตนเองได้:

1. เปิด **Visual Studio Code**
2. ไปที่ **File** > **Open Folder...** (หรือกด `Ctrl + K, Ctrl + O` บน Windows / `Cmd + O` บน macOS)
3. เลือกโฟลเดอร์ `good-first-issue`

คุณควรจะเห็นไฟล์โปรเจกต์ในแถบสำรวจไฟล์:

<br/>

<img src="../src/image4.png" alt="เปิดโปรเจกต์ใน VS Code" width="310" />

<br/>

> 💡 _ยังไม่ได้ติดตั้ง VS Code ใช่ไหม? คุณสามารถดาวน์โหลดได้ฟรีที่ [code.visualstudio.com](https://code.visualstudio.com/)_

💻 **เรียบร้อย!** โปรเจกต์เปิดอยู่ในโปรแกรมแก้ไขโค้ดแล้ว และคุณพร้อมที่จะเริ่มแก้ไขไฟล์

## 5. เพิ่มการ์ดผู้มีส่วนร่วมของคุณ

ตอนนี้ถึงส่วนที่สนุกที่สุดแล้ว: เพิ่มการ์ดของคุณเองลงในโปรเจกต์!

ภายในไดเรกทอรี `assets/cards/` ให้สร้างไฟล์ใหม่โดยตั้งชื่อตามชื่อผู้ใช้ GitHub ของคุณตามด้วย `.json`:

📄 `assets/cards/<ชื่อผู้ใช้ของคุณ>.json` _(เช่น `octocat.json`)_

### โครงสร้าง

ไฟล์ของคุณจะต้องมีโครงสร้างเหมือนกับ `jan.json` ทุกประการ:

```json
{
  "name": "<ชื่อผู้ใช้ของคุณ>",
  "img": "<url-รูปภาพโปรไฟล์ของคุณ>",
  "github": "https://github.com/<ชื่อผู้ใช้ของคุณ>"
}
```

### วิธีรับ URL รูปภาพโปรไฟล์ของคุณ (`img`):

1. เปิดหน้าโปรไฟล์ GitHub ของคุณในเบราว์เซอร์ (`https://github.com/<ชื่อผู้ใช้ของคุณ>`)
2. คลิกขวาที่รูปโปรไฟล์ของคุณแล้วเลือก **"Copy image address"** (หรือคัดลอกที่อยู่รูปภาพ)
3. วาง URL ที่คัดลอกมาลงในช่อง `"img"`

> 💡 _เคล็ดลับด่วน: คุณสามารถใช้ `https://github.com/<ชื่อผู้ใช้ของคุณ>.png` เป็น URL รูปภาพของคุณได้โดยตรง!_

### ตัวอย่าง

หากชื่อผู้ใช้ของคุณคือ `octocat` คุณจะสร้างไฟล์ `assets/cards/octocat.json` ด้วยเนื้อหาต่อไปนี้:

```json
{
  "name": "octocat",
  "img": "https://github.com/octocat.png",
  "github": "https://github.com/octocat"
}
```

บันทึกไฟล์เมื่อทำเสร็จ เมื่อสร้างเสร็จแล้วคุณก็พร้อมสำหรับขั้นตอนต่อไป!

## 6. Commit และ Push การเปลี่ยนแปลงของคุณ

ก่อนสร้าง Pull Request คุณต้องบันทึกการเปลี่ยนแปลงและอัปโหลดกิ่งของคุณขึ้นสู่ GitHub

1. เปิดเทอร์มินัลของคุณภายในไดเรกทอรีโปรเจกต์และเพิ่มไฟล์ใหม่ของคุณ:

   ```bash
   git add assets/cards/<ชื่อผู้ใช้ของคุณ>.json
   ```

2. บันทึก (Commit) การเปลี่ยนแปลงพร้อมข้อความที่กระชับและชัดเจน:

   ```bash
   git commit -m "feat: add <ชื่อผู้ใช้ของคุณ> card"
   ```

3. ดัน (Push) กิ่งของคุณไปยัง fork บน GitHub:

   ```bash
   git push origin <ชื่อกิ่งของคุณ>
   ```

   > 💡 _หากระบบถาม คุณสามารถรัน `git push -u origin <ชื่อกิ่งของคุณ>` ได้เช่นกัน_

## 7. สร้าง Pull Request

ตอนนี้กิ่งของคุณถูกอัปโหลดขึ้น GitHub แล้ว ถึงเวลาส่งผลงานของคุณเข้าร่วมโปรเจกต์!

1. ไปที่หน้า fork ของคุณบน GitHub (หรือไปที่คลังเก็บข้อมูลต้นฉบับ: [jaanque/good-first-issue](https://github.com/jaanque/good-first-issue))
2. คลิกที่ปุ่ม **"Contribute"** แล้วเลือก **"Open pull request"** (หรือคลิกที่ปุ่ม **"Compare & pull request"** ในแถบสีเหลือง):

   <br/>

   <img src="../src/image5.png" alt="เปิด pull request" width="450" />

   <br/>

3. ตรวจสอบว่า:
   - **Base repository:** `jaanque/good-first-issue` (กิ่ง `main`)
   - **Head repository:** fork ของคุณ (กิ่งของคุณ)
4. ในส่วนหัวข้อและคำอธิบาย ให้อธิบายสิ่งที่คุณแก้ไขให้ชัดเจน:
   - **หัวข้อ:** ใส่ชื่อที่สื่อความหมาย (เช่น `Add <ชื่อผู้ใช้ของคุณ> card`)
   - **คำอธิบาย:** เขียนคำอธิบายสั้นๆ เกี่ยวกับการเปลี่ยนแปลงของคุณ (เช่น คุณได้เพิ่มการ์ดของคุณใน `assets/cards/<ชื่อผู้ใช้ของคุณ>.json`)
5. คลิกปุ่มสีเขียว **Create pull request**!
