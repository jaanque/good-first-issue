Frequently Asked Questions ❓

Quick clarity on the most common questions, terminology, and troubleshooting steps.

What is the difference between Fork and Clone?

A Fork happens on GitHub's servers: it creates a personal copy of another user's repository under your GitHub profile. A Clone happens locally: it downloads the files from GitHub to your computer so you can open and edit them.

I made a typo in my card after opening the Pull Request. Do I need to open a new PR?

No! Any new commit you make and push to the same branch on your fork will automatically update your existing Pull Request. Just edit the file, commit your change, and run git push.

Why is my card not visible on the showcase yet?

Your card appears after a project maintainer reviews and merges your Pull Request into the main branch. Once merged, GitHub Actions will compile your card automatically within 1 to 2 minutes.

What is a Pull Request?

A Pull Request (PR) is a formal request asking the repository owner to review the changes you made in your branch and "pull" (merge) them into their project. It is the core collaboration mechanism in Open Source.

Can I translate the guide into my native language?

Yes, absolutely! We love multilingual contributions. You can add a new translation file in assets/lang/README-<language-code>.md and submit it via Pull Request.
