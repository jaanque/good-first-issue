What is Coding Levels?

Adding your JSON card introduced you to Git and GitHub. Coding Levels is the next step: a collection of curated, progressive coding challenges hosted inside the levels/ folder of this repository.

Each level guides you through real code concepts — with clear requirements, local testing instructions, and a reference solution. You code on your machine and submit your solution via Pull Request!

1
Fork
Fork the repository to your account
2

3

4

5

Submit your PR to this repo
