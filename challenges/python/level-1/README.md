# 🟢 Level 1: Print Your Welcome Message (`print()`)

> **Difficulty:** Very Easy | **Estimated Time:** 5 mins | **Track:** Python

Welcome to **Level 1** of the Python Track! This is where every Python journey begins: using Python's built-in `print()` function to send text to your terminal screen.

---

## 📖 What You'll Learn & Why It Matters

Python is celebrated for its clean, expressive syntax. In Python, outputting text to the console doesn't require importing libraries or writing boilerplate classes — a single line is all it takes!

### Syntax Quick Look:
```python
print("Hello, World!")
```
- Strings can be wrapped in double quotes (`"..."`) or single quotes (`'...'`).
- Python automatically appends a newline character at the end of each `print()` call.

---

## 🎯 Objective

Create a file named `<your-username>.py` in this directory that outputs a friendly welcome message to the console.

---

## 📋 Requirements

1. **File Location:**  
   `challenges/python/level-1/<your-username>.py` *(e.g. `challenges/python/level-1/octocat.py`)*

2. **Specifications:**
   - Use the built-in `print()` function to output a greeting.
   - The message must include:
     - The phrase `"Hello Open Source!"`
     - Your GitHub handle (e.g. `@<your-username>`)
     - A mention of your Level 1 contribution.

---

## 💡 Example

```python
"""Level 1: Print Your Welcome Message.

Contributor: @octocat
"""

print("Hello Open Source! I am @octocat and this is my Level 1 contribution.")
```

---

## 🧠 Pro-Tips & Common Gotchas

- 💡 **No Semicolons:** In Python, statements end with a newline — no trailing semicolons (`;`) are required.
- 💡 **Python Version:** Make sure you're running Python 3 (check with `python --version` or `python3 --version`).

---

## 🧪 Testing Your Solution

Run your script in the terminal from the repository root:

```bash
python challenges/python/level-1/<your-username>.py
# or on macOS / Linux:
python3 challenges/python/level-1/<your-username>.py
```

### Expected Terminal Output:
```text
Hello Open Source! I am @octocat and this is my Level 1 contribution.
```
