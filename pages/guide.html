Git Knowledge Guide 📖

Master the fundamental commands and mental models of version control to contribute with confidence.

1. What is Git vs GitHub?

Git is a version control tool running locally on your computer that tracks changes to files over time. GitHub is a cloud platform hosting Git repositories, providing social coding features like Pull Requests, Issue tracking, and web showcases.

2. Essential Commands Cheatsheet

The everyday workflow from downloading code to submitting your changes:

# Clone your fork to your machine
git clone https://github.com/<your-username>/good-first-issue.git

# Move into the project directory
cd good-first-issue

# Create and switch to a new branch
git checkout -b add-my-card

# Check which files have changed
git status

# Stage the modified or new files
git add assets/cards/<your-username>.json

# Save changes with a clear message
git commit -m "Add <your-username> contributor card"

# Upload your branch to your GitHub fork
git push -u origin add-my-card
💡 Tip: Always create a dedicated branch before making edits. Leaving the main branch untouched keeps your repository organized and easy to synchronize.

3. The Open Source Contribution Cycle

Every open source contribution follows five core steps:

Fork ➔ create your personal copy on GitHub.

Clone ➔ download files to your local environment.

Branch & Edit ➔ make and verify your changes safely.

Commit & Push ➔ save your work and upload it to GitHub.

Pull Request (PR) ➔ propose merging your branch into the original project.

4. Keeping your Fork Synchronized

When the original repository receives new updates, your fork might fall behind. You can synchronize it directly from GitHub by clicking the "Sync fork" button on your repository page, or via command line:

git remote add upstream https://github.com/jaanque/good-first-issue.git
git fetch upstream
git checkout main
git merge upstream/main
